Czasy angielskie

Wszystkie 12 czasów: budowa, użycie i sygnały czasowe — w jednej tabeli

Aktualizacja: 2026-06

Angielski ma 12 czasów gramatycznych, które powstają z kombinacji trzech perspektyw czasowych (Present, Past, Future) i czterech aspektów (Simple, Continuous, Perfect, Perfect Continuous). W praktyce najczęściej używane są cztery pierwsze — warto je opanować priorytetowo.

Present Simple — czas teraźniejszy prosty

ElementSzczegółyPrzykład
Budowa (+)podmiot + bezokolicznik (3os.l.poj: + -s/-es)I write code. She writes code.
Budowa (–)podmiot + don't / doesn't + bezokolicznikHe doesn't use tabs.
Budowa (?)Do / Does + podmiot + bezokolicznik?Does she push to main?
UżycieNawyki, stałe czynności, fakty, rozkłady jazdyThe server restarts every night.
Sygnałyalways, usually, often, sometimes, never, every day/week, on MondaysWe always do code review on Fridays.

Present Continuous — czas teraźniejszy ciągły

ElementSzczegółyPrzykład
Budowa (+)podmiot + am/is/are + czasownik-ingI am debugging the issue.
Budowa (–)podmiot + am/is/are not + -ingWe aren't deploying today.
Budowa (?)Am/Is/Are + podmiot + -ing?Is he still refactoring?
UżycieCzynność trwająca teraz; zaplanowana przyszłość; tymczasowe stanyShe is working from home this week.
Sygnałynow, at the moment, currently, right now, today, this week/month, look! listen!The build is currently running.
⚠ Czasowniki stanu (state verbs) nie używają formy Continuous: know, understand, believe, want, need, like, love, hate, see, hear, belong. Mówimy I understand, nie ~~I am understanding~~.

Present Perfect — czas teraźniejszy dokonany

ElementSzczegółyPrzykład
Budowa (+)podmiot + have/has + III forma (past participle)I have fixed the bug.
Budowa (–)podmiot + haven't/hasn't + III formaShe hasn't merged yet.
Budowa (?)Have/Has + podmiot + III forma?Have you pushed the changes?
UżyciePrzeszłość z efektem teraźniejszym; doświadczenie życiowe; niedawno zakończone czynnościI've just deployed v2.0.
Sygnałyjust, already, yet, ever, never, recently, lately, so far, up to now, since, forHas anyone ever seen this error before?
💡 since vs for: since + punkt startowy (since 2020, since Monday); for + czas trwania (for three years, for two hours).

Present Perfect Continuous

ElementSzczegółyPrzykład
Budowapodmiot + have/has been + -ingI have been working on this all day.
UżycieCzynność rozpoczęta w przeszłości, trwająca do teraz (podkreślenie czasu trwania lub efektów)She has been refactoring since morning.
Sygnałyfor, since, all day, all week, how long?How long have you been learning English?

Past Simple — czas przeszły prosty

ElementSzczegółyPrzykład
Budowa (+)podmiot + II forma (reg. -ed, nieregularne osobno)We deployed the hotfix last night.
Budowa (–)podmiot + didn't + bezokolicznikHe didn't push to main.
Budowa (?)Did + podmiot + bezokolicznik?Did the tests pass?
UżycieZdarzenie zakończone w określonym czasie w przeszłościShe joined the company in 2022.
Sygnałyyesterday, last week/month/year, ago, in 2020, then, when, at 3pmThe server crashed two hours ago.

Past Continuous — czas przeszły ciągły

ElementSzczegółyPrzykład
Budowapodmiot + was/were + -ingI was reviewing code when the alarm went off.
UżycieCzynność trwająca w przeszłości, przerwana przez inne zdarzenie; tło dla fabułyWhile she was presenting, the app crashed.
Sygnaływhile, when, at that moment, at 3pm yesterday, all morning

Past Perfect — czas przeszły dokonany zaprzeszły

ElementSzczegółyPrzykład
Budowapodmiot + had + III formaBy the time we noticed, the data had already been deleted.
UżycieCzynność wcześniejsza od innej czynności w przeszłościShe had committed the fix before the meeting started.
Sygnałyby the time, before, after, already, when (+ Past Simple)

Future Simple (will) — czas przyszły prosty

ElementSzczegółyPrzykład
Budowa (+)podmiot + will + bezokolicznikI will send you the report.
Budowa (–)podmiot + won't + bezokolicznikThe pipeline won't run on weekends.
UżycieSpontaniczne decyzje; przewidywania; obietnice; fakty o przyszłościI'll help you with the PR. It will rain tomorrow.
Sygnałytomorrow, next week/month, soon, in the future, I think, I believe, probably

Be going to — zaplanowana przyszłość

Obok will istnieje forma be going to, używana dla zaplanowanych wcześniej działań lub przewidywań opartych na dowodach:

UżyciePrzykład
Zaplanowane działanieWe are going to release v3 next sprint.
Przewidywanie na podstawie dowodówLook at that memory leak — the server is going to crash.

Future Continuous — czas przyszły ciągły

ElementSzczegółyPrzykład
Budowapodmiot + will be + -ingThis time tomorrow I will be presenting to the client.
UżycieCzynność trwająca w określonym momencie w przyszłościThey will be migrating the database all weekend.
Sygnałythis time tomorrow/next week, at 5pm on Friday, when you arrive

Future Perfect — czas przyszły dokonany

ElementSzczegółyPrzykład
Budowapodmiot + will have + III formaBy Friday, we will have shipped all the features.
UżycieCzynność ukończona przed określonym momentem w przyszłościShe will have finished the refactoring by the time you arrive.
Sygnałyby, by the time, before, by then, by next week/Monday
