# Projekt: dom jednorodzinny 100 m²

## Założenia

| Parametr | Wartość |
|---|---|
| Powierzchnia | 100 m² (parter 60 + poddasze 40) |
| Mieszkańcy | 4 osoby |
| Ogrzewanie | pompa ciepła powietrze-woda 4 kW elektryczna |
| Kuchnia | płyta indukcyjna 3-faz 7 kW + piekarnik 3,5 kW |
| CWU | bojler elektryczny 2 kW (rezerwa do PC) |
| Garaż | ładowarka EV wallbox 11 kW (3-faz 16 A) |
| Fotowoltaika | brak, przygotowane miejsce (rezerwa 8 modułów) |
| Układ sieci | TN-C-S (PEN na przyłączu, dalej TN-S) |

## Bilans mocy

| Odbiornik | Moc Pi [kW] |
|---|---|
| Oświetlenie LED (cały dom) | 0,5 |
| Gniazda ogólne | 2,0 |
| AGD (lodówka, pralka, zmywarka, mikrofalówka) | 4,0 |
| Płyta indukcyjna 3-faz | 7,0 |
| Piekarnik | 3,5 |
| Bojler / pompa ciepła | 4,0 |
| Ładowarka EV | 11,0 |
| **Suma Pi** | **32 kW** |

Współczynnik jednoczesności kz = 0,5 (dom jednorodzinny):

```
Pz = Pi · kz = 32 · 0,5 = 16 kW
```

Prąd na fazę (3-faz, cos φ ≈ 0,95):

```
I = Pz / (√3 · U · cos φ) = 16 000 / (1,732 · 400 · 0,95) ≈ 24,3 A
```

**Przyłącze:** 3-fazowe **25 A** (zabezpieczenie przedlicznikowe 3×25 A gG, taryfa G12w lub G13).

**Spadek napięcia** dla obwodu indukcji 6 m, 16 A, 3F: ΔU ≈ 0,7% — OK (limit 5%).
Dla ładowarki EV 12 m, 16 A, 3F, S=6 mm²: ΔU ≈ 0,9% — OK.

## Pomiar i odbiór

Pięć protokołów obowiązkowych:
1. Rezystancja izolacji (każdy obwód, ≥ 1 MΩ przy 500 V DC)
2. Impedancja pętli zwarcia Zs (każde gniazdo końcowe, ≤ tabela dla danego MCB)
3. Test RCD (czas zadziałania ≤ 300 ms przy IΔn, ≤ 40 ms przy 5·IΔn)
4. Rezystancja uziemienia (Rz ≤ 30 Ω dla TN-C-S z lokalnym uziomem)
5. Ciągłość przewodów PE i wyrównawczych (R ≤ 1 Ω)
