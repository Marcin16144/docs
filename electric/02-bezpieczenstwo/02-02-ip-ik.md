# Stopnie ochrony IP i IK

## Czym jest kod IP

Kod IP (Ingress Protection) wg normy PN-EN 60529 określa odporność obudowy urządzenia na wnikanie:

- **ciał stałych** (palec, narzędzie, pył) — pierwsza cyfra
- **wody** (krople, strumień, zanurzenie) — druga cyfra

Format zapisu:

```
IP X Y
   │ │
   │ └── ochrona przed wodą (0-9)
   └──── ochrona przed ciałami stałymi (0-6)
```

Jeśli któraś cyfra nie jest określona, zastępuje się ją znakiem "X" (np. IPX4).

## Pierwsza cyfra IP — ciała stałe

| Cyfra | Ochrona przed |
|---|---|
| **0** | brak ochrony |
| **1** | obiekty ≥50 mm (np. tylna strona ręki) |
| **2** | obiekty ≥12,5 mm (palec) |
| **3** | obiekty ≥2,5 mm (narzędzia, grube druty) |
| **4** | obiekty ≥1 mm (cienkie druty, śrubokręt precyzyjny) |
| **5** | kurz — częściowa ochrona, dopuszczalne minimalne ilości pyłu |
| **6** | kurz — pełna ochrona, **pyłoszczelność** |

## Druga cyfra IP — woda

| Cyfra | Ochrona przed |
|---|---|
| **0** | brak ochrony |
| **1** | krople padające pionowo |
| **2** | krople padające pod kątem do 15° |
| **3** | bryzgi wody pod kątem do 60° (deszcz) |
| **4** | bryzgi wody z dowolnego kierunku |
| **5** | strumień wody (dysza 6,3 mm) z dowolnego kierunku |
| **6** | silny strumień wody (dysza 12,5 mm) — np. fala morska, mycie ciśnieniowe |
| **7** | krótkotrwałe zanurzenie (do 1 m, do 30 min) |
| **8** | długotrwałe zanurzenie (>1 m, warunki uzgadnia producent) |
| **9** | strumień wody o wysokiej temperaturze pod wysokim ciśnieniem (mycie parą) |

## Najczęściej spotykane stopnie IP

| Kod | Co oznacza | Typowe zastosowanie |
|---|---|---|
| **IP20** | palec nie sięga części pod napięciem | gniazda i włączniki w pomieszczeniach suchych |
| **IP21** | + krople pionowe | sufitowe oprawy oświetleniowe |
| **IP22** | + krople do 15° | piwnice z możliwym kondensatem |
| **IP23** | + bryzgi do 60° | osprzęt na zadaszonych werandach |
| **IP44** | + bryzgi z każdej strony | łazienki strefa 2, ogród zadaszony, kuchnie |
| **IP54** | + częściowa pyłoodporność | rozdzielnice w garażu, na strychu |
| **IP55** | + strumień wody | gniazda w garażu, warsztat, plac budowy |
| **IP65** | pyłoszczelne + strumień wody | oprawy ogrodowe, kamery zewnętrzne |
| **IP66** | + silny strumień | fasady, kominy, dachy |
| **IP67** | + krótkie zanurzenie | sprzęt w pomieszczeniach mokrych, latarki nurkowe |
| **IP68** | + długie zanurzenie | pompy zanurzeniowe, kable podziemne, smartfony "wodoodporne" |
| **IPX4** | tylko ochrona przed wodą (bryzgi) | golarki, słuchawki |

## Strefy w łazience i wymagane IP

Norma PN-HD 60364-7-701 dzieli łazienkę na strefy o różnych wymaganiach IP:

| Strefa | Lokalizacja | Wymagany IP | Co wolno |
|---|---|---|---|
| **0** | wewnątrz wanny/brodzika | IPX7 | tylko 12 V SELV |
| **1** | nad wanną/brodzikiem do 2,25 m | IPX4 | 12 V SELV, oprawy IPX4 klasy II |
| **2** | 0,6 m wokół wanny do 2,25 m | IPX4 | gniazda golarkowe SELV, oprawy IPX4 |
| **3** | reszta łazienki | IPX1 (zwykle IP44) | gniazda zwykłe za RCD 30 mA |

## Kod IK — odporność mechaniczna

Kod IK wg PN-EN 62262 określa odporność obudowy na uderzenia. Liczba wskazuje energię uderzenia w **dżulach**:

| Kod | Energia | Symulacja | Zastosowanie |
|---|---|---|---|
| IK00 | brak ochrony | — | wewnątrz urządzeń |
| IK01 | 0,15 J | upadek 250 g z 6 cm | sprzęt biurowy |
| IK02 | 0,2 J | upadek 250 g z 8 cm | |
| IK03 | 0,35 J | | |
| IK04 | 0,5 J | | |
| IK05 | 0,7 J | | |
| IK06 | 1 J | upadek 250 g z 40 cm | rozdzielnice domowe |
| IK07 | 2 J | upadek 500 g z 40 cm | sprzęt warsztatowy |
| IK08 | 5 J | upadek 1,7 kg z 30 cm | oprawy uliczne |
| IK09 | 10 J | upadek 5 kg z 20 cm | oprawy w halach przemysłowych |
| **IK10** | **20 J** | upadek 5 kg z 40 cm | **oprawy wandaloodporne**, stacje benzynowe, sport |

## Praktyczne zasady doboru IP

- **Łazienka:** minimum IP44 dla strefy 2, IP20 dla strefy 3 + RCD 30 mA
- **Ogród zadaszony, taras:** IP44 wystarcza
- **Ogród niezadaszony, na słupku:** IP55 lub IP65
- **Zalany ogród, pompa w basenie:** IP67/IP68
- **Mycie ciśnieniowe (myjnia samochodowa):** IP69K
- **Środowisko z pyłem (warsztat, młyn):** IP5X lub IP6X

## Mit „wodoodporności"

Wiele urządzeń konsumenckich (smartfony, zegarki) reklamuje się jako "wodoodporne". Faktycznie:

| Reklamowane | Realnie znaczy | Praktyka |
|---|---|---|
| "Splash proof" | IPX4 | bryzgi, nie zanurzenie |
| "Wodoodporny" | IPX7 | krótkie zanurzenie do 1 m |
| "Diving watch 100 m" | IPX8 (warunki specyficzne) | nurkowanie ze sprzętem |

**Uwaga:** ochrona IP testowana jest w **wodzie słodkiej**, w spoczynku. Woda słona, mydlana lub strumień (basen, prysznic) może uszkodzić nawet sprzęt IP68.
