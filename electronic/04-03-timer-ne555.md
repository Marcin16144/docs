# 04-03: Timer NE555

## Czym jest NE555

Najsłynniejszy układ scalony w historii. Zaprojektowany w 1971 przez Hansa Camenzinda. Produkowany do dziś **miliardami sztuk rocznie**.

Funkcjonalność: generator opóźnień, oscylator, modulator PWM, układ wyzwalania, dzielnik częstotliwości i wiele więcej.

## Wyprowadzenia (DIP-8)

```
       NE555
   ┌──────────┐
   │1 GND    8│ VCC
   │2 TRIG   7│ DISCH
   │3 OUT    6│ THRESH
   │4 RESET  5│ CTRL
   └──────────┘
```

| Pin | Nazwa | Opis |
|-----|-------|------|
| 1 | GND | masa |
| 2 | TRIGGER | wejście wyzwalania (aktywne LOW) |
| 3 | OUT | wyjście |
| 4 | RESET | reset (aktywne LOW), zwykle do VCC |
| 5 | CTRL | sterowanie napięciem progu |
| 6 | THRESHOLD | wejście progowe |
| 7 | DISCHARGE | wyjście do rozładowania kondensatora |
| 8 | VCC | zasilanie 4,5-16 V (5-15 V typowo) |

## Struktura wewnętrzna

Wewnątrz:
- Dzielnik 3× R (czyli 5 kΩ, 5 kΩ, 5 kΩ) → tworzy progi 1/3 V_CC i 2/3 V_CC
- Dwa komparatory porównujące z tymi progami
- Flip-flop SR sterujący wyjściem i tranzystorem rozładowania
- Stopień wyjściowy push-pull (do 200 mA)

## Wersje NE555

| Wersja | Charakterystyka |
|--------|----------------|
| NE555 (bipolarny) | klasyczny, większy pobór, do 15 V |
| LM555, MC1455 | warianty bipolarne |
| 7555 (TLC555, ICM7555) | CMOS, niski pobór (~60 μA), do 18 V |
| 556 | podwójny 555 (DIP-14) |
| 558 | poczwórny |

## Tryby pracy

### 1. Astabilny (multivibrator) — generator

Generuje **prostokątne fale** o zadanej częstotliwości i wypełnieniu.

```
        VCC
         │
        [Ra]
         │
         ●─── (do pinu 7 DISCH)
         │
        [Rb]
         │
         ●─── (do pinów 2 i 6 TRIG/THRESH)
         │
        [C]
         │
        GND
        
        + pin 4 RESET do VCC, pin 5 CTRL przez 10nF do GND
```

#### Wzory

```
T_H = 0,693 · (Ra + Rb) · C    (czas HIGH)
T_L = 0,693 · Rb · C            (czas LOW)
T = T_H + T_L = 0,693 · (Ra + 2·Rb) · C

f = 1 / T = 1,44 / ((Ra + 2·Rb) · C)

D (duty cycle) = T_H / T = (Ra + Rb) / (Ra + 2·Rb)
```

Wypełnienie zawsze > 50%! Aby zejść poniżej 50%, dodaj diodę.

#### Przykład: oscylator 1 kHz

```
Ra = 4,7 kΩ, Rb = 4,7 kΩ, C = ?
T = 1/1000 = 1 ms
1·10⁻³ = 0,693 · (4700 + 2·4700) · C
C = 0,001 / (0,693 · 14100) ≈ 102 nF → 100 nF
```

#### Duty cycle 50%

Z diodą przez Rb:
```
   Ra ── (do 7)
         │
         ▷│ dioda
         │
   Rb (do 7)
         │
   ──── do TRIG/THRESH
```

Wtedy:
```
T_H ≈ 0,693 · Ra · C
T_L ≈ 0,693 · Rb · C
```

Przy Ra = Rb → duty 50%.

### 2. Monostabilny (one-shot) — pojedynczy impuls

Generuje **jeden impuls** o określonej długości po wyzwoleniu.

```
        VCC
         │
        [R]
         │
         ●── (do 6 i 7)
         │
        [C]
         │
        GND
        
   pin 2 (TRIG) ── przycisk lub sygnał wyzwalający
                  z pull-upem do VCC (przycisk zwiera do GND)
```

#### Wzór czasu impulsu

```
T = 1,1 · R · C
```

#### Przykład: opóźnienie 1 sekunda

```
R = 100 kΩ, C = ?
T = 1,1 · R · C
1 = 1,1 · 100 000 · C
C = 9,1 μF → 10 μF
```

#### Działanie

1. Spoczynek: OUT = LOW, kondensator rozładowany.
2. Krótki LOW na TRIG (pin 2) → flip-flop ustawiony, OUT = HIGH, tranzystor rozładowania wyłączony.
3. Kondensator ładuje się przez R.
4. Gdy U na C osiągnie 2/3 VCC, drugi komparator resetuje flip-flop → OUT = LOW, kondensator rozładowuje się przez pin 7.
5. Powrót do spoczynku.

### 3. Bistable (latch / SR flip-flop)

NE555 jako prosty zatrzask SR. Pin 2 (TRIG, set) ustawia OUT na HIGH, pin 4 (RESET) lub przyłożenie pin 6 do HIGH resetuje.

### 4. Schmitt Trigger

Połącz piny 2 i 6 razem — wejście porównuje się z 1/3 i 2/3 VCC. Działa jak komparator z histerezą.

## Zastosowania praktyczne

### Migający LED

Astabilny ~1 Hz, R_a = 10 kΩ, R_b = 100 kΩ, C = 10 μF → f ≈ 0,67 Hz.

```
   +5V─[Ra]─●─[Rb]─●─ TRIG/THRES (2/6)
              7    │
              │   [C]
              │    │
              ●── GND
        
   OUT (3) ─[R 220]─ ▷│ LED ─ GND
```

### Sygnalizacja dźwiękowa

Astabilny ~1 kHz → wyjście do głośnika piezo lub przez tranzystor do głośnika dynamicznego.

### Generator PWM (sterowanie jasnością LED, prędkością silnika)

CTRL (pin 5) sterowany sygnałem analogowym → zmienia próg → zmienia wypełnienie. Albo Ra i Rb z potencjometrami.

### Debounce przycisku

Monostabilny 50 ms wyzwalany przyciskiem. Wyjście jest stabilne nawet przy iskrzeniu styków.

### Przedłużacz impulsu

Krótkie wyzwolenie → wyjście HIGH na zadany czas. Np. czujnik PIR z krótkim impulsem → sterowanie żarówką przez 5 minut.

### Modulator szerokości impulsów

Sterowanie ESC (Electronic Speed Controller) modeli RC. NE555 z sygnałem analogowym na CTRL daje szerokość 1-2 ms.

### Generator funkcyjny

NE555 + dodatkowe filtry RC → fala trójkątna, sinusoidalna.

### Sirena policyjna / alarm

Dwa NE555 — jeden generuje wolną modulację (0,5 Hz), drugi szybką (1-2 kHz). Wyjście pierwszego steruje CTRL drugiego.

## Wydajność wyjścia

NE555 może dostarczyć/przyjąć **do 200 mA** na wyjściu. Wystarczy bezpośrednio sterować:
- LED z rezystorem
- Przekaźnik (z diodą freewheel!)
- Mały głośnik
- Mosfet (przez rezystor bramki)

## Praktyczne wskazówki

### Kondensator blokujący

Zawsze 100 nF między pin 8 (VCC) a pin 1 (GND), jak najbliżej.

### Pin 5 (CTRL)

Jeśli nie używany, podłącz 10 nF do GND. Bez tego szumy mogą wpłynąć na progi.

### Dłuższe czasy

Dla T > 1 s:
- Większy C → ale ze stratami i prądem upływu (elektrolit, tantal)
- Większy R → ale wpływ prądów wejść CMOS

Praktycznie: R do 10 MΩ, C do 100 μF. Dla dłuższych czasów (godziny) — używaj 7555 (CMOS, mały prąd upływu) lub kaskadowo z liczników.

### Dokładność

NE555 nie jest precyzyjnym timerem:
- Tolerancja częstotliwości ~5-10%
- Wpływ temperatury ~0,005%/°C
- Drift z napięciem zasilania ~0,3%/V

Do zegarów RTC, oscylatory kwarcowe, dedykowane RTC ICs (DS1307, DS3231).

### Niezależność od VCC

Częstotliwość astabilnego prawie nie zależy od napięcia zasilania (oba progi są ułamkiem VCC, ładowanie i rozładowanie też). To rzadka cecha — wykorzystywana w aplikacjach bateryjnych.

### Pin 4 (RESET)

Aktywny LOW. Jeśli nieużywany → podłącz do VCC. Inaczej szumy mogą zresetować układ.

## Łączenie z innymi układami

### NE555 + przekaźnik

```
   OUT (pin 3) ── [Rb=1k] ── B ── tranzystor NPN (BD139)
                              C ── przekaźnik
                              E ── GND
   + dioda freewheel na cewce
```

### NE555 + opto-triak

Sterowanie 230 V z izolacją. NE555 → MOC3041 → triak BT136.

### Łańcuch dzielników

7555 (CMOS) + 4017 (dekada) — mała pobór, dziesięć wyjść kolejno aktywowanych.

## NE555 a nowoczesne MCU

Pytanie: czemu jeszcze używać NE555 w 2026, kiedy mikrokontroler ATtiny85 lub ESP32 robi to samo i więcej?

**Argumenty za NE555:**
- Brak programowania (analogowa elektronika)
- Wysoka niezawodność
- Tani (~1 zł / sztuka)
- Edukacyjny — uczy podstaw
- Mniej części w prostych aplikacjach
- Brak software bugs

**Argumenty za MCU:**
- Większa elastyczność (zmiana czasów przez kod)
- Dokładność (zegar kwarcowy)
- Wiele funkcji na jednym chipie
- Wbudowany ADC, PWM, UART

Dla **jednego prostego timera** — NE555 bije MCU prostotą. Dla **systemu** — MCU.

## Częste błędy

1. **Brak kondensatora 100 nF na zasilaniu** — niestabilność, drgania.
2. **Otwarty pin 4 (RESET)** — reset szumem, "magiczne" zachowania.
3. **Otwarty pin 5 (CTRL)** — zmienna częstotliwość.
4. **Elektrolit C w astabilnym z plus do GND** — wybuch.
5. **Zbyt mały R (poniżej 1 kΩ)** — duży prąd przez DISCH, grzanie pin 7.
6. **Zbyt duży R (powyżej 10 MΩ)** — niedokładność, wpływ wilgoci na PCB.
7. **Zła obudowa dla NE555 (DIP-8)** — pomyłka pinów. Pin 1 wskazany kropką!
8. **Pomylenie monostabila z astabilem** — różne podłączenia kondensatora.
