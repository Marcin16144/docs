Schematy elektroniczne

25 profesjonalnych wizualizacji SVG zastępujących ASCII art. Symbole IEC, czytelne oznaczenia, pełne podpisy, wartości komponentów.

przewód (sygnał)

masa (GND)
węzeł (połączenie)

Podstawy — proste obwody

LED z rezystorem ograniczającym

Najprostszy obwód. Bez rezystora LED spali się natychmiast.

R = (U − U_F) / I = (9−2)/0,02 = 350 Ω → 330 Ω

Dzielnik napięcia

Dwa rezystory szeregowo dzielą napięcie. Standardowy do ADC, sygnalizacji.

Vout = Vin · R2 / (R1 + R2)

Filtr RC dolnoprzepustowy (LP)

Tłumi częstotliwości powyżej f_c. Filtruje szumy, tętnienia, antyaliasing.

f_c = 1 / (2π·R·C) = 1,59 kHz

Filtr RC górnoprzepustowy (HP)

Tłumi częstotliwości poniżej f_c. Odsprzęganie DC, sygnały audio.

f_c = 1 / (2π·R·C) = 1,59 kHz

Prostowniki

Prostownik półfalowy

Jedna dioda przepuszcza tylko dodatnią połówkę sinusa. Sprawność ~40%.

U_DC = U_m / π ≈ 0,318 · U_m

Mostek Graetza (pełnofalowy)

Cztery diody — obie połówki sinusa idą na plus. Sprawność ~95%, standardowy w zasilaczach.

U_DC ≈ √2 · U_AC − 1,4 V (z filtrem)

Zasilacz: mostek + filtr C

Po prostowniku kondensator wygładza pulsujące DC. Im większy C, tym mniejsze tętnienia.

C ≥ I / (2·f·ΔU) = 2 / (200·1) = 10 mF

Stabilizatory napięcia

Stabilizator 7805

Klasyczny stabilizator stały. Pin: IN-GND-OUT. Wymaga U_in > 7V (dropout 2V).

P_strat = (Vin − 5V) · I_out → potrzebny radiator

LM317 regulowany

Stabilizator 1,25-37V. R2 dobiera napięcie wyjściowe. Idealny do projektów.

Vout = 1,25 · (1 + R2/R1)

LM317 jako źródło prądowe (LED driver)

R_set ustawia stały prąd. Idealne dla LED dużej mocy. I niezależne od V_in.

I = 1,25 / R_set = 1,25/3,6 = 347 mA

Symetryczne zasilanie ±15V

Dwa stabilizatory dla op-ampów audio. UWAGA: 7815 i 7915 mają RÓŻNY pinout!

Trafo z odczepem CT + mostek + 2× stabilizator

Tranzystor jako przełącznik

BJT NPN jako przełącznik (low-side)

Sterowanie LED, przekaźnikiem z pinu MCU. R_B ogranicza prąd bazy.

I_B = (V_MCU − 0,7) / R_B → I_C = β · I_B

MOSFET sterowanie przekaźnikiem

D1 = dioda freewheel (OBOWIĄZKOWA przy cewce). R_pull-down trzyma G w stanie LOW.

Bez D1: spike z cewki zniszczy MOSFET

H-Bridge (mostek H) — silnik DC

4 tranzystory pozwalają obrót w dwie strony. UWAGA: nigdy Q1+Q3 ani Q2+Q4 razem (zwarcie)!

Q1+Q4 = prawo | Q2+Q3 = lewo | Q3+Q4 = hamowanie

NE555

NE555 astabilny (oscylator)

Generuje fale prostokątne. Ra i Rb + C ustalają częstotliwość. Pin 2 (TRIG) i pin 6 (THRESH) zwarte do kondensatora C.

f = 1,44 / ((Ra + 2·Rb) · C) ≈ 1 kHz przy Ra=Rb=4,7k, C=100n

NE555 monostabilny (one-shot)

Pojedynczy impuls po naciśnięciu SW1. Pull-up trzyma TRIG w stanie HIGH; przycisk ściąga do GND → wyzwolenie.

T = 1,1 · R · C = 1,1 · 100k · 10μF = 1,1 s

Wzmacniacze operacyjne

Wzmacniacz nieodwracający

Sygnał wzmocniony bez odwracania. Wysoka impedancja wejściowa, sprzężenie ujemne.

A = 1 + R2/R1 = 11 (sygnał ×11)

Wzmacniacz odwracający

Sygnał wzmocniony i odwrócony (180°). Niska impedancja wejściowa = R1.

A = −Rf/R1 = −10

Wtórnik napięciowy (voltage follower / bufor)

Wzmocnienie ×1, ale wysoka Z_in i niska Z_out. Idealny bufor — najczęstsze użycie op-ampa.

A = 1, Z_in ≈ ∞, Z_out ≈ 0

Komparator z histerezą (Schmitt trigger)

Wyjście HIGH/LOW. Dodatnie sprzężenie zwrotne tworzy histerezę — odporność na szumy.

V_TH ± = Vref ± Vout · R1/(R1+R2)

Sallen-Key — filtr 2. rzędu

Sallen-Key LP (dolnoprzepustowy) 2. rzędu

Filtr aktywny Butterworth. 12 dB/oktawę spadku. Op-amp jako wzmacniacz separujący.

f_c = 1 / (2π·R·√(C1·C2)) ≈ 1 kHz

Wzmacniacz CE (Common Emitter)

Klasyczny preamp z BJT. Sygnał wzmocniony i odwrócony. Dzielnik R1/R2 ustawia punkt pracy.

A = −Rc/Re = −4,7 (z R_E bypass: znacznie więcej)

Transformator + kompletny zasilacz

Kompletny zasilacz sieciowy 230V → 12V / 1,5A

Bezpiecznik → transformator → mostek → filtr C → stabilizator 7812 → wyjście + LED. Klasyczny układ liniowy.

P_strat na 7812 = (17V − 12V) · I_out, wymaga radiatora

Oscylator Wien (sinusoidalny)

Oscylator Wien — generator sinusoidalny

Op-amp + sieć RC (Wien bridge) wytwarzają czysty sinus. Stosowane w audio testowym, generatorach funkcyjnych.

f = 1/(2π·R·C) ≈ 1 kHz. Wzmocnienie pętli = dokładnie 3 (R4 = 2·R3)

Transformator sieciowy — wnętrze

Transformator — wnętrze rdzenia EI

Rdzeń żelazny EI z dwoma uzwojeniami. Pierwotne (N₁, 230V) i wtórne (N₂, 12V). Przekładnia = stosunek zwojów.

U₂/U₁ = N₂/N₁ | I₁/I₂ = N₂/N₁ | P₁ · η = P₂
