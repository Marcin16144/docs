Vue.js 3

Vue 3 + Composition API + Pinia + Vite + Nuxt 3 + Vue Router 4. Stan w 2026: stabilny, dojrzaly, z najlepszym DX sposrod frontend frameworkow.

Czym jest Vue.js?

Vue.js to progressive JavaScript framework do budowania interfejsow uzytkownika. Stworzony przez Evana You (ex-Google, AngularJS) w 2014. W 2026 to trzeci najpopularniejszy framework (po React i Angular w enterprise; przed Svelte).

Glowne zalety Vue 3

  • Najlepszy DX (Developer Experience) sposrod major frameworkow
  • Single File Components (.vue files) — template + script + style w jednym
  • Composition API — funkcjonalne, kompozycyjne, jak React Hooks ale lepsze
  • Reaktywnosc fine-grained — automatyczna, bez manual deps
  • Excellent TypeScript support (od Vue 3, w pelni przepisane w TS)
  • Mniejszy bundle niz React (~34 KB vs ~45 KB)
  • Latwa krzywa uczenia — najprostszy z modern frameworkow
  • Stabilne API — Vue 3 od 2020, niewiele breaking changes
  • Single source of truth dla dokumentacji (vuejs.org)
  • Niezalezne — nie sponsorowane przez Big Tech (Vue Foundation)

Wady Vue.js w 2026

  • Mniejszy ekosystem niz React (mniej bibliotek, mniej job offers w US)
  • Slabsze adoption w dużych USA companies (silny w EU, Azja)
  • Dwie API (Options + Composition) — moga konfundowac juniorow
  • Wyższa rotation w bibliotekach (Vue 2 → 3 wymagal migracji)
  • Mniejsza spolecznosc → mniej Stack Overflow odpowiedzi niz React

Single File Component (.vue)

Vue's killer feature — caly component w jednym pliku z 3 sekcjami:

<!-- src/components/Counter.vue -->
<script setup lang="ts">
import { ref, computed } from 'vue'

// Props (typowane)
const props = defineProps<{
  initial?: number
}>()

// Reactive state
const count = ref(props.initial ?? 0)

// Computed (cached, recomputes only on dep change)
const doubled = computed(() => count.value * 2)

// Methods
function increment() {
  count.value++
}

// Emits (events to parent)
const emit = defineEmits<{
  changed: [value: number]
}>()
</script>

<template>
  <div class="counter">
    <p>Count: {{ count }}</p>
    <p>Doubled: {{ doubled }}</p>
    <button @click="increment">+1</button>
    <button @click="emit('changed', count)">Notify parent</button>
  </div>
</template>

<style scoped>
.counter {
  padding: 1rem;
  border: 1px solid #ccc;
}
button {
  margin: 0 4px;
}
</style>

Trzy sekcje:

  • <script setup> — composition API (recommended), implicit return
  • <template> — HTML z Vue directives ({{ }}, v-if, v-for, @click, :prop)
  • <style scoped> — CSS scoped do tego komponentu (no leak)

Composition API (Vue 3 way)

Reactivity primitives

ref() — dla primitive values

import { ref } from 'vue'

const count = ref(0)
const name = ref('Alice')

// W kodzie: count.value (z .value!)
console.log(count.value)  // 0
count.value++             // 1

// W template: {{ count }} (auto-unwrap, bez .value)

reactive() — dla obiektow

import { reactive } from 'vue'

const user = reactive({
  name: 'Alice',
  age: 30,
  hobbies: ['reading', 'coding']
})

// W kodzie i template: user.name (bez .value)
user.name = 'Bob'
user.hobbies.push('hiking')

// UWAGA: destructuring breaks reactivity!
// const { name } = user  // ❌ name nie jest reactive
// Zamiast: toRefs() lub uzywaj user.name

computed() — derived state z cache

import { ref, computed } from 'vue'

const firstName = ref('Jan')
const lastName = ref('Kowalski')

// Read-only computed
const fullName = computed(() => `${firstName.value} ${lastName.value}`)

// Read-write computed
const nameWritable = computed({
  get: () => `${firstName.value} ${lastName.value}`,
  set: (value: string) => {
    [firstName.value, lastName.value] = value.split(' ')
  }
})

console.log(fullName.value)        // "Jan Kowalski"
nameWritable.value = "Anna Nowak"  // splits and updates

watch() i watchEffect()

import { ref, watch, watchEffect } from 'vue'

const count = ref(0)

// watch — z eksplicitnym source
watch(count, (newVal, oldVal) => {
  console.log(`Count: ${oldVal} → ${newVal}`)
})

// Multiple sources
watch([count, name], ([newCount, newName]) => {
  console.log('Either changed')
})

// Deep watch
watch(user, (newUser) => { ... }, { deep: true })

// Immediate (run once on mount)
watch(count, callback, { immediate: true })

// watchEffect — auto-tracks dependencies
watchEffect(() => {
  console.log(`Count is ${count.value}`)
  // Re-runs whenever count.value changes
})

import {

Composables — reusable logic

Composables to funkcje uzywajace Composition API. Vue equivalent React hooks. Konwencja: prefix use.

// src/composables/useCounter.ts
import { ref, computed } from 'vue'

export function useCounter(initial = 0) {
  const count = ref(initial)
  const doubled = computed(() => count.value * 2)

  function increment() { count.value++ }
  function decrement() { count.value-- }
  function reset() { count.value = initial }

  return {
    count,
    doubled,
    increment,
    decrement,
    reset
  }
}

// Uzycie w komponencie:
<script setup>
import { useCounter } from '@/composables/useCounter'

const { count, doubled, increment } = useCounter(10)
</script>

State management — Pinia

Pinia to oficjalny state manager Vue (zastapil Vuex w 2022). Type-safe, intuitive, modular.

// src/stores/counter.ts
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'

export const useCounterStore = defineStore('counter', () => {
  // State
  const count = ref(0)
  const name = ref('My Counter')

  // Getters (computed)
  const doubled = computed(() => count.value * 2)

  // Actions
  function increment() { count.value++ }
  async function fetchInitial() {
    const data = await fetch('/api/counter').then(r => r.json())
    count.value = data.value
  }

  return { count, name, doubled, increment, fetchInitial }
})

// Uzycie w komponencie:
<script setup>
import { useCounterStore } from '@/stores/counter'
import { storeToRefs } from 'pinia'

const store = useCounterStore()
const { count, doubled } = storeToRefs(store)  // reactive refs
const { increment } = store  // direct method call

await store.fetchInitial()
</script>

<template>
  <p>Count: {{ count }}, Doubled: {{ doubled }}</p>
  <button @click="increment">+1</button>
</template>

import { createRouter, createWebHistory } from 'vue-router'
import HomeView from '@/views/HomeView.vue'

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/', name: 'home', component: HomeView },
    {
      path: '/users/:id',
      name: 'user',
      component: () => import('@/views/UserView.vue')  // lazy load
    },
    {
      path: '/admin',
      component: () => import('@/layouts/AdminLayout.vue'),
      meta: { requiresAuth: true },
      children: [
        { path: 'users', component: AdminUsers },
        { path: 'settings', component: AdminSettings }
      ]
    },
    { path: '/:pathMatch(.*)*', component: NotFound }
  ]
})

// Navigation guard (auth)
router.beforeEach((to, from) => {
  if (to.meta.requiresAuth && !isAuthenticated()) {
    return { name: 'login' }
  }
})

export default router

// MyComponent.test.ts
import { describe, it, expect } from 'vitest'
import { mount } from '@vue/test-utils'
import Counter from './Counter.vue'

describe('Counter', () => {
  it('increments count on click', async () => {
    const wrapper = mount(Counter, { props: { initial: 0 } })

    expect(wrapper.text()).toContain('Count: 0')

    await wrapper.find('button').trigger('click')

    expect(wrapper.text()).toContain('Count: 1')
  })

  it('emits changed event', async () => {
    const wrapper = mount(Counter)
    await wrapper.find('button.notify').trigger('click')

    expect(wrapper.emitted('changed')).toBeTruthy()
    expect(wrapper.emitted('changed')[0]).toEqual([0])
  })
})

TypeScript w Vue 3

Vue 3 jest napisany w TypeScript. Pelne wsparcie:

<script setup lang="ts">
// Typowane props
interface Props {
  user: { id: number; name: string; email: string }
  isAdmin?: boolean
}

const props = withDefaults(defineProps<Props>(), {
  isAdmin: false
})

// Typowane emits
const emit = defineEmits<{
  update: [user: Props['user']]
  delete: [id: number]
}>()

// Typowane refs
const count = ref<number>(0)
const users = ref<Array<{ id: number; name: string }>>([])

// Typowane composables
function useApi<T>(url: string) {
  const data = ref<T | null>(null)
  const loading = ref(false)
  const error = ref<Error | null>(null)

  async function fetchData() {
    loading.value = true
    try {
      const response = await fetch(url)
      data.value = await response.json() as T
    } catch (e) {
      error.value = e as Error
    } finally {
      loading.value = false
    }
  }

  return { data, loading, error, fetchData }
}
</script>
