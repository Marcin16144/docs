Wzorce strukturalne

Adapter, Facade i Decorator — trzy kluczowe wzorce do kompozycji i izolacji klas.

Adapter — opakowywanie zewnetrznych API

Adapter tworzy warstwe posredniczaca, ktora tlumaczy jeden interfejs na drugi. Dzieki temu wymiana dostawcy (np. z SendGrid na AWS SES) wymaga tylko nowego adaptera, bez zmian w reszcie kodu.

// Twoj wewnetrzny interfejs
interface EmailService {
    send(to: string, subject: string, body: string): Promise<void>;
    sendBulk(messages: EmailMessage[]): Promise<BulkResult>;
}

// Zewnetrzne API (SendGrid) — inny ksztalt interfejsu
class SendGridClient {
    sendMail(params: {
        to: { email: string }[];
        subject: string;
        content: { type: string; value: string }[];
    }): Promise<SendGridResponse> { /* ... */ }
}

// Adapter tlumaczy Twoj interfejs na API SendGrid
class SendGridAdapter implements EmailService {
    constructor(private client: SendGridClient) {}

    async send(to: string, subject: string, body: string): Promise<void> {
        await this.client.sendMail({
            to: [{ email: to }],
            subject,
            content: [{ type: 'text/html', value: body }],
        });
    }

    async sendBulk(messages: EmailMessage[]): Promise<BulkResult> {
        const results = await Promise.allSettled(
            messages.map(msg =>
                this.client.sendMail({
                    to: [{ email: msg.to }],
                    subject: msg.subject,
                    content: [{ type: 'text/html', value: msg.body }],
                })
            )
        );
        return {
            sent: results.filter(r => r.status === 'fulfilled').length,
            failed: results.filter(r => r.status === 'rejected').length,
        };
    }
}

Facade — upraszczanie podsystemow

Facade zapewnia uproszczony interfejs do zlozonego podsystemu. Nie ukrywa podsystemu — nadal mozna korzystac z poszczegolnych klas bezposrednio — ale oferuje wygodny skrot dla typowych operacji.

// Zlozony podsystem zamowien (4 serwisy, kazdy z wlasnym API)
class InventoryService { /* checkStock, reserveStock, releaseReservation */ }
class PricingService   { /* calculatePrice, applyDiscount */ }
class PaymentService   { /* authorize, capture, void */ }
class ShippingService  { /* calculateShipping, createShipment */ }

// Facade — uproszczony interfejs
class OrderFacade {
    constructor(
        private inventory: InventoryService,
        private pricing: PricingService,
        private payment: PaymentService,
        private shipping: ShippingService,
    ) {}

    async placeOrder(request: PlaceOrderRequest): Promise<OrderResult> {
        // 1. Sprawdz dostepnosc
        for (const item of request.items) {
            const stock = await this.inventory.checkStock(item.productId);
            if (stock < item.quantity)
                throw new InsufficientStockError(item.productId);
        }

        // 2. Rezerwuj towary
        const reservations = [];
        for (const item of request.items) {
            const resId = await this.inventory.reserveStock(
                item.productId, item.quantity
            );
            reservations.push(resId);
        }

        try {
            // 3. Oblicz cene
            let price = await this.pricing.calculatePrice(request.items);
            if (request.discountCode) {
                price = await this.pricing.applyDiscount(
                    request.discountCode, price
                );
            }

            // 4. Autoryzuj i potwierdz platnosc
            const auth = await this.payment.authorize(
                price.total, request.paymentMethod
            );
            await this.payment.capture(auth.authorizationId);

            return { orderId: generateOrderId(), total: price.total };
        } catch (error) {
            // Cofnij rezerwacje w razie bledu
            for (const resId of reservations) {
                await this.inventory.releaseReservation(resId);
            }
            throw error;
        }
    }
}

Decorator — lancuchy middleware

Decorator opakowuje obiekt implementujac ten sam interfejs i delegujac wywolanie do opakowywanego obiektu, dodajac wlasne zachowanie przed lub po.

// Bazowy interfejs
interface HttpClient {
    request(config: RequestConfig): Promise<Response>;
}

// Podstawowa implementacja
class FetchHttpClient implements HttpClient {
    async request(config: RequestConfig): Promise<Response> {
        return fetch(config.url, {
            method: config.method,
            headers: config.headers,
            body: config.body,
        });
    }
}

// Decorator: logowanie
class LoggingHttpClient implements HttpClient {
    constructor(private inner: HttpClient) {}

    async request(config: RequestConfig): Promise<Response> {
        console.log(`-> ${config.method} ${config.url}`);
        const start = Date.now();
        const response = await this.inner.request(config);
        console.log(`<- ${response.status} (${Date.now() - start}ms)`);
        return response;
    }
}

// Decorator: retry z exponential backoff
class RetryHttpClient implements HttpClient {
    constructor(private inner: HttpClient, private maxRetries = 3) {}

    async request(config: RequestConfig): Promise<Response> {
        let lastError: Error;
        for (let attempt = 0; attempt <= this.maxRetries; attempt++) {
            try {
                return await this.inner.request(config);
            } catch (error) {
                lastError = error as Error;
                if (attempt < this.maxRetries) {
                    await new Promise(r =>
                        setTimeout(r, Math.pow(2, attempt) * 1000)
                    );
                }
            }
        }
        throw lastError!;
    }
}

// Decorator: cache dla GET
class CachingHttpClient implements HttpClient {
    private cache = new Map<string, { response: Response; expires: number }>();

    constructor(private inner: HttpClient, private ttlMs = 60000) {}

    async request(config: RequestConfig): Promise<Response> {
        if (config.method !== 'GET') return this.inner.request(config);

        const cached = this.cache.get(config.url);
        if (cached && cached.expires > Date.now()) {
            return cached.response.clone();
        }
        const response = await this.inner.request(config);
        this.cache.set(config.url, {
            response: response.clone(),
            expires: Date.now() + this.ttlMs,
        });
        return response;
    }
}

Kompozycja dekoratorow

Sila wzorca lezy w komponowaniu — kazdy dekorator dodaje jedna odpowiedzialnosc, a lancuch mozna skladac dowolnie.

// Skladanie lancucha dekoratorow
const httpClient: HttpClient =
    new LoggingHttpClient(           // 3. Loguj request/response
        new RetryHttpClient(          // 2. Ponow w razie bledu
            new CachingHttpClient(    // 1. Sprawdz cache
                new FetchHttpClient() // 0. Wykonaj request
            ),
            3
        )
    );

// Kolejnosc ma znaczenie!
// Logging -> Retry -> Cache -> Fetch

Kiedy stosowac ktory wzorzec?

  • Adapter — gdy integrujesz sie z zewnetrznym API/biblioteka i chcesz odizolowac swoj kod od jej interfejsu
  • Facade — gdy podsystem jest zlozony i klienci potrzebuja prostego API dla typowych operacji
  • Decorator — gdy chcesz dynamicznie dodawac cross-cutting concerns (logowanie, cache, retry, metryki) bez modyfikacji istniejacego kodu
