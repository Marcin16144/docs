EFFECTS — przetwarzanie audio

1. Dynamics — kontrola dynamiki sygnalu

Funkcje:

  • Compressor — redukuje dynamike (glosne ciszej, ciche glosniej)
  • Limiter — twardy plafon (brick-wall, np. dla mastering)
  • Gate / Expander — wycina ciche dzwieki (np. tlo)
  • De-esser — redukuje sybilanty (s, sz, s) w wokalu
  • Multiband compressor — kompresja per pasmo czestotliwosci
  • Sidechain compressor — kompresja sterowana z innego zrodla (klasyczny "pumping" w EDM)
  • Transient shaper — wzmacnia/redukuje transients (atak/sustain)
  • Upward compressor — wzmacnia ciche fragmenty zamiast tlumic glosne

Kluczowe parametry: Threshold, Ratio, Attack, Release, Knee, Makeup gain, Lookahead, Detection mode (peak vs RMS)

Open-source (komercja-friendly): chowdsp_utils (BSD) — chowdsp::compressor, STK (permisywna), DSP textbook implementations.

class SimpleCompressor {
    float threshold_dB = -20.0f;
    float ratio = 4.0f;
    float envelope = 0.0f;

public:
    float process(float input) {
        float inputDB = 20.0f * std::log10(std::abs(input) + 1e-10f);
        float overshoot = std::max(0.0f, inputDB - threshold_dB);
        float reduction = overshoot * (1.0f - 1.0f/ratio);

        // Smooth envelope
        float coef = (reduction > envelope) ? attackCoef : releaseCoef;
        envelope = coef * envelope + (1.0f - coef) * reduction;

        float gain = std::pow(10.0f, -envelope / 20.0f);
        return input * gain;
    }
};

2. EQ / Filter — kontrola czestotliwosci

Funkcje:

  • Parametric EQ — dowolne pasma (freq/gain/Q)
  • Graphic EQ — stale pasma z faderami
  • HP / LP / BP / Notch — filtry
  • Shelf (high/low) — wzmocnienie/tlumienie powyzej/ponizej
  • Linear-phase EQ — bez przesuniecia fazy (mastering)
  • Dynamic EQ — EQ + compressor w jednym
  • Pitch-tracking EQ — pasma podazaja za nutami
  • Mid/Side EQ — osobno dla srodka i strony stereo
  • Match EQ — kopiuje krzywa EQ z innego sygnalu
  • Vintage emulation — modeling klasycznych EQ (Pultec, Neve, API, SSL)

Typy filtrow: IIR (Biquad), FIR (linear phase), State Variable Filter (SVF), Moog ladder

Open-source: chowdsp_utils (BSD), Q DSP Library (MIT), STK (permisywna)

3. Time-based effects — opoznienia i odbicia

Funkcje delay / echo:

  • Tape delay (z modulacja + tape saturation)
  • Digital delay (czysty, precyzyjny)
  • Analog/BBD delay (cieply, lo-fi)
  • Ping-pong delay (skacze L/R)
  • Multi-tap delay (wiele opoznien)
  • Tempo-synced delay (BPM-aware)
  • Reverse delay
  • Ducking delay (cichszy gdy zrodlo glosne)

Funkcje reverb:

  • Room/Hall/Plate/Chamber (algorithmic)
  • Convolution reverb (impulse response — symulacja realnych miejsc)
  • Spring reverb (gitarowy, lo-fi)
  • Shimmer reverb (z pitch-shift)
  • Gated reverb (hard cutoff — 80s drums)
  • Reverse reverb

Parametry reverb: Decay/RT60, Pre-delay, Damping (HF/LF), Diffusion, Modulation, Wet/dry

Typy convolution: Direct (male IR), Partitioned (low latency), FFT-based (najszybsze)

Open-source: Argotlunar (MIT) granular delay, Soundpipe (MIT), chowdsp_utils (BSD)

4. Modulation effects

  • Chorus — kopia sygnalu z modulowanym opoznieniem (pogrubia)
  • Flanger — bardzo krotkie opoznienie + modulacja (jet sound)
  • Phaser — zmienne all-pass filtry (sweepy notch)
  • Tremolo — modulacja amplitudy
  • Vibrato — modulacja pitch (rozni sie od tremolo!)
  • Auto-pan — modulacja pozycji stereo
  • Rotary speaker — symulacja Leslie (organy)
  • Ensemble — wzmocniony chorus (string synths)
  • Auto-wah — modulowany band-pass
  • Frequency shifter — przesuniecie pasma (ring mod-like)

Komponenty: LFO (sine, triangle, square, S/H), Envelope follower, Tempo-sync vs free, Stereo offset

5. Distortion / Saturation

  • Overdrive — lagodne, soft clipping (gitara blues/rock)
  • Distortion — twardsze, mocniejsze
  • Fuzz — square wave-like, ekstremalne
  • Bit crusher — redukcja rozdzielczosci bitowej (lo-fi)
  • Sample rate reducer — aliasing, downsampling
  • Tape saturation — analog warmth
  • Tube saturation — emulacja lampowych preampow
  • Transformer saturation — soft compression + harmonics
  • Multi-band saturation — rozne ilosci w roznych pasmach
  • Wave shaper — dowolna funkcja transferu
  • Hard / Soft clipping

Anti-aliasing (kluczowe!): Distortion tworzy aliasing → trzeba oversampling (2x, 4x, 8x).

Open-source: RTNeural (BSD) — neural amp simulation, chowdsp_utils oversampling helpers

6. Pitch processing

  • Pitch correction / Auto-Tune — automatyczna korekcja pitch wokalu
  • Harmonizer — generuje harmonie powyzej/ponizej
  • Octaver — dodaje oktawy
  • Pitch shifter — zmiana pitch o stala wartosc
  • Time stretching — zmiana tempa bez zmiany pitch
  • Formant shifting — zmiana brzmienia ("kobieta → mezczyzna")
  • Vocoder — analiza pitch + synteza (robotic voice)
  • Talk box — rezonatory pitch-tracked

Algorytmy pitch shifting: PSOLA, Phase Vocoder (FFT), Granular pitch shifting

Algorytmy pitch detection: Autocorrelation, YIN, CREPE (deep learning), Cepstrum

Komercja-friendly: wlasna implementacja PSOLA/PV, STK, Soundpipe (MIT)

Pulapki GPL: RubberBand (GPL), SoundTouch (LGPL — dynamic OK)

7. Spatial / Stereo

  • Stereo widener — szerokosc obrazu (Haas effect, M/S)
  • Mono → Stereo — pseudo-stereo z mono zrodla
  • Panner — pozycja w stereo (constant power, linear)
  • Auto-panner — modulacja pozycji
  • 3D / Surround panner — 5.1, 7.1, Atmos
  • Binaural (HRTF) — realistyczne 3D w sluchawkach
  • Ambisonics — 360 sound (VR/AR)
  • Mid/Side encoder/decoder
  • Goniometer / phase scope — wizualizacja stereo

Open-source: HRTF databases (CIPIC public domain), IEM Plug-in Suite (BSD)

8. Special / Creative

  • Vocoder — synteza z analizy spektralnej
  • Talkbox — formanty z mowy
  • Freeze / Hold — zatrzymuje sygnal w petli
  • Spectral processing — modyfikacja w domenie czestotliwosci
  • Spectral gate / compressor — per FFT bin
  • Resynthesis — analiza + ponowna synteza
  • Glitch effect — random retrigger, beat repeat
  • Granular effect — dzielenie na ziarna
  • AI-based effects (2026):
    • Source separation (vocal + instrumental z miksu)
    • Noise removal (NVIDIA RTX Voice-style)
    • Real-time amp simulation (NAM, AIDA-X)
    • Mastering AI (LANDR-style)

INSTRUMENTS — generowanie dzwieku z MIDI

Typy syntezy

1. Subtractive synthesis (klasyczny analog)

Generujesz harmoniczny sygnal (saw, square) i odejmujesz frequencies filtrami.

Oscillator (rich harmonic)
      ↓
Filter (LP/HP/BP, resonance)
      ↓
VCA (volume envelope)
      ↓
Output

Slynne: Moog, Roland Juno/Jupiter, Korg MS-20, Prophet

Komercja-friendly: zbuduj samemu z STK (BSD), Soundpipe (MIT)

2. FM (Frequency Modulation) synthesis

Modulujesz pitch jednego oscillatora innym → kompleksowe spektrum.

Slynne: Yamaha DX7 (1983), Native Instruments FM8

Komercja-friendly: zaimplementuj sam — algorytmy FM sa w domenie publicznej

3. Additive synthesis

Sumujesz wiele sinusow z roznymi czestotliwosciami i amplitudami.

Slynne: Hammond organy, Kawai K5

4. Wavetable synthesis

Odtwarzasz cykliczne tablice probek, interpolujesz miedzy nimi.

Slynne: PPG Wave (1981), Massive, Serum, Vital

Komercja-friendly: wlasna implementacja + wavetables z permissive licenses

5. Granular synthesis

Dzielisz sample na male "ziarna" (5-100ms) i odtwarzasz w roznych pozycjach/pitch.

Open-source: Soundpipe (MIT) zawiera granular primitives

6. Physical modeling

Symulacja fizyki instrumentu (struny, rezonatory, smyczki).

Slynne: Yamaha VL1, Modartt Pianoteq

Open-source: STK (permisywna) — Karplus-Strong strings, modal synthesis. Faust — physmodels.lib

7. Sample-based / Rompler

Odtwarza nagrane probki (multi-sampled instrument).

Slynne: Kontakt, Sampler libraries

8. Hybrid synthesis

Laczenie powyzszych — np. wavetable oscillators + analog filters + samples.

MIDI EFFECTS — przetwarzanie MIDI

  • Arpeggiator — z akordu generuje arpeggio (pattern, rate, octaves)
  • Chord generator — z 1 noty robi akord
  • Strum — symulacja gitarowego strum
  • Scale snapping — kwantyzuje noty do skali
  • Velocity randomization — humanization
  • Note repeater — buzz/roll efekty
  • Pattern sequencer — wbudowany step sequencer
  • MIDI quantizer — wyrownanie do siatki tempa
  • Humanizer — random offsets dla naturalnego brzmienia
  • MIDI transformer — replace notes, change channels

ANALYZERS — wizualizacja

  • Spectrum analyzer — FFT-based
  • Real-time peak meter — VU, peak, RMS
  • Loudness meter — LUFS (integrated/short-term/momentary). Standardy: EBU R128, ATSC A/85
  • Phase correlation meter — czy stereo jest mono-compatible
  • Goniometer / vector scope — wizualizacja stereo image
  • Spectrogram — czestotliwosc w czasie (waterfall)
  • Tuner — pokazuje pitch
  • Oscilloscope — sygnal w czasie

Open-source: KissFFT (BSD), PocketFFT (BSD), libebur128 (MIT) dla loudness

Mixing i mastering specific

Mixing tools

  • Bus compressor — VCA-style (SSL G-bus, API 2500)
  • Mid/Side processor — separacja srodka/strony
  • Crossover — multi-band split (Linkwitz-Riley)
  • Sidechain processor — ducking, gating

Mastering tools

  • Linear-phase EQ — surgical without phase artifacts
  • Multiband compressor — kontrola dynamiki per pasmo
  • Maximizer / brick-wall limiter — final loudness boost
  • Stereo imager — manipulation szerokosci
  • Loudness normalizer — LUFS targeting
  • Dithering — przy redukcji bit-depth
  • Truepeak limiter — z oversampling, anti-clipping

Praktyczna rada — Twoja sciezka

Zacznij od prostego. Twoj pierwszy plugin to nie powinien byc "Vital killer". Zacznij od:

  1. Volume + Mute (godziny — naucz sie frameworka)
  2. Tremolo (LFO + amplitude — 1-2 dni)
  3. Delay (circular buffer — 3-5 dni)
  4. Biquad EQ (1 tydzien — fundament)
  5. Chorus (delay + LFO — 1 tydzien)
  6. Compressor (envelope follower — 2 tygodnie)
  7. Reverb (algorithmic — 2-4 tygodnie)

Kazdy z tych moze byc commercial product jesli wystarczajaco dobrze zrobiony. Lepiej idealny limiter niz przecietny synth.
