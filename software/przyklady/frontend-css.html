3. Card produktu — Vanilla CSS (CSS Custom Properties + container queries)

<style>
:root {
    --surface: white;
    --text: #1e293b;
    --muted: #64748b;
    --primary: #2563eb;
    --primary-hover: #1d4ed8;
    --radius: 12px;
    --shadow: 0 10px 25px rgb(0 0 0 / .1);
}
@media (prefers-color-scheme: dark) {
    :root { --surface: #1e293b; --text: #f1f5f9; }
}

.product-card {
    container-type: inline-size;
    max-width: 24rem;
    background: var(--surface);
    border-radius: var(--radius);
    box-shadow: var(--shadow);
    overflow: hidden;
    transition: transform .2s;
}
.product-card:hover { transform: translateY(-4px); }
.product-card img { width: 100%; height: 12rem; object-fit: cover; }
.product-card__body { padding: 1.5rem; }
.product-card__title { font-weight: 700; font-size: 1.25rem; color: var(--text); }
.product-card__desc { color: var(--muted); font-size: .875rem; margin: .5rem 0 1rem; }
.btn-primary {
    padding: .5rem 1rem;
    background: var(--primary);
    color: white;
    border: none;
    border-radius: .5rem;
    cursor: pointer;
    transition: background .15s;
}
.btn-primary:hover { background: var(--primary-hover); }

/* Container query: zmień layout gdy karta jest wąska */
@container (max-width: 280px) {
    .product-card__body { padding: 1rem; }
    .product-card__title { font-size: 1rem; }
}
</style>

<article class="product-card">
    <img src="product.jpg" alt="Produkt">
    <div class="product-card__body">
        <h3 class="product-card__title">Mechaniczna klawiatura</h3>
        <p class="product-card__desc">Switche brązowe, RGB, USB-C, layout PL.</p>
        <button class="btn-primary">Do koszyka</button>
    </div>
</article>
💡 Container queries (@container) wreszcie działają we wszystkich nowoczesnych przeglądarkach (od 2023). Lepsze niż media queries dla komponentów.

4. Modal — bez JS! (HTML <dialog>)

<button onclick="myDialog.showModal()">Otwórz</button>

<dialog id="myDialog" class="backdrop:bg-black/50 rounded-xl shadow-2xl p-0">
    <form method="dialog" class="p-6 w-96">
        <h2 class="text-xl font-bold mb-4">Potwierdź akcję</h2>
        <p class="mb-6 text-slate-600">Czy na pewno chcesz usunąć ten element?</p>
        <div class="flex gap-2 justify-end">
            <button value="cancel" class="px-4 py-2 border rounded">Anuluj</button>
            <button value="confirm" class="px-4 py-2 bg-red-600 text-white rounded">Usuń</button>
        </div>
    </form>
</dialog>
📝 <dialog> automatycznie obsługuje: Escape (zamyka), focus trap, backdrop, klawiaturę. Zapomnij o React modal libs.

5. Grid layout — responsive bez media queries

/* Auto-fill: tyle kolumn ile się zmieści, każda min. 250px */
.gallery {
    display: grid;
    grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
    gap: 1rem;
}

/* CSS Subgrid — wyrównanie wewnętrznych kolumn między kartami */
.cards {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
    gap: 1rem;
}
.card {
    display: grid;
    grid-template-rows: subgrid;
    grid-row: span 3;
}
