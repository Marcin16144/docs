🪟 IIS i Windows Server — gotowe konfiguracje

Reverse proxy z ARR, FastCGI dla PHP, Let's Encrypt przez win-acme, hardening TLS.

1. Instalacja IIS + Application Request Routing (PowerShell)

# Windows Server 2025
Install-WindowsFeature -Name Web-Server -IncludeManagementTools
Install-WindowsFeature -Name Web-Asp-Net45, Web-Net-Ext45

# URL Rewrite + ARR (z chocolatey)
choco install urlrewrite -y
choco install iis-arr -y

# Włącz proxy globalnie
Import-Module WebAdministration
Set-WebConfigurationProperty -Filter "system.webServer/proxy" `
    -Name "enabled" -Value $true -PSPath IIS:\

2. Reverse proxy do Node.js / .NET Core (web.config)

<?xml version="1.0" encoding="UTF-8"?>
<configuration>
  <system.webServer>
    <rewrite>
      <rules>
        <rule name="ReverseProxyToKestrel" stopProcessing="true">
          <match url="(.*)" />
          <action type="Rewrite" url="http://localhost:5000/{R:1}" />
          <serverVariables>
            <set name="HTTP_X_FORWARDED_FOR" value="{REMOTE_ADDR}" />
            <set name="HTTP_X_FORWARDED_PROTO" value="https" />
            <set name="HTTP_X_FORWARDED_HOST" value="{HTTP_HOST}" />
          </serverVariables>
        </rule>
      </rules>
    </rewrite>

    <!-- HTTPS redirect -->
    <rewrite>
      <rules>
        <rule name="HTTPS" stopProcessing="true">
          <match url="(.*)" />
          <conditions>
            <add input="{HTTPS}" pattern="off" />
          </conditions>
          <action type="Redirect" url="https://{HTTP_HOST}/{R:1}" redirectType="Permanent" />
        </rule>
      </rules>
    </rewrite>

    <!-- Security headers -->
    <httpProtocol>
      <customHeaders>
        <add name="Strict-Transport-Security" value="max-age=63072000; includeSubDomains; preload" />
        <add name="X-Content-Type-Options" value="nosniff" />
        <add name="X-Frame-Options" value="DENY" />
        <add name="Referrer-Policy" value="strict-origin-when-cross-origin" />
        <remove name="X-Powered-By" />
      </customHeaders>
    </httpProtocol>
  </system.webServer>
</configuration>

3. FastCGI dla PHP 8.4

# Pobierz PHP 8.4 Non-Thread Safe x64 z windows.php.net
Expand-Archive -Path php-8.4.0-nts-Win32-vs17-x64.zip -DestinationPath C:\php

# php.ini — minimalna konfiguracja
Copy-Item C:\php\php.ini-production C:\php\php.ini
# Edytuj: extension_dir, fastcgi.impersonate=1, cgi.fix_pathinfo=0

# Zarejestruj w IIS FastCGI
Add-WebConfiguration -Filter "/system.webServer/fastCgi" -Value @{
    fullPath = "C:\php\php-cgi.exe"
    arguments = ""
    maxInstances = 0      # auto-scale
    idleTimeout = 300
    activityTimeout = 30
    requestTimeout = 90
    instanceMaxRequests = 10000  # recycle
    protocol = "NamedPipe"
}

# Mapowanie .php → FastCGI
New-WebHandler -Name "PHP-FastCGI" -Path "*.php" -Verb "*" `
    -Modules FastCgiModule -ScriptProcessor "C:\php\php-cgi.exe" `
    -ResourceType Either

4. Let's Encrypt — win-acme (wacs)

# Pobierz win-acme z github.com/win-acme/win-acme/releases
# Uruchom jako Administrator
.\wacs.exe

# Interaktywnie:
#  N — create certificate
#  1 — read bindings from IIS
#  Wybierz site, potwierdź email, accept TOS

# Albo bezobsługowo (CI/CD)
.\wacs.exe --target iis --siteid 1 --installation iis --emailaddress admin@example.com `
    --accepttos --usedefaulttaskuser

# Auto-renewal jest dodawany jako scheduled task — sprawdź:
Get-ScheduledTask -TaskName "win-acme renew*"
💡 win-acme jest darmowy i robi auto-renewal co 60 dni. Lepszy niż płatne narzędzia w 95% przypadków.

5. Hardening TLS (IIS Crypto przez PowerShell)

# Wyłącz stare protokoły (Schannel)
function Disable-Protocol {
    param([string]$Protocol)
    $base = "HKLM:\SYSTEM\CurrentControlSet\Control\SecurityProviders\SCHANNEL\Protocols\$Protocol"
    foreach ($role in "Client", "Server") {
        $path = "$base\$role"
        if (!(Test-Path $path)) { New-Item -Path $path -Force | Out-Null }
        New-ItemProperty -Path $path -Name "Enabled" -Value 0 -PropertyType DWord -Force | Out-Null
        New-ItemProperty -Path $path -Name "DisabledByDefault" -Value 1 -PropertyType DWord -Force | Out-Null
    }
}

foreach ($p in "SSL 2.0", "SSL 3.0", "TLS 1.0", "TLS 1.1") {
    Disable-Protocol $p
}

# Wymuś TLS 1.3 + TLS 1.2 (TLS 1.3 wymaga Win Server 2022+)
foreach ($p in "TLS 1.2", "TLS 1.3") {
    $base = "HKLM:\SYSTEM\CurrentControlSet\Control\SecurityProviders\SCHANNEL\Protocols\$p"
    foreach ($role in "Client", "Server") {
        $path = "$base\$role"
        if (!(Test-Path $path)) { New-Item -Path $path -Force | Out-Null }
        New-ItemProperty -Path $path -Name "Enabled" -Value 1 -PropertyType DWord -Force
        New-ItemProperty -Path $path -Name "DisabledByDefault" -Value 0 -PropertyType DWord -Force
    }
}

Restart-Computer  # wymagane

6. Application Pool — recycle + identity

# Utwórz app pool
New-WebAppPool -Name "MyAppPool"

# Recycle co noc
Set-ItemProperty -Path "IIS:\AppPools\MyAppPool" `
    -Name recycling.periodicRestart.schedule -Value @{value="03:00:00"}

# Bez recyklingu po zmianie pamięci (tylko po czasie)
Set-ItemProperty -Path "IIS:\AppPools\MyAppPool" `
    -Name recycling.periodicRestart.memory -Value 0
Set-ItemProperty -Path "IIS:\AppPools\MyAppPool" `
    -Name recycling.periodicRestart.privateMemory -Value 0

# Dedykowany użytkownik (zamiast ApplicationPoolIdentity)
Set-ItemProperty -Path "IIS:\AppPools\MyAppPool" `
    -Name processModel -Value @{
        identityType = "SpecificUser"
        userName = "DOMAIN\svc-myapp"
        password = "REDACTED"
    }

# Always-running (dla Node/Core, by nie czekać 10s na pierwszy request)
Set-ItemProperty -Path "IIS:\AppPools\MyAppPool" `
    -Name startMode -Value "AlwaysRunning"
