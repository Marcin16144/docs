📦 Git — workflow i ratunki

Konkretne komendy do codziennej pracy + jak wyjść z opresji.

1. Codzienne komendy

# Stan repo
git status -sb                          # krótki przegląd
git log --oneline --graph --all -20     # wizualny log
git diff                                # niezacommitowane
git diff --staged                       # zacommitowane do staging

# Commit z poprawnym formatem (Conventional Commits)
git add -p                              # interaktywnie wybierz hunks
git commit -m "feat(auth): add refresh token rotation"
git commit -m "fix(api): handle null email in signup"
git commit -m "refactor(db): extract repository pattern"

# Push z trackingiem nowego brancha
git push -u origin feature/refresh-tokens

# Synchronizacja z main
git fetch origin
git rebase origin/main                  # preferuj rebase dla feature branch
# lub: git merge origin/main

2. Interactive rebase — czyszczenie historii

# Złącz/zmień ostatnie 5 commitów
git rebase -i HEAD~5

# W edytorze pojawi się:
# pick a1b2c3 WIP first commit
# pick d4e5f6 WIP add validation
# pick g7h8i9 WIP fix typo
#
# Zmień na:
# pick a1b2c3 feat: add signup endpoint
# squash d4e5f6 WIP add validation
# fixup g7h8i9 WIP fix typo
⚠️ Nie rebasuj branchy, na których pracują inni — przepisuje historię. Wyjątek: --force-with-lease po koordynacji.

3. Cherry-pick — wybiórczy commit

# Skopiuj jeden commit z innego brancha
git cherry-pick a1b2c3d

# Kilka pod rząd
git cherry-pick a1b2c3d..f7e8d9c

# Bez auto-commit (tylko stage)
git cherry-pick -n a1b2c3d

4. Ratunki — kiedy coś się popsuło

# ❌ "Zrobiłem commit nie na tej gałęzi"
git log --oneline -1                  # zapamiętaj hash
git reset --hard HEAD~1              # cofnij commit (TYLKO LOKALNIE)
git checkout poprawny-branch
git cherry-pick <hash>

# ❌ "Usunąłem branch z niezmergowaną pracą"
git reflog                              # znajdź ostatni HEAD na tym branchu
git checkout -b ratunek <hash z reflog>

# ❌ "git push --force usunął moje zmiany!" (z remote)
git fetch origin
git reflog show origin/main             # lokalny ślad poprzedniej HEAD
git reset --hard <poprzedni hash>
git push --force-with-lease origin main

# ❌ "Zacommituj zmiany do złego brancha (lokalnie)"
git reset --soft HEAD~1              # wraca pliki do staging
git stash
git checkout poprawny-branch
git stash pop
git commit -m "..."

# ❌ "Niechcąco git add & commit poufnego pliku"
git rm --cached secrets.env
echo "secrets.env" >> .gitignore
git commit -m "chore: remove secrets from repo"
# Jeśli już pushnięte: użyj git-filter-repo i obróć klucze!

5. Bisect — binary search w historii

# Znajdź który commit popsuł testy
git bisect start
git bisect bad HEAD                     # tu jest błąd
git bisect good v1.0.0                 # wcześniej działało

# Git wybiera środkowy commit. Testujesz, oznaczasz:
npm test && git bisect good || git bisect bad

# Albo zautomatyzuj:
git bisect run npm test

# Gdy znaleziono:
git bisect reset

6. Worktree — równoległa praca

# Drugi katalog z innym branchem (bez clonowania!)
git worktree add ../app-hotfix hotfix/critical-bug
cd ../app-hotfix
# pracujesz, commitujesz, pushujesz

# Lista worktrees
git worktree list

# Sprzątanie
git worktree remove ../app-hotfix
💡 Idealne gdy: review PR-a kolegi gdy sam piszesz feature, hotfix bez stashowania pracy.

7. Hooks — automatyzacja

# .git/hooks/pre-commit (po chmod +x)
#!/usr/bin/env bash
set -e
npm run lint
npm run typecheck
npm test -- --bail

# Lepsza opcja — husky (dystrybuujesz hooki przez repo)
npm i -D husky lint-staged
npx husky init
echo "npx lint-staged" > .husky/pre-commit

# package.json:
"lint-staged": {
    "*.{ts,tsx}": ["eslint --fix", "prettier --write"],
    "*.md": ["prettier --write"]
}

9. Komendy, które warto znać

# Kto napisał daną linię i kiedy
git blame -L 42,50 src/api.ts

# Wszystkie commity dotykające pliku
git log --follow -p src/auth.ts

# Szukaj tekstu w historii
git log -S "deprecatedFunction" --oneline

# Statystyki commitów
git shortlog -sn --since="1 month ago"

# Rozmiar repozytorium
git count-objects -vH
git gc --aggressive --prune=now
