Vue.js 3

Progressive JavaScript framework — Composition API, Pinia state, Nuxt SSR

Co to Vue.js?

Vue.js to progressive framework do budowy interfejsow uzytkownika, stworzony przez Evan You w 2014. "Progressive" oznacza, ze mozesz uzywac od bardzo prostych przypadkow (skrypt z CDN) az do pelnych SPA i SSR aplikacji. W 2026 stabilna wersja to Vue 3 z Composition API, ktora unifikuje styl pisania komponentow z React Hooks.

Vue znajduje sie na trzecim miejscu pod wzgledem popularnosci wsrod frameworkow JS (po React i Angular). W Chinach jest #1, na zachodzie traci do React. Mocno oslawiony za swoja prostote skladniowa i swietna dokumentacje.

Kluczowe cechy

  • Composition API (Vue 3) — setup() function z reactive primitives
  • SFC (Single File Components) — .vue z <script>, <template>, <style> w jednym pliku
  • Reactive system — ref(), reactive(), computed(), watch()
  • Built-in directives — v-if, v-for, v-model, v-on
  • Pinia — oficjalna biblioteka state management (zastapila Vuex)
  • Vue Router — oficjalny routing
  • Nuxt — meta-framework dla SSR/SSG (jak Next.js)
  • TypeScript-first w Vue 3

Instalacja

# Vite + Vue + TS
npm create vue@latest my-app
cd my-app
npm install
npm run dev

# Z Nuxt
npx nuxi@latest init my-app

Pierwszy komponent

<!-- App.vue -->
<script setup lang="ts">
import { ref, computed } from 'vue';

const count = ref(0);
const doubled = computed(() => count.value * 2);

const increment = () => count.value++;
</script>

<template>
  <div>
    <h1>Count: {{ count }}</h1>
    <p>Doubled: {{ doubled }}</p>
    <button @click="increment">+</button>
  </div>
</template>

<style scoped>
button { padding: 8px 16px; }
</style>

State management — Pinia

// stores/counter.ts
import { defineStore } from 'pinia';

export const useCounterStore = defineStore('counter', {
  state: () => ({ count: 0 }),
  getters: {
    doubled: (state) => state.count * 2
  },
  actions: {
    increment() { this.count++; }
  }
});

// W komponencie
const counter = useCounterStore();
counter.increment();

Nuxt — meta-framework

Nuxt 3 to dla Vue tym, czym Next.js dla React. Dostarcza:

  • SSR (Server-Side Rendering)
  • SSG (Static Site Generation)
  • File-based routing
  • Auto-imports komponentow i composables
  • Nitro — uniwersalny server (Node, Vercel, Cloudflare Workers)
  • Module ecosystem (auth, content, image, etc.)

Kiedy uzyc Vue?

  • Pierwszy framework JS — ma niska bariere wejscia
  • Aplikacje gdzie wolisz declarative templates niz JSX
  • Zespol z preferencja "wszystko w jednym pliku" (SFC)
  • Migracja z jQuery / Vanilla — Vue mozna progressively dodawac
  • Chinski rynek — Vue dominuje

Komponenty UI

  • Vuetify — Material Design
  • Quasar — cross-platform (web, mobile, desktop)
  • Element Plus — Chinese popular
  • PrimeVue — bogaty zestaw komponentow
  • Nuxt UI — Tailwind-based, oficjalne dla Nuxt
  • shadcn-vue — port shadcn/ui na Vue
