Angular 18+

Pelen framework od Google — TypeScript-first, Signals (od v17), Standalone components, enterprise-friendly

Co to Angular?

Angular to pelen framework JavaScript stworzony przez Google w 2010 (jako AngularJS), kompletnie przepisany w 2016 jako Angular 2+. W przeciwienstwie do React (biblioteka), Angular daje wszystko w pakiecie: routing, formy, HTTP, animacje, walidacja, DI, CLI.

W 2026 stabilna wersja to Angular 18+. Ostatnie dwa lata przyniosly znaczace odmlodzenie: Signals (od v17), Standalone Components (defauly w v18), defer blocks, control flow @if/@for/@switch, Server-Side Rendering with hydration.

Kluczowe cechy

  • Pelen framework — routing, forms, http, validation w pakiecie
  • TypeScript-first — cala dokumentacja i wzorce uzywaja TS
  • Signals (od v17) — nowoczesne reactive primitives
  • Standalone components (default v18) — brak NgModules
  • RxJS — rozbudowany system observables
  • Dependency Injection — pelnoprawny DI container
  • Angular CLI — tooling: schematics, build, test, deploy
  • Material Design — Angular Material official UI library

Pierwszy komponent (Standalone)

import { Component, signal, computed } from '@angular/core';

@Component({
  selector: 'app-counter',
  standalone: true,
  template: `
    <h1>Count: {{ count() }}</h1>
    <p>Doubled: {{ doubled() }}</p>
    <button (click)="increment()">+</button>
  `,
  styles: [`button { padding: 8px 16px; }`]
})
export class CounterComponent {
  count = signal(0);
  doubled = computed(() => this.count() * 2);

  increment() {
    this.count.update(c => c + 1);
  }
}

New control flow (v17+)

<!-- Stary sposob -->
<div *ngIf="user; else noUser">{{ user.name }}</div>
<ng-template #noUser>Brak uzytkownika</ng-template>

<!-- Nowy -->
@if (user) {
  <div>{{ user.name }}</div>
} @else {
  <div>Brak uzytkownika</div>
}

@for (item of items; track item.id) {
  <div>{{ item.name }}</div>
}

@switch (status) {
  @case ('loading') { Ladowanie... }
  @case ('error') { Blad }
  @default { OK }
}

HTTP Client

import { inject } from '@angular/core';
import { HttpClient } from '@angular/common/http';

@Injectable({ providedIn: 'root' })
export class ProductService {
  private http = inject(HttpClient);

  getAll() {
    return this.http.get<Product[]>('/api/products');
  }

  create(product: Product) {
    return this.http.post<Product>('/api/products', product);
  }
}

Kiedy wybrac Angular?

  • Enterprise — banki, korporacje, dlugotrwale projekty
  • Duzy zespol — opinionated framework chroni przed bardlanem
  • TypeScript-first kultury
  • Aplikacje typu pelen ERP / CRM
  • Migracja z AngularJS
  • Zespol z Java / C# background — podobny mental model (DI, classes, decorators)

Kiedy nie?

  • Mae projekty / MVP — overkill
  • Public-facing site z fokusem na bundle size
  • Junior team — wysoka bariera wejscia
  • Modne projekty 2026 — React, Vue, Svelte sa popularniejsze wsrod indie devs

Komponenty UI

  • Angular Material — oficjalny Material Design
  • PrimeNG — bogaty zestaw komponentow
  • NG-ZORRO — AntDesign
  • Clarity — VMware
  • Spartan — shadcn/ui port dla Angular
