Foundation

ZURB Foundation — framework enterprise focused, accessible, ze wsparciem dla email templates

Co to Foundation?

Foundation to jeden z najstarszych CSS frameworkow (od 2011), wczesnie konkurujacy z Bootstrap. Stworzony przez agencje ZURB, byl od poczatku zorientowany na enterprise i accessibility. W 2019 ZURB przekazalo projekt spolecznosci, ale rozwoj jest mniej intensywny niz w Bootstrap czy Tailwind.

Foundation 6 to aktualna wersja stabilna. Najlepiej znana jest jako framework do email templates — Foundation for Emails ma najlepsze wsparcie cross-client (Gmail, Outlook, Apple Mail).

Kluczowe cechy

  • Mobile-first — layout zaczyna sie od mobile
  • Accessibility — ARIA-roles, focus management, screen reader support out-of-box
  • Sass-first — pelna customizacja
  • XY Grid — flex-based 12-column grid
  • Foundation for Emails — oddzielny framework dla mailowych templates
  • Motion UI — biblioteka animacji

Instalacja

npm install foundation-sites

// W Sass
@import "~foundation-sites/scss/foundation";
@include foundation-everything();

Foundation for Emails (Inky)

Specjalna wersja dla HTML emaili, kompatybilna z Outlook, Gmail, Apple Mail. Uzywa Inky — abstrakcji nad table-based HTML.

<container>
  <row>
    <columns large="6">Lewa kolumna</columns>
    <columns large="6">Prawa kolumna</columns>
  </row>
</container>

<!-- Kompiluje sie do skomplikowanego table layout -->

Kiedy uzyc?

  • Enterprise projekty z wymaganiami accessibility
  • Email templates — Foundation for Emails to standard
  • Strony marketingowe z fokusem na ZURB-styles
  • Projekty migrowane z legacy Foundation 4/5
