Catalyst — Tailwind UI Kit

Premium application UI kit od Tailwind Labs. Modern React component library dla SaaS dashboardow, admin paneli, internal tools.

Czym jest Catalyst?

Catalyst to application UI kit stworzony przez Tailwind Labs (zespol Adam Wathan, ktory robi Tailwind CSS, Headless UI, Tailwind UI). Wydany w grudniu 2023 jako odpowiedz na rosnaca popularnosc shadcn/ui.

Kluczowe info w skrocie

  • Tworca: Tailwind Labs (Adam Wathan, Steve Schoger)
  • Wydany: grudzien 2023
  • Wersja: v1.0+ (stable od 2024)
  • Stack: React 18+ z TypeScript, Tailwind CSS, Headless UI
  • Wsparcie Vue: Brak natywnie (tylko React)
  • Cena: Czesc Tailwind Plus subscription (formerly Tailwind UI):
    • Personal: $299 jednorazowo (lifetime)
    • Team: $799 jednorazowo (lifetime, 25 developerow)
  • Model: "Copy-paste components" (jak shadcn/ui), nie biblioteka npm
  • Licencja: Personal / Commercial dla projektow z Tailwind Plus license
  • URL: tailwindui.com/templates/catalyst

Catalyst vs Tailwind UI vs Tailwind CSS

Latwo pomylic te 3 produkty Tailwind Labs:

ProduktCo toCena
Tailwind CSS Sam framework CSS (utility classes) FREE (open source)
Headless UI Unstyled accessible komponenty (logika bez stylu) FREE (open source)
Tailwind UI (Plus) 500+ HTML snippets + szablony stron (marketing, ecommerce, app) $299/$799 jednorazowo
Catalyst React component kit (copy-paste) dla aplikacji $299/$799 (czesc Tailwind Plus)
Tailwind Templates Gotowe szablony stron (Studio, Salient, Spotlight) Czesc Tailwind Plus

Roznice praktyczne:

  • Tailwind UI = HTML snippets do skopiowania. Mozna uzywac z React, Vue, Angular, vanilla.
  • Catalyst = gotowe komponenty React (.tsx). Tylko React.
  • Tailwind UI = "lego" do budowania marketing pages, ecommerce, dashboards.
  • Catalyst = "framework" konkretny dla application UI (forms, tables, dialogs, navigation).

Filozofia: copy-paste components

Catalyst NIE jest biblioteka npm. Nie instalujesz przez npm install @catalyst/ui. Zamiast tego:

  1. Kupujesz Tailwind Plus subscription
  2. Pobierasz ZIP z plikami komponentow (.tsx)
  3. Kopiujesz do swojego projektu (np. src/components/ui/)
  4. Importujesz lokalnie: import { Button } from '@/components/ui/button'
  5. Modyfikujesz dowolnie — to twoj kod

Zalety podejscia copy-paste

  • ✓ Pelna kontrola — modyfikujesz kod jak chcesz
  • ✓ Brak vendor lock-in — zalezne od ciebie
  • ✓ Brak abstraction layer — widzisz dokladnie co robi komponent
  • ✓ Brak update conflicts — twoje modyfikacje nie pekna z nowa wersja
  • ✓ Type-safe od razu — TypeScript w pelni
  • ✓ Mniejszy bundle — tylko to czego uzywasz
  • ✓ Tailwind classes inline — latwo dostosowac styling

Wady podejscia

  • ⚠ Recznne updates — gdy Tailwind Labs wypusci v2, musisz manualnie merge zmiany
  • ⚠ Wiecej plikow w projekcie
  • ⚠ Wymagana znajomosc React + Tailwind (nie dla beginners)
  • ⚠ Brak community plugins (nie ma ekosystemu jak Material UI)

Architektura Catalyst

Catalyst nie wymyslal kola od nowa. Buduje na sprawdzonych klockach:

┌──────────────────────────────────────┐
│      Twoja aplikacja React            │
│  <Button color="indigo">Save</Button>  │
└──────────────┬───────────────────────┘
               │
┌──────────────▼───────────────────────┐
│      Catalyst Components (.tsx)       │
│  Button, Input, Dialog, Table...      │
└──────────────┬───────────────────────┘
               │ uses
┌──────────────▼───────────────────────┐
│      Headless UI (logic + a11y)       │
│  Listbox, Combobox, Disclosure...     │
└──────────────┬───────────────────────┘
               │ uses
┌──────────────▼───────────────────────┐
│      Tailwind CSS (styling)           │
│  bg-indigo-600, hover:bg-indigo-700... │
└──────────────────────────────────────┘

Headless UI dostarcza accessibility + interaction logic (keyboard navigation, focus management, ARIA attributes), a Tailwind CSS daje styling. Catalyst je laczy w gotowe komponenty z konkretnym wygladem.

Komponenty w Catalyst (v2.x, 2026)

Catalyst zawiera ~40 komponentow pogrupowanych w kategorie:

Forms (~12 komponentow)

  • Button — primary, secondary, ghost, with icon, loading state
  • Input — text, email, password, number, with icon
  • Textarea — multi-line input
  • Select — native select replacement
  • Listbox — searchable dropdown z Headless UI Combobox
  • Combobox — autocomplete
  • Switch — toggle on/off
  • Checkbox — single i checkbox group
  • Radio — radio buttons z RadioGroup
  • FieldGroup, Field, Label, Description, ErrorMessage — form layout primitives
  • Fieldset, Legend — grupowanie pol

Navigation (~6 komponentow)

  • Navbar — application navbar z logo + links + user menu
  • Sidebar — left sidebar navigation z grouping
  • SidebarLayout — layout wrapper sidebar + content
  • StackedLayout — top navbar + content
  • Pagination — page navigation
  • Tabs — tabbed navigation

Data display (~10 komponentow)

  • Table — z TableHead, TableBody, TableRow, TableCell, TableHeader
  • Avatar — z initials fallback, sizes
  • AvatarGroup — overlapping avatars
  • Badge — kolorowe pill labels (status indicators)
  • DescriptionList — definition list (klucz-wartosc)
  • Heading — typography heading levels
  • Text — body text z size variants
  • Strong — emphasized text
  • Code — inline code
  • Divider — horizontal separator

Feedback / Overlays (~8 komponentow)

  • Dialog — modal dialog z Headless UI
  • Alert — alert dialog (confirmation)
  • DropdownMenu — context menu z items, separators, shortcuts
  • Dropdown.Header, Dropdown.Item, Dropdown.Section
  • Spinner — loading indicator

Layout helpers (~3 komponentow)

  • SidebarLayout — kompletny layout aplikacji
  • StackedLayout — alternative layout
  • AuthLayout — layout dla login/register

Setup i instalacja

Wymagania

  • Tailwind Plus subscription ($299+) — bez tego brak dostepu
  • React 18+
  • TypeScript (zalecane, ale dziala w JS)
  • Tailwind CSS 3.x lub 4.x (Catalyst v2 wspiera oba)

Krok po kroku

# 1. Stworz projekt React (jesli jeszcze nie masz)
npm create vite@latest my-app -- --template react-ts
cd my-app
npm install

# 2. Zainstaluj Tailwind CSS
npm install -D tailwindcss @tailwindcss/vite
# vite.config.ts:
import tailwindcss from '@tailwindcss/vite'
export default defineConfig({
  plugins: [react(), tailwindcss()]
})

# 3. Zainstaluj dependencies Catalyst
npm install @headlessui/react clsx tailwind-merge framer-motion

# 4. Pobierz Catalyst .zip z tailwindui.com
# 5. Rozpakuj i skopiuj folder /catalyst do swojego projektu:
my-app/
├── src/
│   ├── components/
│   │   └── catalyst/        ← skopiowane pliki
│   │       ├── button.tsx
│   │       ├── input.tsx
│   │       ├── dialog.tsx
│   │       └── ... (40+ plikow)
│   └── App.tsx

Dialog (modal)

import { useState } from 'react'
import {
  Dialog, DialogTitle, DialogDescription,
  DialogBody, DialogActions
} from '@/components/catalyst/dialog'
import { Button } from '@/components/catalyst/button'

export function DeleteConfirmDialog({ user, onDelete }) {
  const [isOpen, setIsOpen] = useState(false)

  return (
    <>
      <Button color="red" onClick={() => setIsOpen(true)}>
        Usun {user.name}
      </Button>

      <Dialog open={isOpen} onClose={setIsOpen}>
        <DialogTitle>Usun uzytkownika</DialogTitle>
        <DialogDescription>
          Czy na pewno chcesz usunac {user.name}?
          Ta akcja jest nieodwracalna.
        </DialogDescription>
        <DialogBody>
          {/* dodatkowa zawartosc */}
        </DialogBody>
        <DialogActions>
          <Button plain onClick={() => setIsOpen(false)}>
            Anuluj
          </Button>
          <Button color="red" onClick={() => {
            onDelete(user.id)
            setIsOpen(false)
          }}>
            Usun
          </Button>
        </DialogActions>
      </Dialog>
    </>
  )
}

Custom colors

Edytujesz button.tsx bezposrednio i dodajesz custom variant:

// src/components/catalyst/button.tsx
const styles = {
  colors: {
    'dark/zinc': '...',
    'light/zinc': '...',
    indigo: 'text-white bg-indigo-600 hover:bg-indigo-500...',
    // Dodaj wlasny:
    brand: 'text-white bg-purple-700 hover:bg-purple-600...',
  }
}

Custom variants

// Mozesz tez dodac wlasne props:
type ButtonProps = {
  size?: 'xs' | 'sm' | 'md' | 'lg'
  // domyslnie tylko default size — dodajesz sam
}

// Uzyj clsx + tailwind-merge dla bezpiecznego mergowania klas
import { clsx } from 'clsx'
import { twMerge } from 'tailwind-merge'

const classes = twMerge(clsx(
  'base-classes',
  size === 'lg' && 'px-6 py-3 text-lg',
  size === 'sm' && 'px-2 py-1 text-sm',
))

Dark mode

Catalyst natywnie wspiera dark mode. Wszystkie komponenty maja warianty dark: w klasach Tailwind:

// Aktywuj dark mode w aplikacji (kilka opcji):

// Opcja 1: Class-based (manual toggle)
<html className={isDark ? 'dark' : ''}>...

// Opcja 2: System preference
import { useDarkMode } from '@/hooks/useDarkMode'

// Opcja 3: Tailwind 'media' strategy w config
// tailwind.config.js: darkMode: 'media'

Kiedy wybrac Catalyst?

Catalyst jest dobrym wyborem dla:

  • SaaS dashboardow — admin panele, business apps
  • Internal tools dla firm
  • Project ze sztywnym budzetem $299 ale chca premium quality
  • Team juz uzywajacy Tailwind UI — naturalne uzupelnienie
  • React + TypeScript projects
  • Klienci ktorzy ceniają spojny "Tailwind look"
  • Tailwind Labs ekosystem fans

NIE wybieraj Catalyst gdy:

  • Budzet 0 zl → uzyj shadcn/ui (free, podobny model)
  • Vue / Svelte projekt → Catalyst tylko React
  • Marketing / landing pages → Tailwind UI lub Astro templates
  • Material Design wymagany → Material UI (MUI)
  • iOS-style → React Native lub Cupertino-themed library
  • Maximum customization design → Headless UI sam (bez Catalyst layer)
  • Custom / unique brand design → Catalyst's "Tailwind Labs look" moze ograniczac

Catalyst vs shadcn/ui — szczegolowe porownanie

To najczesciej zadawane pytanie: skoro shadcn/ui jest darmowy i podobny, czemu placic za Catalyst?

shadcn/ui ma przewage

  • ✓ FREE — zero kosztow
  • ✓ CLI tool — npx shadcn@latest add button
  • ✓ Wiekszy ekosystem — community blocks, charts, themes
  • ✓ Opensource — mozesz contributing
  • ✓ Wiele themes z generatora
  • ✓ Better dla content sites (jest blog, marketing components)

Catalyst ma przewage

  • ✓ Bardziej spojny design system (jeden autor, mniej decyzji)
  • ✓ Wsparcie Tailwind Labs (oficjalny produkt)
  • ✓ Layout components (Sidebar, StackedLayout) — shadcn nie ma
  • ✓ Specjalizacja w application UI (formy, tabele, dialogi)
  • ✓ Premium quality animations (Framer Motion)
  • ✓ Headless UI over Radix (lepszy dla typescript inference)
  • ✓ Lepsze defaults dla biznesowych UI

Werdykt

W 2026 shadcn/ui jest #1 wyborem dla wiekszosci projektow (free, community, ekosystem). Catalyst jest premium alternatywa dla zespolow, ktore juz placa za Tailwind UI i chca spojnego doswiadczenia od jednego dostawcy. Jego silna strona to layout components (Sidebar) i bardziej "ulizany" design.

Wielu developerow w 2026 uzywa obu: shadcn/ui jako baze, Catalyst layouts dla SidebarLayout, Tailwind UI dla landing pages.

Tips i best practices

  1. Trzymaj Catalyst w osobnym folderze (src/components/catalyst/) — latwo updates manualne
  2. Nie modyfikuj plikow source bez potrzeby — komentuj zmiany dla future you
  3. Wraping pattern — zamiast modyfikowac, wrap w wlasne komponenty: 
    // src/components/ui/MyButton.tsx
import { Button as CatalystButton } from '@/components/catalyst/button'

export function MyButton(props) {
  // Add custom logic, default props, etc.
  return <CatalystButton color="indigo" {...props} />
}
  4. Subscribe do Tailwind Plus newsletter — info o nowych komponentach
  5. Combine z React Hook Form + Zod dla form validation
  6. Storybook dla dokumentacji wlasnych wrapperow
  7. Code review zmian Catalyst przy upgrade do v2/v3

Podsumowanie

Catalyst to premium application UI kit od Tailwind Labs. W 2026 jest swiadomy wybor dla zespolow ktore:
