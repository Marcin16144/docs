Breakpoints — mobile-first

Tailwind dziala mobile-first. Klasy bez prefixu obowiazuja na kazdym ekranie. Prefixy sm:, md:, lg: nadpisuja wartosci od danego breakpointu w gore.

PrefixMin-widthTypowy device
(brak)0pxMobile (default)
sm:640pxTelefon w pionie / mala tabletka
md:768pxTablet
lg:1024pxLaptop, ekran 13"
xl:1280pxDesktop
2xl:1536pxBig monitor

Przyklad mobile-first

<div class="text-center md:text-left">
  Wycentrowany na mobile, wyrownany do lewej od md
</div>

<div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4">
  <!-- 1 kolumna na mobile, 2 na tabletach, 3 na desktop -->
</div>

<img class="w-full md:w-1/2 lg:w-1/3">

Dark mode

Tailwind ma prefix dark:. Sposob aktywacji wybierasz w konfiguracji.

Class strategy (rekomendowana)

<!-- v4 -->
@import "tailwindcss";
@variant dark (&.dark, &.dark *);

<!-- v3 -->
// tailwind.config.js
module.exports = {
  darkMode: 'class',
  // ...
}
<html class="dark">
  <body class="bg-white text-gray-900 dark:bg-gray-900 dark:text-gray-100">
    <p class="text-gray-700 dark:text-gray-300">Adaptacyjny tekst</p>
  </body>
</html>

Toggle w JS

const toggle = () => {
  document.documentElement.classList.toggle('dark');
  localStorage.theme = document.documentElement.classList.contains('dark') ? 'dark' : 'light';
};

// Inicjalizacja
if (localStorage.theme === 'dark' || (!('theme' in localStorage) &&
    window.matchMedia('(prefers-color-scheme: dark)').matches)) {
  document.documentElement.classList.add('dark');
}

Media strategy (auto-detekcja)

// v3 config
darkMode: 'media'

// Bedzie aktywne gdy uzytkownik ma dark mode w systemie

Group i peer modifiers

Pozwalaja stylowac dziecko w zaleznosci od stanu rodzica (group) lub rodzenstwa (peer).

Group

<a href="#" class="group block p-4 border rounded hover:bg-gray-100">
  <h3 class="font-bold group-hover:text-blue-600">Tytul</h3>
  <p class="text-gray-600 group-hover:text-gray-800">Opis</p>
  <span class="opacity-0 group-hover:opacity-100 transition">→</span>
</a>

Mozna miec wiele nazwanych grup:

<div class="group/menu">
  <div class="group/item">
    <span class="group-hover/menu:text-blue-500 group-hover/item:underline">...</span>
  </div>
</div>

Peer

<input type="checkbox" class="peer">
<div class="peer-checked:bg-green-500 hidden peer-checked:block">
  Pokazany gdy checkbox zaznaczony
</div>

<input type="email" required class="peer ...">
<p class="hidden peer-invalid:block text-red-500">Wpisz poprawny email</p>

Arbitrary values

Czasem musisz uzyc niestandardowej wartosci. Tailwind pozwala na to przez nawiasy kwadratowe:

<!-- Custom width -->
<div class="w-[123px]">...</div>
<div class="w-[80vw]">...</div>

<!-- Custom kolor -->
<div class="bg-[#1da1f2]">Twitter blue</div>
<div class="text-[oklch(0.7_0.15_250)]">OKLCH</div>

<!-- Custom grid -->
<div class="grid-cols-[200px_1fr_auto]">...</div>

<!-- Custom selektor -->
<div class="[&:nth-child(3)]:bg-red-500">...</div>
<div class="[&>p]:mb-2">Wszystkie p w srodku maja margin</div>

Container queries (od v4)

<div class="@container">
  <div class="@md:flex @md:gap-4">
    Reaguje na rozmiar RODZICA, nie viewport
  </div>
</div>

Has selector

Klasa has-[...] pozwala stylowac element gdy jego dziecko spelnia warunek.

<div class="has-[input:checked]:bg-blue-50 p-4 border">
  <input type="checkbox"> Zmieni tlo gdy zaznaczone
</div>

Print styles

<header class="print:hidden">...</header>
<article class="print:text-black print:bg-white">...</article>

Combo states

<!-- dark + hover -->
<button class="dark:hover:bg-gray-700">...</button>

<!-- responsive + state -->
<button class="md:hover:scale-110">...</button>

<!-- group + dark -->
<div class="group">
  <p class="dark:group-hover:text-white">...</p>
</div>
