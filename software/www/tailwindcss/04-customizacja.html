v4 CSS-first config

W Tailwind v4 konfiguracja zyje w CSS, nie w pliku JS. Uzywasz dyrektywy @theme — ustawiasz CSS variables, ktore Tailwind przeklada na klasy utility.

/* style.css */
@import "tailwindcss";

@theme {
  /* Kolory */
  --color-brand: #ff6b35;
  --color-brand-100: #fff1eb;
  --color-brand-500: #ff6b35;
  --color-brand-900: #6b2410;

  /* Font */
  --font-display: "Cabinet Grotesk", system-ui, sans-serif;
  --font-mono: "JetBrains Mono", monospace;

  /* Breakpointy */
  --breakpoint-3xl: 1920px;

  /* Spacing */
  --spacing-128: 32rem;
  --spacing-144: 36rem;

  /* Radius */
  --radius-4xl: 2rem;
}

Generuje automatycznie klasy: .text-brand, .bg-brand-100, .font-display, .max-w-128, .rounded-4xl, .3xl:flex itd.

v3 tailwind.config.js

W starszej wersji caly setup byl w pliku JS. Wciaz duzo projektow uzywa tego stylu.

// tailwind.config.js
/** @type {import('tailwindcss').Config} */
module.exports = {
  content: [
    "./src/**/*.{html,js,jsx,ts,tsx,vue}",
    "./pages/**/*.{js,jsx,ts,tsx}"
  ],
  darkMode: 'class',
  theme: {
    extend: {
      colors: {
        brand: {
          DEFAULT: '#ff6b35',
          100: '#fff1eb',
          500: '#ff6b35',
          900: '#6b2410'
        }
      },
      fontFamily: {
        display: ['Cabinet Grotesk', 'system-ui', 'sans-serif']
      },
      screens: {
        '3xl': '1920px'
      },
      spacing: {
        '128': '32rem'
      },
      animation: {
        'slow-spin': 'spin 5s linear infinite'
      }
    }
  },
  plugins: [
    require('@tailwindcss/typography'),
    require('@tailwindcss/forms')
  ]
}

Custom fonty

Z Google Fonts

<!-- W head HTML -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&display=swap" rel="stylesheet">
@theme {
  --font-sans: "Inter", system-ui, sans-serif;
}

/* Lub dla samej klasy */
@theme {
  --font-inter: "Inter", sans-serif;
}
/* Generuje .font-inter */

Self-hosted

@font-face {
  font-family: "Cabinet Grotesk";
  src: url("/fonts/cabinet.woff2") format("woff2");
  font-display: swap;
}

@theme {
  --font-display: "Cabinet Grotesk", sans-serif;
}

Wlasne komponenty z @apply

Czasami warto wyodrebnic powtarzajacy sie pattern do CSS class:

@layer components {
  .btn {
    @apply px-4 py-2 rounded-lg font-semibold transition;
  }
  .btn-primary {
    @apply btn bg-blue-600 text-white hover:bg-blue-700;
  }
  .btn-outline {
    @apply btn border-2 border-blue-600 text-blue-600 hover:bg-blue-50;
  }
}

Dark mode strategies

Class-based (rekomendowana)

/* v4 */
@variant dark (&.dark, &.dark *);

/* v3 */
darkMode: 'class'

Daje pelna kontrole — uzytkownik moze zmienic motyw klikiem, niezaleznie od ustawien systemu.

Media-based (auto)

/* v4 */
@variant dark (@media (prefers-color-scheme: dark));

/* v3 */
darkMode: 'media'

Automatyczne dopasowanie do ustawien OS — brak przelacznika.

Selector strategy (zaawansowane v4)

@variant dark (&[data-theme="dark"], &[data-theme="dark"] *);

<html data-theme="dark">...</html>

Migracja z v3 do v4

npx @tailwindcss/upgrade

Codemod automatycznie konwertuje config JS do CSS-first @theme. Po migracji warto zweryfikowac plugins (niektore moga wymagac aktualizacji do v4).
