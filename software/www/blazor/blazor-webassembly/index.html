HttpClient, named clients, Polly resilience, JWT token handling, CORS, error handling, retry policies.

OIDC, MSAL.js dla Azure AD, OAuth 2.0 Implicit Flow, BFF pattern (preferowane), token storage security.

Static hosting (Azure SWA, Netlify, Vercel, S3+CloudFront), CDN, compression headers, cache busting, environment configs.
