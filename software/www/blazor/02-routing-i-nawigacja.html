Routing i nawigacja Blazor

App.razor, NavigationManager, route parametry, route constraints, protected routes

App.razor — root komponent

Plik App.razor definiuje routing dla calej aplikacji. Komponent Router przeszukuje zalozenia w danym assembly i mapuje URL na odpowiednie strony.

<Router AppAssembly="@typeof(App).Assembly">
    <Found Context="routeData">
        <RouteView RouteData="@routeData" DefaultLayout="@typeof(MainLayout)" />
        <FocusOnNavigate RouteData="@routeData" Selector="h1" />
    </Found>
    <NotFound>
        <PageTitle>Nie znaleziono</PageTitle>
        <LayoutView Layout="@typeof(MainLayout)">
            <p>Strona nie istnieje.</p>
        </LayoutView>
    </NotFound>
</Router>

Definiowanie strony

Dyrektywa @page przypisuje routing URL do komponentu. Mozesz miec wiele @page dyrektyw na jednej stronie (aliasy URL).

@page "/products"
@page "/produkty"

<h1>Lista produktow</h1>

Route constraints

ConstraintOpis
{id:int}Liczba calkowita
{id:long}Long
{val:double}Liczba zmiennoprzecinkowa
{val:bool}true/false
{date:datetime}Data ISO
{id:guid}GUID
{name?}Optional parameter
{*rest}Catch-all (zlapie reszte URL)
 
@page "/orders/{Year:int}/{Month:int?}"
@page "/files/{*path}"

@code {
    [Parameter] public int Year { get; set; }
    [Parameter] public int? Month { get; set; }
    [Parameter] public string Path { get; set; } = "";
}

Query string parameters

@page "/search"

<h1>Wyniki: @Query</h1>

@code {
    [SupplyParameterFromQuery]
    public string? Query { get; set; }

    [SupplyParameterFromQuery(Name = "page")]
    public int Page { get; set; } = 1;
}

<!-- URL: /search?Query=blazor&page=2 -->

NavigationManager

Wbudowany serwis do programatycznej nawigacji.

@inject NavigationManager Navigation

<button @onclick="GoToProducts">Produkty</button>
<button @onclick="GoBack">Powrot</button>

@code {
    private void GoToProducts()
    {
        Navigation.NavigateTo("/products");
    }

    private void GoToProductWithReplace(int id)
    {
        Navigation.NavigateTo($"/products/{id}", replace: true);
    }

    private void ForceReload()
    {
        Navigation.NavigateTo("/", forceLoad: true);
    }

    private void GoBack()
    {
        Navigation.NavigateTo(Navigation.HistoryEntryState ?? "/");
    }
}

Subskrypcja zmiany URL

@inject NavigationManager Navigation
@implements IDisposable

@code {
    protected override void OnInitialized()
    {
        Navigation.LocationChanged += OnLocationChanged;
    }

    private void OnLocationChanged(object? sender, LocationChangedEventArgs e)
    {
        Console.WriteLine($"Nawigacja do: {e.Location}");
    }

    public void Dispose()
    {
        Navigation.LocationChanged -= OnLocationChanged;
    }
}

NavLink — aktywny link

Komponent NavLink automatycznie dodaje klase active gdy URL pasuje.

<nav>
  <NavLink href="/" Match="NavLinkMatch.All">Home</NavLink>
  <NavLink href="/products">Produkty</NavLink>
  <NavLink href="/contact" ActiveClass="active text-bold">Kontakt</NavLink>
</nav>

Route ordering — kolejnosc dopasowania

Blazor wybiera najbardziej specyficzny route. Litera ma pierwszenstwo nad parametrem, parametr nad catch-all.

@page "/products"           // 1. najbardziej specyficzny
@page "/products/{id:int}"  // 2. z parametrem
@page "/products/{*rest}"   // 3. catch-all

Protected routes — AuthorizeView

Aby chronic strone wymagajaca logowania uzyj [Authorize] i AuthorizeRouteView.

<!-- App.razor -->
<Router AppAssembly="@typeof(App).Assembly">
    <Found Context="routeData">
        <AuthorizeRouteView RouteData="@routeData" DefaultLayout="@typeof(MainLayout)">
            <NotAuthorized>
                <p>Zaloguj sie aby zobaczyc te strone.</p>
            </NotAuthorized>
        </AuthorizeRouteView>
    </Found>
</Router>
@page "/admin"
@attribute [Authorize(Roles = "Admin")]

<h1>Panel administratora</h1>

Layouts

</HeadContent>
