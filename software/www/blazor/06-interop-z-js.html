JS Interop Blazor

IJSRuntime, wywolywanie JS z C#, C# z JS, JS modules, integracja Chart.js

Po co JS Interop?

Blazor pozwala robic 95% rzeczy w C#, ale czasem musisz wykorzystac istniejaca biblioteke JS (Chart.js, Leaflet, mapy, edytory tekstu) lub wywolac niskopoziomowe API przegladarki (clipboard, geolocation, notifications). Wtedy uzywasz JS Interop.

IJSRuntime — podstawowy serwis

@inject IJSRuntime JS

<button @onclick="ShowAlert">Pokaz alert</button>

@code {
    private async Task ShowAlert()
    {
        await JS.InvokeVoidAsync("alert", "Hello z C#!");
    }
}

Wywolywanie JS z C#

InvokeVoidAsync — bez wartosci zwracanej

await JS.InvokeVoidAsync("console.log", "Wiadomosc");
await JS.InvokeVoidAsync("localStorage.setItem", "key", "value");
await JS.InvokeVoidAsync("scrollTo", 0, 0);

InvokeAsync — z wartoscia zwracana

var width = await JS.InvokeAsync<int>("eval", "window.innerWidth");
var savedValue = await JS.InvokeAsync<string>("localStorage.getItem", "key");
var data = await JS.InvokeAsync<MyData>("loadData", id);

Wlasna funkcja JS

// wwwroot/js/site.js
window.myApp = {
    showToast: (message, duration) => {
        const toast = document.createElement('div');
        toast.textContent = message;
        toast.className = 'toast';
        document.body.appendChild(toast);
        setTimeout(() => toast.remove(), duration);
    },

        return document.getElementById('myCanvas').width;
    }

<script src="js/site.js"></script>

await JS.InvokeVoidAsync("myApp.showToast", "Zapisano!", 3000);
var width = await JS.InvokeAsync<int>("myApp.getCanvasWidth");

Instance method z DotNetObjectReference

Najczesciej chcesz wywolac metode instancyjna komponentu. Wtedy musisz przekazac referencje do JS.

@inject IJSRuntime JS
@implements IDisposable

<div id="resizable">Treść</div>

@code {
    private DotNetObjectReference<ResizableComponent>? selfRef;

    protected override async Task OnAfterRenderAsync(bool firstRender)
    {
        if (firstRender)
        {
            selfRef = DotNetObjectReference.Create(this);
            await JS.InvokeVoidAsync("setupResizeObserver", "resizable", selfRef);
        }
    }

    [JSInvokable]
    public void OnResize(int width, int height)
    {
        Console.WriteLine($"Resize: {width}x{height}");
        StateHasChanged();
    }

    public void Dispose() => selfRef?.Dispose();
}
// JS
window.setupResizeObserver = (id, dotNetRef) => {
    const el = document.getElementById(id);
    new ResizeObserver(entries => {
        const r = entries[0].contentRect;
        dotNetRef.invokeMethodAsync('OnResize', r.width | 0, r.height | 0);
    }).observe(el);
};

JS isolation — modules (zalecane)

Zamiast globalnego namespace mozna ladowac JS jako moduly per komponent.

// wwwroot/js/myComponent.js
export function init(canvas, data) {
    // ... rysowanie
}

export function update(newData) {
    // ...
}

export function dispose() {
    // ...
}
@implements IAsyncDisposable
@inject IJSRuntime JS

<canvas @ref="canvasRef"></canvas>

@code {
    private ElementReference canvasRef;
    private IJSObjectReference? module;

    protected override async Task OnAfterRenderAsync(bool firstRender)
    {
        if (firstRender)
        {
            module = await JS.InvokeAsync<IJSObjectReference>(
                "import", "./js/myComponent.js");
            await module.InvokeVoidAsync("init", canvasRef, data);
        }
    }

    public async ValueTask DisposeAsync()
    {
        if (module != null)
        {
            await module.InvokeVoidAsync("dispose");
            await module.DisposeAsync();
        }
    }
}

ElementReference

Czasem chcesz wskazac konkretny element DOM aby JS mogl na nim operowac.

<input @ref="inputRef" />
<button @onclick="Focus">Focus</button>

@code {
    private ElementReference inputRef;

    private async Task Focus()
    {
        await inputRef.FocusAsync();
        // lub: await JS.InvokeVoidAsync("doSomething", inputRef);
    }
}

Integracja Chart.js

// wwwroot/js/chart-helper.js
export function createChart(canvas, config) {
    return new Chart(canvas, config);
}

export function updateChart(chart, newData) {
    chart.data.datasets[0].data = newData;
    chart.update();
}

export function destroyChart(chart) {
    chart.destroy();
}
@implements IAsyncDisposable
@inject IJSRuntime JS

<canvas @ref="canvasRef"></canvas>

@code {
    [Parameter] public List<double> Data { get; set; } = new();

    private ElementReference canvasRef;
    private IJSObjectReference? module;
    private IJSObjectReference? chart;

    protected override async Task OnAfterRenderAsync(bool firstRender)
    {
        if (firstRender)
        {
            module = await JS.InvokeAsync<IJSObjectReference>(
                "import", "./js/chart-helper.js");

            chart = await module.InvokeAsync<IJSObjectReference>(
                "createChart", canvasRef, new {
                    type = "bar",
                    data = new {
                        labels = new[] { "A", "B", "C" },
                        datasets = new[] { new { data = Data } }
                    }
                });
        }
    }

    public async ValueTask DisposeAsync()
    {
        if (chart != null) await module!.InvokeVoidAsync("destroyChart", chart);
        if (module != null) await module.DisposeAsync();
    }
}

Integracja Leaflet (mapy)

// js/leaflet-helper.js
export function createMap(elementId, lat, lng, zoom) {
    const map = L.map(elementId).setView([lat, lng], zoom);
    L.tileLayer('https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png').addTo(map);
    return map;
}

export function addMarker(map, lat, lng, popup) {
    L.marker([lat, lng]).addTo(map).bindPopup(popup);
}

Performance considerations

  • JS Interop ma overhead — nie wywoluj w petli "1000 razy"
  • Batch wywolania: jeden call z tablica zamiast wielu pojedynczych
  • W Blazor Server kazdy interop = round trip przez SignalR (latency)
  • W Blazor WASM call jest synchroniczny (lokalny), wiec szybszy
  • Dispose IJSObjectReference i DotNetObjectReference — memory leak inaczej

Common patterns

Clipboard API

await JS.InvokeVoidAsync("navigator.clipboard.writeText", "skopiowane");
var text = await JS.InvokeAsync<string>("navigator.clipboard.readText");

Geolocation

// js
window.getLocation = () => new Promise((resolve, reject) =>
    navigator.geolocation.getCurrentPosition(
        pos => resolve({ lat: pos.coords.latitude, lng: pos.coords.longitude }),
        err => reject(err.message)
    ));

// C#
var loc = await JS.InvokeAsync<LocationDto>("getLocation");

Pobranie pliku

// js
window.downloadFile = (filename, base64) => {
    const link = document.createElement('a');
    link.href = "data:application/octet-stream;base64," + base64;
    link.download = filename;
    link.click();
};

// C#
var bytes = File.ReadAllBytes(path);
await JS.InvokeVoidAsync("downloadFile", "raport.pdf", Convert.ToBase64String(bytes));
