Blazor Hybrid

Blazor w aplikacjach desktop i mobile via .NET MAUI, WPF, WinForms. Reuse Razor components dla web i natywnych aplikacji.

┌──────────────────────────────────────┐ │ Native Application │ │ (MAUI / WPF / WinForms) │ │ ┌────────────────────────────────┐ │ │ │ BlazorWebView control │ │ │ │ ┌─────────────────────────┐ │ │ │ │ │ Razor Components (.NET)│ │ │ │ │ │ Direct .NET runtime │ │ │ │ │ │ No HTTP — local IPC │ │ │ │ │ └─────────────────────────┘ │ │ │ └────────────────────────────────┘ │ │ ↕ │ │ Native APIs (file system, GPS, │ │ camera, sensors, push) │ └──────────────────────────────────────┘

01. Blazor + .NET MAUI (cross-platform)

Single codebase: Windows, macOS, iOS, Android. BlazorWebView, MainPage.xaml, integracja z native APIs (geolocation, camera).

02. Blazor + WPF (Windows desktop)

WPF host z BlazorWebView, mieszanie XAML i Razor, typowe scenariusze migracji legacy WPF do Blazor.

03. Blazor + WinForms (legacy modernization)

WinForms BlazorWebView, modernizacja starych aplikacji bez full rewrite, hybrid screens.

04. Native interop

Wywoływanie native APIs z Blazor (file system, notifications, hardware sensors, Bluetooth, USB), DependencyInjection w MAUI.

05. Shared codebase: Web + Hybrid

RazorClassLibrary, condicional compilation (#if MAUI), platform-specific implementations, MVVM patterns.

06. Deployment mobile (App Store, Play Store)

iOS code signing, Apple notarization, Android signing, Microsoft Store, Mac App Store, distribution outside stores.
