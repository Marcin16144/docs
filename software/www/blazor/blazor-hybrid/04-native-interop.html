Native interop Blazor Hybrid

Calling native APIs from Blazor: file system, notifications, sensors, BLE, USB

Roznica vs Blazor WASM

W Blazor Hybrid (MAUI/WPF/WinForms) C# zyje w pelnym .NET runtime z dostepem do platforma APIs. Mozesz uzywac:

  • System.IO — dowolne pliki, bez sandbox
  • P/Invoke do native bibliotek (Win32, IOKit, Android NDK)
  • Platform-specific APIs (MAUI Essentials, WindowsAPICodePack, JNI)
  • Native UI overlay (popups, dialogi systemowe)

File system — pelny dostep

@inject IFileService Files

@code {
    private async Task SaveReport(byte[] data)
    {
        // Pelny dostep do filesystem (nie sandbox)
        var path = Path.Combine(
            Environment.GetFolderPath(Environment.SpecialFolder.MyDocuments),
            "raport.pdf");
        await File.WriteAllBytesAsync(path, data);
    }

    private async Task OpenFile()
    {
        // MAUI - file picker
        var result = await FilePicker.Default.PickAsync();
        if (result != null)
        {
            using var stream = await result.OpenReadAsync();
            // ...
        }

        // WinForms - dialog systemowy
        using var dialog = new OpenFileDialog();
        if (dialog.ShowDialog() == DialogResult.OK)
        {
            var bytes = await File.ReadAllBytesAsync(dialog.FileName);
        }
    }
}

Camera

private async Task TakePhoto()
{
    if (MediaPicker.Default.IsCaptureSupported)
    {
        var photo = await MediaPicker.Default.CapturePhotoAsync(new MediaPickerOptions
        {
            Title = "Zdjecie produktu"
        });

        if (photo != null)
        {
            // Save to local
            var localFilePath = Path.Combine(FileSystem.AppDataDirectory, photo.FileName);
            using var stream = await photo.OpenReadAsync();
            using var newStream = File.OpenWrite(localFilePath);
            await stream.CopyToAsync(newStream);
        }
    }
}

Sensory (akcelerometr, kompas, zyroskop)

@implements IDisposable

@code {
    private double x, y, z;

    protected override void OnInitialized()
    {
        if (Accelerometer.Default.IsSupported)
        {
            Accelerometer.Default.ReadingChanged += OnReading;
            Accelerometer.Default.Start(SensorSpeed.UI);
        }
    }

    private void OnReading(object? sender, AccelerometerChangedEventArgs e)
    {
        var data = e.Reading;
        x = data.Acceleration.X;
        y = data.Acceleration.Y;
        z = data.Acceleration.Z;
        InvokeAsync(StateHasChanged);
    }

    public void Dispose()
    {
        if (Accelerometer.Default.IsSupported)
        {
            Accelerometer.Default.Stop();
            Accelerometer.Default.ReadingChanged -= OnReading;
        }
    }
}

Bluetooth Low Energy

Dla aplikacji terenowych (skanery kodow kreskowych, urzadzenia medyczne, beacons).

// Plugin.BLE
using Plugin.BLE;

private async Task ScanDevices()
{
    var ble = CrossBluetoothLE.Current;
    var adapter = ble.Adapter;

    adapter.DeviceDiscovered += (s, e) =>
    {
        devices.Add(e.Device);
        InvokeAsync(StateHasChanged);
    };

    await adapter.StartScanningForDevicesAsync(
        timeout: TimeSpan.FromSeconds(10));
}

private async Task ConnectAndRead(IDevice device)
{
    var adapter = CrossBluetoothLE.Current.Adapter;
    await adapter.ConnectToDeviceAsync(device);

    var services = await device.GetServicesAsync();
    var service = services.FirstOrDefault(s => s.Id == myServiceUuid);
    var characteristics = await service.GetCharacteristicsAsync();
    var data = await characteristics[0].ReadAsync();
}

DI for native services

// Generic interface
public interface IDeviceInfoService
{
    string GetDeviceName();
    string GetOSVersion();
}

// Platform-specific implementacje
#if WINDOWS
public class WindowsDeviceInfoService : IDeviceInfoService
{
    public string GetDeviceName() => Environment.MachineName;
    public string GetOSVersion() => Environment.OSVersion.ToString();
}
#elif ANDROID
public class AndroidDeviceInfoService : IDeviceInfoService
{
    public string GetDeviceName() => Android.OS.Build.Model;
    public string GetOSVersion() => Android.OS.Build.VERSION.Release;
}
#endif

// Program.cs
#if WINDOWS
services.AddSingleton<IDeviceInfoService, WindowsDeviceInfoService>();
#elif ANDROID
services.AddSingleton<IDeviceInfoService, AndroidDeviceInfoService>();
#endif

Common patterns

Service abstraction

Stworz abstrakcyjny interfejs z metodami, ktorych potrzebujesz. Implementuj per platform — Blazor komponent uzywa tylko interfejsu.

Lazy initialization

Ciezkie native services (BLE, USB, Camera) inicjalizuj tylko kiedy uzytkownik faktycznie ich potrzebuje — nie przy starcie aplikacji.

Error handling

Native APIs czesto rzucaja platform-specific bledy. Wraps w try-catch, mapuj na sensowne komunikaty:

try
{
    var location = await Geolocation.GetLastKnownLocationAsync();
}
catch (FeatureNotSupportedException)
{
    error = "GPS nie jest wspierany";
}
catch (PermissionException)
{
    error = "Brak uprawnien do GPS";
}
catch (Exception ex)
{
    error = $"Nieznany blad: {ex.Message}";
}

Hybrid is the bridge

Blazor Hybrid jest powolany do laczenia "web-like" UI z natywnymi APIs platformy. Jesli twoja aplikacja musi miec dostep do hardware, plikow lokalnych, sensorow — to wlasnie hybrid jest dobrym wyborem. Dla pure web preferowane sa Blazor Server / WASM / United.
