iOS deployment

Wymagania

  • Mac z najnowszym Xcode (do build)
  • Apple Developer Account (99 USD/rok)
  • Distribution Certificate
  • Provisioning Profile
  • App Store Connect setup

Build

# Z Mac (potrzebny Xcode)
dotnet publish -f net9.0-ios -c Release \
  -p:RuntimeIdentifier=ios-arm64 \
  -p:CodesignKey="iPhone Distribution: Your Name (...)" \
  -p:CodesignProvision="Automatic"

App Store Connect

  1. Stworz aplikacje w App Store Connect
  2. Setup Bundle ID, screenshots, opis
  3. Upload .ipa przez Transporter app lub CLI
  4. Submit for review (typowo 1-3 dni)
  5. Po approve — aplikacja w App Store

TestFlight beta testing

App Store Connect umozliwia darmowe testy beta z 100 wewnetrznymi testerami i 10000 zewnetrznymi (po review).

Apple notarization (macOS)

Dla aplikacji macOS dystrybuowanych poza Mac App Store musisz notarize binarka u Apple. Inaczej Gatekeeper zablokuje uruchomienie.

# Build
dotnet publish -f net9.0-maccatalyst -c Release

# Notarize via xcrun
xcrun notarytool submit MyApp.zip \
  --apple-id you@example.com \
  --team-id ABCD123456 \
  --password "app-specific-password" \
  --wait

# Staple notarization
xcrun stapler staple MyApp.app

Android deployment

Wymagania

  • Google Play Developer Account (25 USD jednorazowo)
  • Keystore do podpisania aplikacji
  • Privacy policy URL
  • Aplikacja targeting min API 35 (Android 15) w 2026

Generowanie keystore

keytool -genkey -v -keystore myapp.keystore \
  -alias myappkey -keyalg RSA -keysize 2048 \
  -validity 10000

Build z signing

dotnet publish -f net9.0-android -c Release \
  -p:AndroidPackageFormats=aab \
  -p:AndroidKeyStore=true \
  -p:AndroidSigningKeyStore=myapp.keystore \
  -p:AndroidSigningKeyAlias=myappkey \
  -p:AndroidSigningKeyPass=PASSWORD \
  -p:AndroidSigningStorePass=PASSWORD

Play Console

  1. Stworz aplikacje w Google Play Console
  2. Wypelnij Store listing (screenshots, opis, kategoria, wiek)
  3. Setup Privacy Policy
  4. Upload AAB do internal testing
  5. Po stabilizacji — promote na production
  6. Pierwsza app review trwa 1-7 dni

App Bundle (AAB) vs APK

Od 2021 Google Play wymaga AAB (Android App Bundle). Play generuje optymalne APK per device. APK uzywaj tylko do side-load testing.

Windows deployment

MSIX package

dotnet publish -f net9.0-windows10.0.19041.0 -c Release \
  -p:GenerateAppxPackageOnBuild=true

Microsoft Store

  1. Microsoft Partner Center account (19 USD jednorazowo)
  2. Reserve nazwy aplikacji
  3. Upload .msixupload
  4. Submit for cert (typowo <24h)
  5. Po approve dostepne w Store

Direct distribution

Jesli nie chcesz Store, mozesz dystrybuowac MSIX przez wlasna strone. Uzytkownik musi:

  • Wlaczyc Sideloading w Settings
  • Zaufac certyfikatowi (Developer Mode lub trust manualny)

Code signing z prawdziwym EV cert (kosztuje ~250 USD/rok) usuwa SmartScreen warnings.

Mac App Store vs direct

Mac App Store

Distribution przez Apple. Korzysci: laczna lista wszystkich aplikacji uzytkownika, Apple ID payments. Wady: 30% prowizja, restrykcyjny sandboxing.

Direct + notarized

Self-hosted DMG, kazdy uzytkownik scieki download. Free tier — tylko notarization required. Wieksza wolnosc dla aplikacji systemowych.

CI/CD dla mobile builds

GitHub Actions — Android

name: Android Build

on:
  push:
    tags: ['v*']

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-dotnet@v4
        with:
          dotnet-version: '9.0'
      - name: Install MAUI
        run: dotnet workload install maui-android

      - name: Decode keystore
        run: echo "${{ secrets.KEYSTORE_BASE64 }}" | base64 -d > myapp.keystore

      - name: Build AAB
        run: |
          dotnet publish -f net9.0-android -c Release \
            -p:AndroidPackageFormats=aab \
            -p:AndroidSigningKeyStore=myapp.keystore \
            -p:AndroidSigningKeyAlias=${{ secrets.KEY_ALIAS }} \
            -p:AndroidSigningKeyPass=${{ secrets.KEY_PASSWORD }} \
            -p:AndroidSigningStorePass=${{ secrets.STORE_PASSWORD }}

      - uses: r0adkll/upload-google-play@v1
        with:
          serviceAccountJsonPlainText: ${{ secrets.PLAY_STORE_SA_JSON }}
          packageName: com.example.myapp
          releaseFiles: bin/Release/**/*.aab
          track: internal

GitHub Actions — iOS (wymaga macOS runner)

name: iOS Build

jobs:
  build:
    runs-on: macos-14
    steps:
      - uses: actions/checkout@v4
      - run: dotnet workload install maui-ios

      - name: Install certificates
        env:
          P12_BASE64: ${{ secrets.IOS_P12 }}
          P12_PASSWORD: ${{ secrets.IOS_P12_PASSWORD }}
        run: |
          echo "$P12_BASE64" | base64 -d > cert.p12
          security create-keychain -p "" build.keychain
          security import cert.p12 -k build.keychain -P "$P12_PASSWORD" -T /usr/bin/codesign
          security set-keychain-settings build.keychain
          security unlock-keychain -p "" build.keychain

      - name: Build IPA
        run: |
          dotnet publish -f net9.0-ios -c Release \
            -p:RuntimeIdentifier=ios-arm64 \
            -p:CodesignKey="iPhone Distribution: My Co" \
            -p:CodesignProvision="MyApp Distribution"

      - uses: apple-actions/upload-testflight-build@v1
        with:
          app-path: bin/Release/net9.0-ios/ios-arm64/publish/MyApp.ipa
          issuer-id: ${{ secrets.APP_STORE_CONNECT_ISSUER_ID }}
          api-key-id: ${{ secrets.APP_STORE_CONNECT_KEY_ID }}
          api-private-key: ${{ secrets.APP_STORE_CONNECT_PRIVATE_KEY }}

App Store guidelines

iOS

  • Apps must NOT just wrap WebView (vague rule, but Blazor Hybrid OK)
  • Privacy: musisz raportowac uzywane data types w Info.plist
  • App Tracking Transparency dla tracking cross-app
  • Push notifications wymagaja capability
  • Content Security: brak nielegalnych tresci, gambling, hate speech

Android (Play)

  • Min API 31 dla nowych apps (rosnie co rok)
  • Privacy declaration (Data Safety section)
  • Permissions usage justification
  • 64-bit binaries required
  • Target SDK requirements (Play wymusza upgrade)

Distribution outside stores

iOS — trudno

Apple bardzo restrykcyjne — tylko Enterprise Distribution (299 USD/rok dla 100+ company), Ad-hoc (max 100 devices), TestFlight (beta), Developer Direct Distribution (UE od 2024 dla wybranych firm).

Android — latwo

APK direct download dziala wszedzie, tylko uzytkownik musi wyrazic zgode na install z unknown sources. Idealnie dla kiosk apps, internal corporate apps.

Windows — latwo

MSIX direct download + signed cert -> zero friction install. Albo MSI / EXE installer.

macOS — mozliwe

Notarized DMG, drag&drop install. Bez Mac App Store ale z Gatekeeper trust.

Crash reporting

  • App Center — Microsoft, free, integracja z Visual Studio

  • Firebase Crashlytics — Google, Android-friendly
  • BugSnag — alternatywa premium

Pre-release checklist

  • Privacy Policy URL aktualny
  • Screenshots dla wszystkich device sizes
  • Localization na wymagane jezyki
  • Ikonki we wszystkich rozmiarach (iOS 30+ rozmiarow, Android 5+)
  • Crash reporting wlaczone
  • Analytics wlaczone (z opt-out)
  • App-specific password / API keys w secret store
  • Tests na realnych urzadzeniach (nie tylko emulator)
  • Battery usage profiling
  • Network usage minimization
