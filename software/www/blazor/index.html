Blazor

C# w przeglądarce i nie tylko. .NET 9 wprowadziło unified Blazor — jeden model, wiele render modes (Server, WebAssembly, Hybrid, SSR).

Warianty Blazor

🖥️ Blazor Server

SignalR connection, server-side rendering. Mała bundle, real-time UI, wymaga persistent connection.

🌐 Blazor WebAssembly

C# w przeglądarce via WASM. SPA-like, działa offline. Większy bundle ale klient autonomiczny.

📱 Blazor Hybrid (MAUI/WPF)

Blazor w aplikacjach desktop/mobile via .NET MAUI. Cross-platform z natywnym hostingiem.

🔄 Blazor United (.NET 8/9)

Mix render modes per komponent: SSR + Server + WASM. Najlepsze z wszystkich światów. Domyślne w nowych projektach.

Wspólne tematy

01. Podstawy Blazor

Razor syntax, components (.razor), parameters, events, two-way binding, lifecycle methods (OnInitialized, OnAfterRender).

02. Routing i nawigacja

App.razor, NavigationManager, route parameters, route constraints, protected routes z authorize.

03. State management

Cascading parameters, dependency injection, scoped services, Fluxor (Redux-like), Carter, persistent state.

04. Formy i walidacja

EditForm, Data Annotations, FluentValidation, custom validators, file uploads (InputFile).

05. Uwierzytelnianie i autoryzacja

ASP.NET Core Identity, JWT, AuthenticationStateProvider, AuthorizeView, role-based access, OAuth.

06. Interop z JavaScript

IJSRuntime, calling JS from C# i vice versa, JS isolation modules, integracja z bibliotekami JS (Chart.js, Leaflet).

07. Biblioteki komponentów

MudBlazor, Radzen, Telerik UI, DevExpress, Syncfusion, FluentUI Web Components, Bootstrap dla Blazor.

08. Deployment

IIS, Azure App Service, Docker, Static Web Apps (dla WASM), Kubernetes, prerendering, AOT compilation.
