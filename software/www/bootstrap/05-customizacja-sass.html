Customizacja przez Sass

Wlasne kolory, breakpointy, ograniczenie bundle do potrzebnych komponentow

Po co Sass w Bootstrap?

Domyslny gotowy plik bootstrap.min.css wazy okolo 230 KB (przed gzip), bo zawiera wszystkie komponenty i utilities. Wiele projektow uzywa tylko 30–40% tej zawartosci. Kompilacja z Sass pozwala:

  • Modyfikowac zmienne (kolory, breakpointy, fonty)
  • Importowac tylko te moduly, ktorych uzywasz
  • Dodawac wlasne utilities i komponenty
  • Tworzyc spojne theming dla brandu

Setup projektu z Sass

npm init -y
npm install bootstrap@5.3.3 sass

Struktura plikow:

my-app/
  scss/
    _variables.scss   # Twoje nadpisania
    custom.scss       # Punkt wejscia
  dist/
    custom.css        # Wynik kompilacji
  package.json

W package.json dopisz skrypt:

"scripts": {
  "build:css": "sass scss/custom.scss dist/custom.css --style=compressed",
  "watch:css": "sass scss/custom.scss dist/custom.css --watch"
}

Wlasny theme — krok po kroku

Plik custom.scss:

// 1. Default function (potrzebne do darken/lighten)
@import "../node_modules/bootstrap/scss/functions";

// 2. Modyfikacje zmiennych
$primary: #6f42c1;
$secondary: #495057;
$success: #20c997;
$danger: #e83e8c;
$body-bg: #f8f9fa;
$enable-shadows: true;
$border-radius: 0.5rem;

$font-family-sans-serif: "Inter", system-ui, sans-serif;
$font-size-base: 0.95rem;

// 3. Wlasne breakpointy (opcjonalne)
$grid-breakpoints: (
  xs: 0,
  sm: 640px,
  md: 800px,
  lg: 1024px,
  xl: 1280px,
  xxl: 1600px
);

// 4. Variables i mixins (Bootstrap zaleznosci)
@import "../node_modules/bootstrap/scss/variables";
@import "../node_modules/bootstrap/scss/mixins";
@import "../node_modules/bootstrap/scss/maps";
@import "../node_modules/bootstrap/scss/utilities";

// 5. Reszta Bootstrap
@import "../node_modules/bootstrap/scss/bootstrap";

// 6. Twoje wlasne style
.my-component {
  background: $primary;
  border-radius: $border-radius;
}

Dolaczanie tylko potrzebnych komponentow

Zamiast importowac caly bootstrap.scss, mozesz wybrac konkretne moduly. Tu szkielet drastycznie zmniejszajacy bundle:

// Required
@import "../node_modules/bootstrap/scss/functions";
@import "../node_modules/bootstrap/scss/variables";
@import "../node_modules/bootstrap/scss/maps";
@import "../node_modules/bootstrap/scss/mixins";
@import "../node_modules/bootstrap/scss/root";

// Reset i base
@import "../node_modules/bootstrap/scss/reboot";
@import "../node_modules/bootstrap/scss/type";

// Layout
@import "../node_modules/bootstrap/scss/grid";
@import "../node_modules/bootstrap/scss/containers";

// Tylko wybrane komponenty
@import "../node_modules/bootstrap/scss/buttons";
@import "../node_modules/bootstrap/scss/forms";
@import "../node_modules/bootstrap/scss/card";
@import "../node_modules/bootstrap/scss/navbar";
@import "../node_modules/bootstrap/scss/modal";

// Utilities (musi byc na koncu)
@import "../node_modules/bootstrap/scss/utilities";
@import "../node_modules/bootstrap/scss/utilities/api";

Custom theme colors

Mozesz dodac wlasny kolor (np. brand) do mapy kolorow theme i automatycznie wygeneruja sie klasy .btn-brand, .text-brand, .bg-brand itd.

$theme-colors: (
  "primary": #6f42c1,
  "brand": #ff6b35,
  "neutral": #6c757d
);

@import "../node_modules/bootstrap/scss/bootstrap";

// Generuje:
// .btn-brand, .text-brand, .bg-brand, .border-brand, .alert-brand itd.

Color modes (5.3+)

Bootstrap 5.3 wprowadzil natywne wsparcie dla trybu ciemnego oparte na data-bs-theme. W Sass mozesz dodac wlasny mode (np. company-dark).

<html data-bs-theme="dark">...</html>
<!-- lub w sekcji -->
<div data-bs-theme="dark">Ciemna sekcja w jasnym layout</div>

Build process

Tylko Sass CLI

npm run watch:css

Z Vite (zalecane w 2026)

npm install -D vite

// vite.config.js
import { defineConfig } from 'vite';
export default defineConfig({
  css: {
    preprocessorOptions: {
      scss: { silenceDeprecations: ['mixed-decls'] }
    }
  }
});

// main.js
import './scss/custom.scss';
import 'bootstrap/dist/js/bootstrap.bundle.min.js';

Z PostCSS i autoprefixerem

npm install -D postcss postcss-cli autoprefixer cssnano

// postcss.config.js
module.exports = {
  plugins: [
    require('autoprefixer'),
    require('cssnano')({ preset: 'default' })
  ]
};

Wskazowka — rozmiar bundle

Po wlasnej kompilacji z usunietymi nieuzywanymi komponentami mozesz zejsc z 230 KB do 40–80 KB CSS. Dodatkowo dolozenie PurgeCSS lub UnoCSS w roli post-processora moze obciac niewykorzystane klasy — ostateczne CSS schodzi nawet do 15–20 KB.
