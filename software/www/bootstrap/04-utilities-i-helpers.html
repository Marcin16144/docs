Utilities i helpers

Spacing, kolory, typografia, display, position i inne klasy single-purpose

Filozofia utilities

Klasy utility w Bootstrap to klasy o jednym celu, ktore mozna laczyc bez pisania CSS. To nadal mniej radykalne podejscie niz w Tailwind — Bootstrap miesza utilities z gotowymi komponentami. W praktyce wiekszosc dewelopelow uzywa utilities do drobnych modyfikacji (margin, padding, kolor tekstu) i komponentow do duzych blokow UI.

Spacing (margin i padding)

Format klasy: {property}{sides}-{breakpoint}-{size}. Przyklady: m-3 (margin: 1rem), px-4 (padding-left/right: 1.5rem), my-md-5 (margin-y od md w gore: 3rem).

SkrotOpis
m / pmargin / padding (wszystkie strony)
mt / pttop
mb / pbbottom
ms / psstart (left w LTR)
me / peend (right w LTR)
mx / pxhorizontalne (start + end)
my / pypionowe (top + bottom)

Skala 0-5 odpowiada za wartosci: 0 (0), 1 (0.25rem), 2 (0.5rem), 3 (1rem), 4 (1.5rem), 5 (3rem). Dodatkowo auto dla automargin (np. mx-auto centruje element).

<div class="p-4 mb-3 bg-light">Padding 1.5rem, margin-bottom 1rem</div>
<div class="mx-auto" style="max-width: 400px">Wycentrowany</div>
<div class="mt-md-5 mt-2">Wiekszy margin od md w gore</div>

Custom utilities w 5.x

Mozesz dodawac wlasne klasy utility przez API $utilities w Sass:

$utilities: map-merge($utilities, (
  "cursor": (
    property: cursor,
    class: cursor,
    values: pointer help wait,
  )
));
// generuje .cursor-pointer, .cursor-help, .cursor-wait
