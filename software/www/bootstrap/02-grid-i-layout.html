Grid i layout Bootstrap

12-kolumnowy responsywny system, breakpointy, kontenery, gutters

Filozofia 12-column grid

Bootstrap od zawsze opiera layouty o 12-kolumnowy grid. Liczba 12 jest podzielna przez 1, 2, 3, 4, 6 i 12 — co daje ogromna elastycznosc kompozycji. Mozesz zrobic 2 kolumny po 6, 3 po 4, 4 po 3, asymetryczny uklad 8+4 itd. Pod spodem od wersji 4 grid uzywa flexboxa, a od wersji 5.3 dostepny jest tez nowy grid CSS Grid opt-in (klasa .grid z bardziej zaawansowanym templatingiem).

Breakpointy (responsive prefixes)

Klasy gridu uzywaja prefiksow odpowiadajacych breakpointom:

BreakpointPrefixMin szerokoscContainer max-width
Extra small(brak)< 576pxauto (100%)
Smallsm≥ 576px540px
Mediummd≥ 768px720px
Largelg≥ 992px960px
X-Largexl≥ 1200px1140px
XX-Largexxl≥ 1400px1320px

Container

Cala zawartosc gridu musi byc opakowana w .container lub .container-fluid. Te klasy ustawiaja max-width i poprawne paddingi po bokach.

<!-- Stalej szerokosci, przyciagany do max-width per breakpoint -->
<div class="container">...</div>

<!-- Pelna szerokosc -->
<div class="container-fluid">...</div>

<!-- Pelna szerokosc do md, potem fixed -->
<div class="container-md">...</div>

Row i kolumny

Wewnatrz containera tworzysz .row, ktory dziala jako flex container. Dzieci z klasa .col sa kolumnami. Mozesz dac numer (1-12) lub pozwolic na rowny podzial.

<div class="container">
  <div class="row">
    <div class="col-md-8">Glowna kolumna</div>
    <div class="col-md-4">Sidebar</div>
  </div>

  <div class="row">
    <div class="col">Auto 1</div>
    <div class="col">Auto 2</div>
    <div class="col">Auto 3</div>
  </div>
</div>

Mieszanie breakpointow

Na malym ekranie kolumny moga zajmowac pelna szerokosc, a na duzym ukladac sie obok siebie:

<div class="row">
  <div class="col-12 col-md-6 col-lg-4">Card 1</div>
  <div class="col-12 col-md-6 col-lg-4">Card 2</div>
  <div class="col-12 col-md-12 col-lg-4">Card 3</div>
</div>

Gutters

Gutters to odstepy miedzy kolumnami. Domyslnie wynosza 1.5rem (24px). Mozesz je modyfikowac klasami .g-* (gutter), .gx-* (horizontalne) i .gy-* (pionowe), gdzie liczba 0–5 odpowiada za skale.

<div class="row g-0">...kolumny bez gutters</div>
<div class="row gx-3 gy-4">...szersze pionowe</div>

Auto-layout, offsets, order

Kolumny moga miec automatyczna szerokosc dopasowana do tresci (.col-auto), wymuszony nowy wiersz, offset (puste miejsce po lewej) i dynamiczna kolejnosc.

<div class="row">
  <div class="col-md-4 offset-md-2">Z offsetem</div>
  <div class="col-md-4">Druga</div>
</div>

<!-- Order -->
<div class="row">
  <div class="col order-3">A</div>
  <div class="col order-1">B</div>
  <div class="col order-2">C</div>
</div>

Flex utilities

Bootstrap udostepnia bogaty zestaw klas flex do uzytku poza gridem. Mozesz na ich podstawie budowac wlasne layouty:

  • .d-flex, .d-inline-flex — ustawia display
  • .flex-row, .flex-column, .flex-row-reverse
  • .justify-content-start | center | end | between | around | evenly
  • .align-items-start | center | end | baseline | stretch
  • .flex-wrap, .flex-nowrap, .flex-wrap-reverse
  • .flex-grow-1, .flex-shrink-0
  • .gap-3 — odstep miedzy elementami

RTL support

Od wersji 5 Bootstrap oferuje pelne wsparcie dla layoutow right-to-left (jezyki arabski, hebrajski). Wystarczy dolaczyc oddzielny plik CSS RTL i ustawic dir="rtl" na html.

<html lang="ar" dir="rtl">
  <link rel="stylesheet" href="bootstrap.rtl.min.css">

CSS Grid (eksperymentalne, opt-in)

Od wersji 5.3 dostepny jest grid oparty o CSS Grid. Wymaga ustawienia $enable-cssgrid: true w Sass. Daje wieksza kontrole nad rozkladem, ale jest mniej standardowy niz tradycyjny row/col.
