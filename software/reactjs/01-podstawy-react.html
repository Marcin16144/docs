Podstawy React

Czym jest React, JSX, komponenty, props i state

Czym jest React?

React to biblioteka JavaScript do budowy interfejsow uzytkownika (UI). Nie framework, lecz wlasnie biblioteka skupiona wylacznie na warstwie widoku. Resztę (routing, data fetching, state) dolaczasz z ekosystemu lub uzywasz meta-frameworka takiego jak Next.js.

Kluczowe cechy:

  • Component-based — UI jako kompozycja malych, reuzywalnych klockow
  • Declarative — opisujesz JAK ma wygladac UI, a nie jak go zbudowac krok po kroku
  • Virtual DOM — React porownuje stary i nowy stan UI w pamieci, potem aktualizuje tylko to co sie zmienilo
  • One-way data flow — dane plyna z gory na dol przez props

Historia

React powstal w 2013 roku w Facebooku (dzis Meta). Pierwotnie napisany przez Jordana Walke dla feedu Facebooka. W 2015 dolaczyl React Native (mobile), w 2018 wprowadzono Hooks (rewolucja — koniec klas), w 2022 React 18 z concurrent rendering, a w 2024 React 19 z Server Components, Server Actions, useOptimistic, use() hook i automatic memoization (React Compiler).

JSX — HTML wewnatrz JavaScript

JSX (JavaScript XML) to rozszerzenie skladni JS pozwalajace pisac strukture UI niemal tak jak HTML. Pod spodem kompiluje sie do wywolan React.createElement(...).

// JSX
const element = <h1 className="title">Witaj, {name}!</h1>;

// Po kompilacji (Babel/SWC):
const element = React.createElement('h1', { className: 'title' }, 'Witaj, ', name, '!');

Roznice wzgledem HTML:

  • className zamiast class (class jest slowem zarezerwowanym w JS)
  • htmlFor zamiast for
  • camelCase dla atrybutow: onClick, tabIndex, autoFocus
  • Wyrazenia JS w klamrach: {zmienna}, {tablica.map(...)}
  • Self-closing tags wymagane: <img />, <br />
  • Jeden root element (lub Fragment <> ... </>)

Function Components

Wspolczesny React uzywa function components — klasy uznano za legacy. Komponent to po prostu funkcja przyjmujaca props i zwracajaca JSX.

// Najprostszy komponent
function Hello() {
  return <h1>Witaj swiecie</h1>;
}

// Z propsami (destructuring)
function Greeting({ name, age }) {
  return <p>Czesc, {name}! Masz {age} lat.</p>;
}

// Uzycie
<Greeting name="Anna" age={28} />

Props — immutable wejscie

Props to argumenty komponentu. Sa read-only — komponent nie powinien ich mutowac. Jesli chcesz cos zmienic, uzyj state.

// Children jako specjalny prop
function Card({ title, children }) {
  return (
    <div className="card">
      <h3>{title}</h3>
      <div>{children}</div>
    </div>
  );
}

<Card title="Witaj">
  <p>Tresc karty</p>
</Card>

State — useState

State to lokalne dane komponentu, ktore moga sie zmieniac w czasie. Po zmianie React rerenderuje komponent. Najprostszy sposob to hook useState.

import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0); // [aktualna wartosc, setter]

  return (
    <div>
      <p>Liczba klikniec: {count}</p>
      <button onClick={() => setCount(count + 1)}>+1</button>
      <button onClick={() => setCount(c => c - 1)}>-1</button>
      <button onClick={() => setCount(0)}>Reset</button>
    </div>
  );
}

Wazne: setter nie modyfikuje obecnej wartosci — planuje rerender z nowa wartoscia. Jesli nowa wartosc zalezy od poprzedniej, uzyj funkcyjnej formy: setCount(c => c + 1).

Setup projektu — Vite (rekomendowane)

W 2026 roku Vite jest standardem dla SPA z React. Create React App jest oficjalnie deprecated od 2023. Dla full-stack uzywaj Next.js.

# Vite + React + TypeScript
npm create vite@latest moja-aplikacja -- --template react-ts
cd moja-aplikacja
npm install
npm run dev   # serwer dev na http://localhost:5173

Pierwszy kompletny komponent

// src/Counter.jsx
import { useState } from 'react';

export default function Counter({ initial = 0, step = 1 }) {
  const [count, setCount] = useState(initial);

  const increment = () => setCount(c => c + step);
  const decrement = () => setCount(c => c - step);
  const reset = () => setCount(initial);

  return (
    <div className="counter">
      <h2>Licznik: {count}</h2>
      <button onClick={increment}>+{step}</button>
      <button onClick={decrement}>-{step}</button>
      <button onClick={reset}>Reset</button>
      {count < 0 && <p>Wartosc ujemna!</p>}
    </div>
  );
}

// src/App.jsx
import Counter from './Counter';

export default function App() {
  return (
    <main>
      <h1>Moja aplikacja</h1>
      <Counter initial={10} step={2} />
    </main>
  );
}

Zasady, ktorych warto sie trzymac

  • Komponent nazwij z wielkiej litery (PascalCase), inaczej JSX potraktuje go jako natywny tag HTML
  • Jedna funkcjonalnosc — jeden komponent (Single Responsibility)
  • Nie mutuj propsow ani state — zawsze twoz nowe obiekty
  • Listy renderuj przez map z unikalnym key
  • Logike biznesowa wyciagaj do custom hookow lub funkcji utility
