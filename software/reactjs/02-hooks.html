Hooks

useState, useEffect, useMemo, useCallback, useRef i custom hooks

Czym sa Hooks?

Hooks to funkcje pozwalajace function components uzywac state, lifecycle i innych mozliwosci Reacta. Wprowadzone w 16.8 (2018), zastapily klasy. Obowiazuja dwie zasady:

  • Wywoluj hooki tylko na top-level — nigdy w if, petlach, zagniezdzonych funkcjach
  • Wywoluj je tylko z function components lub custom hooks

useState

Lokalny state komponentu. Zwraca pare [wartosc, setter].

const [count, setCount] = useState(0);
const [user, setUser] = useState({ name: '', email: '' });
const [items, setItems] = useState([]);

// Lazy initial state — funkcja wywolana TYLKO przy pierwszym renderze
const [data, setData] = useState(() => expensiveCalculation());

// Funkcyjna forma settera — gdy nowa wartosc zalezy od starej
setCount(prev => prev + 1);
setUser(prev => ({ ...prev, name: 'Jan' }));

useEffect

Side-effects: subskrypcje, fetchowanie, logowanie, manipulacja DOM. Uruchamia sie po renderze.

// Po kazdym renderze
useEffect(() => { console.log('render'); });

// Tylko raz po montazu (mount)
useEffect(() => {
  console.log('komponent zamontowany');
}, []);

// Po zmianie zaleznosci
useEffect(() => {
  document.title = `Klikniecia: ${count}`;
}, [count]);

// Z cleanup — wykonuje sie przy unmount lub przed kolejnym effectem
useEffect(() => {
  const id = setInterval(() => tick(), 1000);
  return () => clearInterval(id); // cleanup
}, []);

// Subskrypcja
useEffect(() => {
  const handler = (e) => setSize({ w: e.target.innerWidth });
  window.addEventListener('resize', handler);
  return () => window.removeEventListener('resize', handler);
}, []);

Pulapki useEffect

  • Brak dependency array → effect po kazdym renderze (zwykle blad)
  • Pusty array [] → tylko mount/unmount — uwaga na stale closures
  • Nie pomijaj zaleznosci, ktorych uzywasz wewnatrz — wlacz ESLint plugin react-hooks
  • Do data fetchingu w 2026 lepiej uzyj Tanstack Query lub Server Components

useContext

Wspoldzielenie wartosci miedzy komponentami bez prop drillingu. Tworzysz Context, owijasz drzewo Providerem, a glebiej czytasz wartosc.

// theme-context.jsx
import { createContext, useContext, useState } from 'react';

const ThemeContext = createContext(null);

export function ThemeProvider({ children }) {
  const [theme, setTheme] = useState('dark');
  return (
    <ThemeContext.Provider value={{ theme, setTheme }}>
      {children}
    </ThemeContext.Provider>
  );
}

export const useTheme = () => {
  const ctx = useContext(ThemeContext);
  if (!ctx) throw new Error('useTheme musi byc wewnatrz ThemeProvider');
  return ctx;
};

// Uzycie
function Header() {
  const { theme, setTheme } = useTheme();
  return <button onClick={() => setTheme(theme === 'dark' ? 'light' : 'dark')}>Tryb: {theme}</button>;
}

useReducer

Alternatywa dla useState gdy logika jest zlozona lub stan jest zagniezdzony. Pattern znany z Reduxa.

function reducer(state, action) {
  switch (action.type) {
    case 'add':    return [...state, { id: Date.now(), text: action.text, done: false }];
    case 'toggle': return state.map(t => t.id === action.id ? { ...t, done: !t.done } : t);
    case 'remove': return state.filter(t => t.id !== action.id);
    default: throw new Error('Nieznany typ: ' + action.type);
  }
}

function TodoList() {
  const [todos, dispatch] = useReducer(reducer, []);
  return (
    <ul>
      {todos.map(t => (
        <li key={t.id} onClick={() => dispatch({ type: 'toggle', id: t.id })}>
          {t.text} {t.done && '(zrobione)'}
        </li>
      ))}
    </ul>
  );
}

useMemo i useCallback

Memoizacja kosztownych obliczen lub funkcji. Uwaga: w React 19 z React Compilerem ich potrzeba znika — kompilator robi to automatycznie.

// useMemo — memoizuje wartosc
const sortedItems = useMemo(
  () => items.slice().sort((a, b) => a.price - b.price),
  [items]
);

// useCallback — memoizuje funkcje
const handleAdd = useCallback((id) => {
  setCart(prev => [...prev, id]);
}, []);

Kiedy NIE uzywac useMemo/useCallback

  • Dla prostych obliczen — narzut wiekszy niz korzysc
  • Gdy nie ma realnego problemu wydajnosci (zmierz najpierw!)
  • W projekcie z React Compilerem — jest zbedny
  • Pamiataj: useMemo to cache, ktory tez zajmuje pamiec

useRef

Mutowalna wartosc trwajaca przez cykl zycia komponentu, ktora nie powoduje rerenderu. Dwa zastosowania: referencja do DOM lub mutowalna wartosc.

// 1. Referencja do DOM
function FocusInput() {
  const inputRef = useRef(null);
  return (
    <>
      <input ref={inputRef} />
      <button onClick={() => inputRef.current.focus()}>Focus</button>
    </>
  );
}

// 2. Mutowalna wartosc (np. id timera, poprzednia wartosc)
function Timer() {
  const intervalRef = useRef(null);
  const [seconds, setSeconds] = useState(0);

  const start = () => {
    intervalRef.current = setInterval(() => setSeconds(s => s + 1), 1000);
  };
  const stop = () => clearInterval(intervalRef.current);

  return <>...</>;
}

useTransition i useDeferredValue

Concurrent features — oznaczanie aktualizacji jako nie-pilne aby UI pozostal responsywny.

const [isPending, startTransition] = useTransition();

const handleSearch = (q) => {
  setQuery(q); // pilne — aktualizuje input natychmiast
  startTransition(() => {
    setResults(filterBigList(q)); // moze byc opoznione
  });
};

return (
  <>
    <input value={query} onChange={e => handleSearch(e.target.value)} />
    {isPending ? <Spinner /> : <Results items={results} />}
  </>
);

// useDeferredValue — "cien" wartosci, ktora moze sie aktualizowac asynchronicznie
const deferredQuery = useDeferredValue(query);
<Results query={deferredQuery} />

useId

Generuje stabilny unikalny ID, bezpieczny dla SSR. Idealne dla labelek formularzy.

function PasswordField() {
  const id = useId();
  return (
    <>
      <label htmlFor={id}>Haslo</label>
      <input id={id} type="password" />
    </>
  );
}

Custom Hooks

Funkcja zaczynajaca sie od use, ktora kapsuluje logike z hookow. Reuzywalna miedzy komponentami.

// useDebounce — opozniona wartosc
import { useState, useEffect } from 'react';

export function useDebounce(value, delay = 500) {
  const [debounced, setDebounced] = useState(value);
  useEffect(() => {
    const id = setTimeout(() => setDebounced(value), delay);
    return () => clearTimeout(id);
  }, [value, delay]);
  return debounced;
}

// Uzycie
function Search() {
  const [q, setQ] = useState('');
  const debouncedQ = useDebounce(q, 300);

  useEffect(() => {
    if (debouncedQ) fetchResults(debouncedQ);
  }, [debouncedQ]);

  return <input value={q} onChange={e => setQ(e.target.value)} />;
}
// useFetch — prosty hook do GET (w produkcji uzyj Tanstack Query)
export function useFetch(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    let cancelled = false;
    setLoading(true);
    fetch(url)
      .then(r => r.json())
      .then(d => { if (!cancelled) setData(d); })
      .catch(e => { if (!cancelled) setError(e); })
      .finally(() => { if (!cancelled) setLoading(false); });
    return () => { cancelled = true; };
  }, [url]);

  return { data, loading, error };
}
