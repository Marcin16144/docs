Meta-frameworki

Next.js 15, Remix/React Router 7, Astro, Tanstack Start

Czemu meta-framework?

Sam React to tylko warstwa UI. Aby zbudowac produkcyjna aplikacje potrzebujesz: routing, SSR/SSG, optymalizacje (obrazy, fonty), code splitting, data layer, deployment. Meta-frameworki dostarczaja to wszystko + Server Components.

Next.js 15

Next.js — #1 framework React (od Vercel). W wersji 15 (2024+) wszystko obraca sie wokol App Router (Server Components default).

Glowne features Next.js 15

  • App Router — file-based routing z folderami
  • Server Components default — wszystko serwer, "use client" gdy potrzeba
  • Server Actions — mutations bez API endpointow
  • Partial Prerendering (PPR) — statyczna shell + streaming dynamiczne czesci
  • Turbopack — nowy bundler (Rust), 10x szybszy dev (stable w 15.0)
  • Async Request APIs — cookies(), headers(), params sa Promise (Next 15)
  • next/image, next/font — auto optymalizacje

Partial Prerendering (PPR)

Najwiekszy nowy paradygmat. Strona ma statyczna shell (pre-rendered HTML) z dziurami dla dynamicznych czesci ktore streamuja sie w runtime.

// app/page.tsx
export const experimental_ppr = true;

export default function Page() {
  return (
    <>
      <StaticHeader /> {/* pre-renderowane */}
      <Suspense fallback={<Skeleton />}>
        <UserCart /> {/* dynamic, streamuje sie po hydratacji */}
      </Suspense>
      <StaticFooter />
    </>
  );
}

Remix / React Router 7

W 2024 Remix polaczyl sie z React Router. Obecna wersja (React Router 7) ma dwa tryby: SPA mode i Framework mode (dawny Remix).

Filozofia Remix

  • Web fundamentals first — FormData, Request, Response, cookies
  • Loaders i actions per route
  • Nested routes z paralelnym data loading
  • Progressive enhancement — dziala bez JS
# Tworzenie
npx create-react-router@latest my-app --template framework

// app/routes/products.$id.tsx
import { Form, useLoaderData } from 'react-router';
import type { Route } from './+types/products.$id';

export async function loader({ params }: Route.LoaderArgs) {
  return await db.products.find(params.id);
}

export async function action({ request, params }: Route.ActionArgs) {
  const fd = await request.formData();
  await db.products.update(params.id, {
    name: fd.get('name') as string,
  });
  return { ok: true };
}

export default function Product() {
  const product = useLoaderData<typeof loader>();
  return (
    <Form method="post">
      <input name="name" defaultValue={product.name} />
      <button>Zapisz</button>
    </Form>
  );
}

Astro

Astro — framework dla content-heavy sites (blogi, dokumentacja, marketing). Zero JS by default, islands architecture — wybrane komponenty hydratuja sie selektywnie.

# Instalacja
npm create astro@latest

# Dodanie React integration
npx astro add react

---
// src/pages/index.astro
import ReactCounter from '../components/Counter';
const posts = await fetch('https://api.example.com/posts').then(r => r.json());
---

<html>
  <head><title>Mojstrona</title></head>
  <body>
    <h1>Posty</h1>
    {posts.map(p => <article><h2>{p.title}</h2></article>)}

    <!-- React island - hydrate dopiero w viewport -->
    <ReactCounter client:visible />

    <!-- Hydrate od razu -->
    <ReactCounter client:load />

    <!-- Tylko desktop -->
    <ReactCounter client:media="(min-width: 768px)" />
  </body>
</html>

Astro — kiedy uzywac?

  • Blog, dokumentacja, marketing site — idealne
  • Mocno content-heavy z odrobina interakcji
  • Mozesz miksowac React z Vue, Svelte, Solid w jednej stronie
  • Lighthouse 100/100/100/100 latwo osiagalne

Nie nadaje sie do mocno interaktywnych SPA (dashboardy, edytory, social).

Tanstack Start (nowy 2025)

Tanstack Start — full-stack framework od tworcow Tanstack Query/Router. Type-safe od podstaw, oparty na Vite, server functions.

npm create @tanstack/start@latest my-app

// app/routes/posts.$id.tsx
import { createFileRoute } from '@tanstack/react-router';
import { createServerFn } from '@tanstack/start';

const getPost = createServerFn('GET', async (id: string) => {
  return await db.posts.find(id);
});

export const Route = createFileRoute('/posts/$id')({
  loader: ({ params }) => getPost(params.id),
  component: Post,
});

function Post() {
  const post = Route.useLoaderData(); // typed
  return <h1>{post.title}</h1>;
}
