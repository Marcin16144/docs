Minimal APIs (.NET 6+)

Route handlers, parameter binding, TypedResults, filtry, grupy i integracja z OpenAPI

Czym sa Minimal APIs?

Minimal APIs to podejscie wprowadzone w .NET 6, ktore pozwala definiowac endpointy HTTP bezposrednio w Program.cs bez klas kontrolerow. Cel to redukcja plytki i szybsze pisanie prostych API. W .NET 9 Minimal APIs sa w pelni dojrzale i wspieraja wszystkie funkcje MVC.

Kiedy wybrac Minimal API zamiast kontrolerow?
  • Mikrouslugi z malym zestawem endpointow
  • Projekty gdzie prostota i szybkosc startu sa priorytetem
  • Serwisy lambda / Azure Functions (podobny model programowania)
  • Prototypowanie i POC

Route handlers — MapGet/MapPost/MapPut/MapDelete/MapPatch

var app = builder.Build();

// GET — pobierz liste
app.MapGet("/products", async (IProductRepository repo) =>
{
    var products = await repo.GetAllAsync();
    return Results.Ok(products);
});

// GET — pobierz pojedynczy rekord
app.MapGet("/products/{id:int}", async (int id, IProductRepository repo) =>
{
    var product = await repo.GetByIdAsync(id);
    return product is null
        ? Results.NotFound(new { message = $"Produkt {id} nie istnieje" })
        : Results.Ok(product);
});

// POST — utworz
app.MapPost("/products", async (
    CreateProductRequest request,
    IProductRepository repo,
    LinkGenerator links,
    HttpContext ctx) =>
{
    var product = await repo.CreateAsync(request);
    var uri = links.GetPathByName(ctx, "GetProductById", new { id = product.Id });
    return Results.Created(uri, product);
})
.WithName("CreateProduct")
.RequireAuthorization();

// PUT — aktualizuj
app.MapPut("/products/{id:int}", async (
    int id,
    UpdateProductRequest request,
    IProductRepository repo) =>
{
    var updated = await repo.UpdateAsync(id, request);
    return updated is null ? Results.NotFound() : Results.Ok(updated);
});

// PATCH — czesciowa aktualizacja
app.MapPatch("/products/{id:int}/price", async (
    int id,
    [FromBody] decimal newPrice,
    IProductRepository repo) =>
{
    await repo.UpdatePriceAsync(id, newPrice);
    return Results.NoContent();
});

// DELETE
app.MapDelete("/products/{id:int}", async (int id, IProductRepository repo) =>
{
    var deleted = await repo.DeleteAsync(id);
    return deleted ? Results.NoContent() : Results.NotFound();
})
.RequireAuthorization("AdminOnly");

Parameter binding

Minimal APIs automatycznie rozpoznaja zrodlo parametru na podstawie jego nazwy i atrybutow. Mozna to nadpisac jawnie:

AtrybutZrodloPrzyklad
[FromQuery]Query string?page=2&size=10
[FromRoute]Segment URL/products/{id}
[FromBody]Cialo zadania (JSON)POST body
[FromHeader]Naglowek HTTPX-Api-Key: abc
[FromServices]Kontener DIWstrzykniecie serwisu
[AsParameters]Obiekt zbiorczyGrupowanie parametrow
 
// Automatyczne bindowanie
app.MapGet("/search", (
    [FromQuery] string? query,
    [FromQuery] int page = 1,
    [FromQuery] int size = 20,
    [FromHeader(Name = "X-Api-Version")] string? apiVersion,
    ISearchService searchService) =>
{
    return searchService.Search(query, page, size);
});

// AsParameters — grupowanie w rekord
record ProductSearchParams(
    [FromQuery] string? Name,
    [FromQuery] decimal? MinPrice,
    [FromQuery] decimal? MaxPrice,
    [FromQuery] int Page = 1,
    [FromQuery] int PageSize = 20);

app.MapGet("/products/search", ([AsParameters] ProductSearchParams p,
    IProductRepository repo) =>
    repo.SearchAsync(p.Name, p.MinPrice, p.MaxPrice, p.Page, p.PageSize));

TypedResults — silnie typowane odpowiedzi

TypedResults (dostepne od .NET 7) jest preferowana alternatywa dla Results. Zwracane typy sa statycznie znane, co umozliwia automatyczne generowanie OpenAPI bez dodatkowych adnotacji.

// TypedResults zamiast Results
app.MapGet("/products/{id:int}", async Task<Results<Ok<Product>, NotFound>>(
    int id, IProductRepository repo) =>
{
    var product = await repo.GetByIdAsync(id);
    return product is null
        ? TypedResults.NotFound()
        : TypedResults.Ok(product);
})
.WithName("GetProductById");

app.MapPost("/products", async Task<Results<Created<Product>, ValidationProblem>>(
    CreateProductRequest request,
    IValidator<CreateProductRequest> validator,
    IProductRepository repo) =>
{
    var validation = await validator.ValidateAsync(request);
    if (!validation.IsValid)
        return TypedResults.ValidationProblem(validation.ToDictionary());

    var product = await repo.CreateAsync(request);
    return TypedResults.Created($"/products/{product.Id}", product);
});

Endpoint Filters — IEndpointFilter

Filtry pozwalaja na przekrojowe przetwarzanie zadan — walidacje, logowanie, rate limiting — bez powielania kodu w kazdym handlerze.

// Definicja filtra
public class ValidationFilter<TRequest> : IEndpointFilter
{
    private readonly IValidator<TRequest> _validator;

    public ValidationFilter(IValidator<TRequest> validator)
    {
        _validator = validator;
    }

    public async ValueTask<object?> InvokeAsync(
        EndpointFilterInvocationContext context,
        EndpointFilterDelegate next)
    {
        var request = context.Arguments
            .OfType<TRequest>()
            .FirstOrDefault();

        if (request is not null)
        {
            var result = await _validator.ValidateAsync(request);
            if (!result.IsValid)
                return Results.ValidationProblem(result.ToDictionary());
        }

        return await next(context);
    }
}

// Uzywanie filtra
app.MapPost("/products", CreateProductHandler)
   .AddEndpointFilter<ValidationFilter<CreateProductRequest>>();

// Inline filter (krotki)
app.MapDelete("/products/{id:int}", DeleteProductHandler)
   .AddEndpointFilter(async (ctx, next) =>
   {
       var id = ctx.GetArgument<int>(0);
       if (id <= 0) return Results.BadRequest("Id musi byc > 0");
       return await next(ctx);
   });

Route Groups — organizacja endpointow

Grupy pozwalaja wspoldzielic prefix, middleware, filtry i metadane miedzy wieloma endpointami bez powtarzania kodu.

// Grupowanie z wspolnym prefixem i autoryzacja
var productsGroup = app.MapGroup("/api/v1/products")
    .RequireAuthorization()
    .WithTags("Products")
    .WithOpenApi();

productsGroup.MapGet("/", GetAllProducts);
productsGroup.MapGet("/{id:int}", GetProductById).WithName("GetProductById");
productsGroup.MapPost("/", CreateProduct)
    .AddEndpointFilter<ValidationFilter<CreateProductRequest>>();
productsGroup.MapPut("/{id:int}", UpdateProduct);
productsGroup.MapDelete("/{id:int}", DeleteProduct);

// Grupy zagniezdzane
var adminGroup = app.MapGroup("/api/admin")
    .RequireAuthorization("AdminPolicy");

var adminProducts = adminGroup.MapGroup("/products");
adminProducts.MapPost("/bulk-delete", BulkDeleteProducts);
adminProducts.MapPost("/reindex", ReindexProducts);

Kompletne CRUD Minimal API — przyklad

// --- Models ---
public record Product(int Id, string Name, decimal Price, int Stock);
public record CreateProductRequest(string Name, decimal Price, int Stock);
public record UpdateProductRequest(string Name, decimal Price, int Stock);

// --- Program.cs ---
var builder = WebApplication.CreateBuilder(args);
builder.Services.AddScoped<IProductRepository, ProductRepository>();
builder.Services.AddScoped<IValidator<CreateProductRequest>,
    CreateProductValidator>();
builder.Services.AddOpenApi();
builder.Services.AddAuthentication().AddJwtBearer();
builder.Services.AddAuthorization();

var app = builder.Build();
app.MapOpenApi();

var api = app.MapGroup("/api/products")
    .WithTags("Products");

api.MapGet("/", async (
    [FromQuery] int page,
    [FromQuery] int size,
    IProductRepository repo,
    CancellationToken ct) =>
{
    var result = await repo.GetPagedAsync(page, size, ct);
    return TypedResults.Ok(result);
});

api.MapGet("/{id:int}", async Task<Results<Ok<Product>, NotFound>>(
    int id, IProductRepository repo, CancellationToken ct) =>
{
    var p = await repo.GetByIdAsync(id, ct);
    return p is null ? TypedResults.NotFound() : TypedResults.Ok(p);
}).WithName("GetById");

api.MapPost("/", async Task<Results<Created<Product>, ValidationProblem>>(
    CreateProductRequest req,
    IValidator<CreateProductRequest> validator,
    IProductRepository repo,
    CancellationToken ct) =>
{
    var v = await validator.ValidateAsync(req, ct);
    if (!v.IsValid) return TypedResults.ValidationProblem(v.ToDictionary());
    var p = await repo.CreateAsync(req, ct);
    return TypedResults.Created($"/api/products/{p.Id}", p);
}).RequireAuthorization();

api.MapPut("/{id:int}", async Task<Results<Ok<Product>, NotFound, ValidationProblem>>(
    int id, UpdateProductRequest req,
    IValidator<UpdateProductRequest> validator,
    IProductRepository repo,
    CancellationToken ct) =>
{
    var v = await validator.ValidateAsync(req, ct);
    if (!v.IsValid) return TypedResults.ValidationProblem(v.ToDictionary());
    var p = await repo.UpdateAsync(id, req, ct);
    return p is null ? TypedResults.NotFound() : TypedResults.Ok(p);
}).RequireAuthorization();

api.MapDelete("/{id:int}", async Task<Results<NoContent, NotFound>>(
    int id, IProductRepository repo, CancellationToken ct) =>
{
    var deleted = await repo.DeleteAsync(id, ct);
    return deleted ? TypedResults.NoContent() : TypedResults.NotFound();
}).RequireAuthorization("AdminOnly");

app.Run();
Uwaga — walidacja w Minimal APIs: W odroznieniu od kontrolerow z [ApiController], Minimal APIs NIE wykonuja automatycznej walidacji Data Annotations. Musisz recznie wywolac walidator (FluentValidation) lub uzyc filtra.

Integracja z OpenAPI (.NET 9)

// .NET 9 — wbudowane OpenAPI (bez Swashbuckle)
builder.Services.AddOpenApi(options =>
{
    options.AddDocumentTransformer((doc, ctx, ct) =>
    {
        doc.Info.Title = "Products API";
        doc.Info.Version = "v1";
        return Task.CompletedTask;
    });
});

app.MapOpenApi();  // dostepne pod /openapi/v1.json

// Metadane endpointu
api.MapGet("/", GetAllProducts)
   .WithSummary("Pobierz liste produktow")
   .WithDescription("Zwraca stronicowana liste produktow z opcjonalnym filtrowaniem.")
   .Produces<PagedResult<Product>>(200)
   .WithOpenApi();
