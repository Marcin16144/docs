Glowna / API / Rust

API w Rust

Axum, Actix-web, Rocket, Warp. Tokio async runtime. Performance + safety.

Podstawy Rust API

Cargo, tokio runtime, async/await, ownership basics dla API dev. Fundament — rozumienie modelu pamieci w kontekscie HTTP.

Axum Framework

Router, handlers, extractors (Json/Path/Query/State), layers. Oficjalny framework tokio — typesafe, composable, wydajny.

Axum zaawansowany

Middleware (tower), error handling, shared state, WebSocket. Zaawansowane wzorce — tower ecosystem i obsługa bledow.

Actix-web

Actor model (opcjonalnie), App factory, extractors, guards. Jeden z najszybszych frameworkow HTTP na swiecie.

Rocket

Code-gen routing, fairings (middleware), request guards, responders. Ergonomiczny framework — developer experience na pierwszym miejscu.

SQLx

Async queries, compile-time query checking, migrations, PostgreSQL. SQL sprawdzany w czasie kompilacji — zero runtime surprises.

SeaORM

Async ORM, migrations, relationships, query builder. Nowoczesny ORM dla Rusta — asynchroniczny i typesafe.

Uwierzytelnianie

jsonwebtoken crate, OAuth2 (oauth2 crate), middleware tower. JWT i OAuth2 w Rust — implementacja i integracja z Axum.

Testing

#[tokio::test], reqwest (HTTP client), testcontainers-rs, wiremock-rs. Testowanie async API — unit, integracyjne, kontrakty.

Deployment

cargo build --release, Docker (distroless), musl static binary, K8s. Minimalne obrazy — kilka MB, zero zaleznosci runtime.
