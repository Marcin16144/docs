Glowna / API / PHP

API w PHP

Symfony API Platform, Laravel API, Slim, Phalcon. REST + OpenAPI.

Podstawy PHP API

PSR-7/15 (request/response), Composer, autoloading. Standardy PHP — fundament nowoczesnego API.

Laravel API Resources

Resource/Collection, API routes, form requests. Transformacja danych i wersjonowanie API w Laravel.

Laravel Sanctum + Passport

API tokens, OAuth2 server, SPA auth. Kompletne rozwiazanie autentykacji dla aplikacji Laravel.

Symfony API Platform

HAL/JSON-LD, filters, serialization groups, GraphQL. Najpotezniejsze narzedzie API dla PHP.

Slim Framework

Routing, PSR-15 middleware, DI (PHP-DI). Lekki mikro-framework — idealny do prostych REST API.

Eloquent ORM

Relationships, eager loading, query builder, migrations. ActiveRecord ORM Laravel — wzorce i optymalizacja.

Doctrine ORM

Entity, Repository, DQL, migrations (Symfony). DataMapper pattern — zaawansowane mapowanie obiektowo-relacyjne.

Walidacja i bezpieczenstwo

Laravel validation, Symfony constraints, CORS, rate limiting. Ochrona API przed naduzywaniem i nieprawidlowymi danymi.

OpenAPI z PHP

L5-Swagger (Laravel), NelmioApiDocBundle (Symfony), auto-gen. Dokumentacja API generowana automatycznie z kodu.

Deployment

PHP-FPM + Nginx, Laravel Octane (Swoole/FrankenPHP), Docker. Produkcyjne srodowisko PHP — konfiguracja i skalowanie.
