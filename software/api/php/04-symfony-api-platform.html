Symfony API Platform

ApiResource, operacje, serializacja, filtry, GraphQL, JSON-LD i Mercure

Czym jest API Platform?

API Platform to framework zbudowany na Symfony, zaprojektowany specjalnie do tworzenia API. Automatycznie generuje endpointy CRUD, dokumentacje OpenAPI, obsluge JSON-LD/Hydra oraz GraphQL na podstawie prostych klas PHP opatrzonych atrybutami. To podejscie "API-first" — definiujesz model, a infrastruktura powstaje automatycznie.

Instalacja API Platform 
# Nowy projekt Symfony z API Platform
composer create-project api-platform/api-platform my-api

# Lub dodanie do istniejacego projektu Symfony
composer require api-platform/core

# Uruchomienie dev serwera
symfony serve --daemon

# API dostepne pod: https://localhost:8000/api
# Swagger UI:       https://localhost:8000/api/docs
# JSON-LD context:  https://localhost:8000/api/contexts/Product

ApiResource — definicja zasobu

Atrybut #[ApiResource] przeksztalca zwykla klase PHP (encje Doctrine lub dowolna klase) w zasob API. API Platform automatycznie generuje wszystkie operacje REST, dokumentacje OpenAPI i obsluge wielu formatow (JSON, JSON-LD, CSV, XML).

<?php

namespace App\Entity;

use ApiPlatform\Metadata\ApiResource;
use ApiPlatform\Metadata\Get;
use ApiPlatform\Metadata\GetCollection;
use ApiPlatform\Metadata\Post;
use ApiPlatform\Metadata\Put;
use ApiPlatform\Metadata\Patch;
use ApiPlatform\Metadata\Delete;
use ApiPlatform\Metadata\ApiFilter;
use ApiPlatform\Doctrine\Orm\Filter\SearchFilter;
use ApiPlatform\Doctrine\Orm\Filter\RangeFilter;
use ApiPlatform\Doctrine\Orm\Filter\DateFilter;
use Doctrine\ORM\Mapping as ORM;
use Symfony\Component\Serializer\Annotation\Groups;
use Symfony\Component\Validator\Constraints as Assert;

#[ApiResource(
    shortName: 'Product',
    description: 'Zasob reprezentujacy produkt w katalogu',
    operations: [
        new GetCollection(normalizationContext: ['groups' => ['product:list']]),
        new Get(normalizationContext: ['groups' => ['product:detail']]),
        new Post(
            normalizationContext:   ['groups' => ['product:detail']],
            denormalizationContext: ['groups' => ['product:write']],
            security: "is_granted('ROLE_ADMIN')"
        ),
        new Put(
            denormalizationContext: ['groups' => ['product:write']],
            security: "is_granted('ROLE_ADMIN') or object.getOwner() == user"
        ),
        new Patch(
            denormalizationContext: ['groups' => ['product:write']],
            security: "is_granted('ROLE_ADMIN')"
        ),
        new Delete(security: "is_granted('ROLE_ADMIN')"),
    ],
    paginationItemsPerPage: 20,
    paginationMaximumItemsPerPage: 100,
)]
#[ApiFilter(SearchFilter::class, properties: [
    'name'     => 'partial',  // LIKE %name%
    'category' => 'exact',    // category = ?
    'sku'      => 'start',    // LIKE sku%
])]
#[ApiFilter(RangeFilter::class, properties: ['price', 'stock'])]
#[ApiFilter(DateFilter::class, properties: ['createdAt'])]
#[ORM\Entity]
class Product
{
    #[ORM\Id, ORM\GeneratedValue, ORM\Column]
    #[Groups(['product:list', 'product:detail'])]
    private ?int $id = null;

    #[ORM\Column(length: 255)]
    #[Assert\NotBlank, Assert\Length(min: 2, max: 255)]
    #[Groups(['product:list', 'product:detail', 'product:write'])]
    private string $name = '';

    #[ORM\Column(type: 'decimal', precision: 10, scale: 2)]
    #[Assert\Positive]
    #[Groups(['product:list', 'product:detail', 'product:write'])]
    private string $price = '0.00';

    #[ORM\Column(type: 'text', nullable: true)]
    #[Groups(['product:detail', 'product:write'])]
    private ?string $description = null;

    #[ORM\Column]
    #[Groups(['product:detail'])]
    private \DateTimeImmutable $createdAt;

    public function __construct()
    {
        $this->createdAt = new \DateTimeImmutable();
    }

    // Gettery i settery...
    public function getId(): ?int { return $this->id; }
    public function getName(): string { return $this->name; }
    public function setName(string $name): static { $this->name = $name; return $this; }
    public function getPrice(): string { return $this->price; }
    public function setPrice(string $price): static { $this->price = $price; return $this; }
}

Grupy serializacji (#[Groups])

Grupy serializacji to mechanizm kontrolujacy, ktore pola encji sa widoczne w odpowiedziach API i ktore moga byc zapisywane przez klientow. Kazda operacja moze miec inny normalizationContext (do JSON) i denormalizationContext (z JSON). Dzieki temu mozna na przyklad udostepniac mniej pol w kolekcji (szybciej) a wiecej w szczegolach pojedynczego zasobu.

Custom State Providers i Processors

State Providers zastepuja domyslna integracje z Doctrine — uzyteczne gdy dane pochodza z zewnetrznego API, cache'u Redis lub innego zrodla. State Processors definiuja co dzieje sie z danymi przy zapisie (POST/PUT/PATCH/DELETE).

<?php

namespace App\State;

use ApiPlatform\Metadata\Operation;
use ApiPlatform\State\ProviderInterface;
use App\Repository\ProductRepository;

// Custom Provider — pobieranie danych ze specyficznego zrodla
class ProductProvider implements ProviderInterface
{
    public function __construct(
        private readonly ProductRepository $repository,
    ) {}

    public function provide(
        Operation $operation,
        array $uriVariables = [],
        array $context = []
    ): object|array|null {
        // Dla operacji GetCollection
        if ($operation instanceof GetCollection) {
            return $this->repository->findAllWithCache();
        }

        // Dla operacji Get (pojedynczy zasob)
        return $this->repository->findWithRelations($uriVariables['id']);
    }
}

// Custom Processor — logika przy zapisie
class ProductProcessor implements ProcessorInterface
{
    public function __construct(
        private readonly EntityManagerInterface $em,
        private readonly SluggerInterface $slugger,
    ) {}

    public function process(
        mixed $data,
        Operation $operation,
        array $uriVariables = [],
        array $context = []
    ): Product {
        // Automatyczne generowanie slug przed zapisem
        $data->setSlug($this->slugger->slug($data->getName())->lower());

        $this->em->persist($data);
        $this->em->flush();

        return $data;
    }
}

JSON-LD i Hydra

API Platform domyslnie serwuje odpowiedzi w formacie JSON-LD z rozszerzeniem Hydra. JSON-LD to standard W3C dodajacy kontekst semantyczny do JSON — kazdy zasob ma unikalny @id (IRI) i @type. Hydra rozszerza JSON-LD o opis operacji API (hypermedia). Dzieki temu klienci moga dynamicznie odkrywac mozliwosci API bez znajomosci dokumentacji.

GraphQL — wbudowane wsparcie

API Platform posiada wbudowane wsparcie GraphQL — bez dodatkowej konfiguracji API jest dostepne rowniez przez endpoint GraphQL. Automatycznie generuje schemat GraphQL na podstawie atrybutow ApiResource, obsluguje queries, mutations i subscriptions (przez Mercure).

Mercure — real-time push

Mercure to protokol oparty na Server-Sent Events (SSE) do wysylania aktualizacji w czasie rzeczywistym z serwera do klientow. API Platform integruje sie z Mercure — po kazdym zapisie zasobu automatycznie publikuje aktualizacje do zasubskrybowanych klientow.

OpenAPI — automatyczna dokumentacja

API Platform automatycznie generuje specyfikacje OpenAPI 3.x na podstawie atrybutow PHP. Dokumentacja jest dostepna pod /api/docs.json (JSON) i /api/docs.yaml (YAML). Wbudowany Swagger UI jest dostepny pod /api/docs.
