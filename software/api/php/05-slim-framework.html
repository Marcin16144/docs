Slim Framework

Mikro-framework PHP oparty na PSR-7 i PSR-15 — routing, middleware, DI i obsluga bledow

Czym jest Slim?

Slim to mikro-framework PHP zaprojektowany specjalnie do budowania API i mikroserwisow. W odroznieniu od pelnych frameworkow jak Laravel czy Symfony, Slim nie narzuca struktury projektu — dostarcza jedynie routing, middleware pipeline i obserwacje PSR-7/PSR-15. Dzieki temu jest ekstremalnie lekki i szybki, a programista sam decyduje, jakich bibliotek uzywa.

Slim 4.x (aktualna wersja) jest w pelni zgodny ze standardami PSR-7, PSR-11 (Container) i PSR-15 (Middleware), co umozliwia wymiane komponentow bez zmiany kodu aplikacji.

Instalacja Slim 4 
# Core frameworka
composer require slim/slim:"4.*"

# Implementacja PSR-7 (wymagana — Slim nie ma wlasnej)
composer require slim/psr7
# Alternatywa: nyholm/psr7 + nyholm/psr7-server

# PHP-DI jako kontener PSR-11
composer require php-di/php-di

# Opcjonalnie — do logowania
composer require monolog/monolog

Podstawowa aplikacja Slim

Aplikacja Slim tworzona jest przez AppFactory. Jesli kontener PSR-11 jest ustawiony przed utworzeniem aplikacji, Slim automatycznie uzywa go do rozwiazywania zaleznosci w handlerach tras.

<?php

use DI\ContainerBuilder;
use Slim\Factory\AppFactory;
use Slim\Middleware\ErrorMiddleware;
use Psr\Http\Message\ResponseInterface as Response;
use Psr\Http\Message\ServerRequestInterface as Request;

require __DIR__ . '/../vendor/autoload.php';

// 1. Budowanie kontenera PHP-DI
$containerBuilder = new ContainerBuilder();

// Rejestracja zaleznosci w kontenerze
$containerBuilder->addDefinitions([
    // PDO — polaczenie z baza danych
    PDO::class => function () {
        return new PDO(
            dsn: 'mysql:host=127.0.0.1;dbname=myapp;charset=utf8mb4',
            username: $_ENV['DB_USER'],
            password: $_ENV['DB_PASS'],
            options: [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]
        );
    },

    // Monolog logger
    \Psr\Log\LoggerInterface::class => function () {
        $logger = new \Monolog\Logger('api');
        $logger->pushHandler(new \Monolog\Handler\StreamHandler(
            'php://stdout',
            \Monolog\Level::Info
        ));
        return $logger;
    },
]);

$container = $containerBuilder->build();

// 2. Tworzenie aplikacji Slim z kontenerem
AppFactory::setContainer($container);
$app = AppFactory::create();

// 3. Routing — podstawowe metody HTTP
$app->get('/api/health', function (Request $request, Response $response): Response {
    $payload = json_encode(['status' => 'ok', 'timestamp' => time()]);
    $response->getBody()->write($payload);
    return $response->withHeader('Content-Type', 'application/json');
});

$app->get('/api/users/{id}', function (Request $request, Response $response, array $args): Response {
    $id = (int) $args['id'];
    // $this->get(PDO::class) dziala dzieki kontenerowi
    $stmt = $this->get(PDO::class)->prepare('SELECT id, name, email FROM users WHERE id = ?');
    $stmt->execute([$id]);
    $user = $stmt->fetch(PDO::FETCH_ASSOC);

    if (!$user) {
        $response->getBody()->write(json_encode(['error' => 'Not found']));
        return $response->withStatus(404)->withHeader('Content-Type', 'application/json');
    }

    $response->getBody()->write(json_encode($user));
    return $response->withHeader('Content-Type', 'application/json');
});

$app->post('/api/users', function (Request $request, Response $response): Response {
    $data = (array) $request->getParsedBody();
    // ... walidacja i zapis
    $response->getBody()->write(json_encode(['id' => 42, ...$data]));
    return $response->withStatus(201)->withHeader('Content-Type', 'application/json');
});

$app->put('/api/users/{id}', function (Request $request, Response $response, array $args): Response {
    $id   = (int) $args['id'];
    $data = (array) $request->getParsedBody();
    // ... aktualizacja
    $response->getBody()->write(json_encode(['id' => $id, ...$data]));
    return $response->withHeader('Content-Type', 'application/json');
});

$app->delete('/api/users/{id}', function (Request $request, Response $response, array $args): Response {
    $id = (int) $args['id'];
    // ... usuniecie
    return $response->withStatus(204);
});

// 4. Middleware — dodawane przez add()
$app->add(new ErrorMiddleware(
    callableResolver:  $app->getCallableResolver(),
    responseFactory:   $app->getResponseFactory(),
    displayErrorDetails: ($_ENV['APP_ENV'] ?? 'prod') === 'dev',
    logErrors:         true,
    logErrorDetails:   true,
));

$app->run();

PSR-15 Middleware w Slim

Middleware dodaje sie metoda $app->add() lub $route->add() dla konkretnej trasy. Slim przetwarza middleware w kolejnosci LIFO (last in, first out) — ostatnio dodane middleware jest wykonywane jako pierwsze dla requestu.

<?php

namespace App\Middleware;

use Psr\Http\Message\ResponseInterface;
use Psr\Http\Message\ServerRequestInterface;
use Psr\Http\Server\MiddlewareInterface;
use Psr\Http\Server\RequestHandlerInterface;
use Psr\Log\LoggerInterface;

// Middleware do logowania requestow
class RequestLoggerMiddleware implements MiddlewareInterface
{
    public function __construct(
        private readonly LoggerInterface $logger
    ) {}

    public function process(
        ServerRequestInterface $request,
        RequestHandlerInterface $handler
    ): ResponseInterface {
        $start = microtime(true);

        $response = $handler->handle($request);

        $elapsed = round((microtime(true) - $start) * 1000, 2);

        $this->logger->info('HTTP Request', [
            'method'   => $request->getMethod(),
            'path'     => $request->getUri()->getPath(),
            'status'   => $response->getStatusCode(),
            'duration' => $elapsed . 'ms',
            'ip'       => $request->getServerParams()['REMOTE_ADDR'] ?? 'unknown',
        ]);

        return $response;
    }
}

// Middleware uwierzytelniania JWT (uproszczone)
class JwtAuthMiddleware implements MiddlewareInterface
{
    public function __construct(
        private readonly string $secretKey
    ) {}

    public function process(
        ServerRequestInterface $request,
        RequestHandlerInterface $handler
    ): ResponseInterface {
        $header = $request->getHeaderLine('Authorization');

        if (!preg_match('/^Bearer\s+(.+)$/', $header, $matches)) {
            // Zwrocenie 401 bez wywolania kolejnego handlera
            $factory = new \Slim\Psr7\Factory\ResponseFactory();
            $response = $factory->createResponse(401);
            $response->getBody()->write(json_encode(['error' => 'Unauthorized']));
            return $response->withHeader('Content-Type', 'application/json');
        }

        // Weryfikacja JWT i dolaczenie payload do atrybutow requestu
        $token   = $matches[1];
        $payload = $this->verifyJwt($token);
        $request = $request->withAttribute('user', $payload);

        return $handler->handle($request);
    }

    private function verifyJwt(string $token): array
    {
        // Uproszczona weryfikacja — w produkcji uzyj firebase/php-jwt
        [$header, $payload, $signature] = explode('.', $token);
        return json_decode(base64_decode($payload), true) ?? [];
    }
}

// Rejestracja middleware na konkretnej grupie tras
$app->group('/api/admin', function (\Slim\Routing\RouteCollectorProxy $group) {
    $group->get('/stats', AdminController::class . ':stats');
    $group->get('/users', AdminController::class . ':users');
})->add(new JwtAuthMiddleware($_ENV['JWT_SECRET']))
  ->add(new RequestLoggerMiddleware($container->get(LoggerInterface::class)));

PHP-DI — Dependency Injection

PHP-DI to zaawansowany kontener DI dla PHP z obsluga autowiring — automatycznego rozwiazywania zaleznosci na podstawie type hints w konstruktorach. Dzieki temu mozna wstrzykiwac zaleznosci do kontrolerow i serwisow bez recznej konfiguracji.

Obsluga bledow — ErrorMiddleware

Slim 4 obsluguje bledy przez ErrorMiddleware, ktory przechwytuje wyjatek i konwertuje go na odpowiednia odpowiedz HTTP. Mozna rejestrownac wlasne handlery dla konkretnych typow wyjatkow.

Customowy handler bledow 
$errorMiddleware = $app->addErrorMiddleware(true, true, true);

// Handler dla konkretnego wyjatku
$errorMiddleware->setErrorHandler(
    \App\Exception\ValidationException::class,
    function (Request $request, \Throwable $exception, bool $displayErrorDetails) use ($app): Response {
        $response = $app->getResponseFactory()->createResponse(422);
        $payload  = json_encode([
            'error'   => 'Validation failed',
            'details' => $exception->getErrors(), // metoda z wlasnego wyjatku
        ]);
        $response->getBody()->write($payload);
        return $response->withHeader('Content-Type', 'application/json');
    }
);
