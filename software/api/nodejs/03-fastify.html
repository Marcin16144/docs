Fastify

Wydajny, schema-first framework Node.js z pelnym wsparciem TypeScript i systemem pluginow

Dlaczego Fastify?

Fastify to framework webowy skupiony na maksymalnej wydajnosci i dobrej ergonomii deweloperskiej. Walidacja oparta na JSON Schema (kompilowana do szybkiego kodu przez ajv) pozwala osiagnac nawet 30 000 req/s na prostym endpoincie — znacznie wiecej niz Express. Poza wydajnoscia, Fastify oferuje: system pluginow z izolacja zaleznosci, hooki cyklu zycia, dekoratory i pelne wsparcie TypeScript out-of-the-box.

Fastify vs Express — kluczowa roznica

Express przetwarza JSON przez JSON.parse() bez walidacji. Fastify kompiluje schemat do zoptymalizowanego walidatora i serializatora — JSON odpowiedzi jest 2-5x szybszy niz JSON.stringify(). Schemat jest wymagany, nie opcjonalny.

Inicjalizacja i konfiguracja

import Fastify from 'fastify';
import cors from '@fastify/cors';
import helmet from '@fastify/helmet';
import compress from '@fastify/compress';

const fastify = Fastify({
  logger: {
    level: 'info',
    transport: process.env.NODE_ENV === 'development'
      ? { target: 'pino-pretty', options: { colorize: true } }
      : undefined, // produkcja: JSON do stdout (dla log aggregatorow)
  },
  ajv: {
    customOptions: {
      strict: 'log',       // ostrzez o nieznanych polach zamiast rzucac bledem
      allErrors: true,     // zbierz WSZYSTKIE bledy walidacji naraz
    }
  },
  trustProxy: true,        // wazne za reverse proxy (X-Forwarded-For)
});

// Rejestracja pluginow
await fastify.register(helmet);
await fastify.register(cors, {
  origin: ['https://myapp.com'],
  credentials: true,
});
await fastify.register(compress, { global: false }); // kompresja per-route

// Uruchomienie
await fastify.listen({ port: 3000, host: '0.0.0.0' });
console.log(fastify.server.address());

Walidacja schematu — JSON Schema i TypeBox

Kazda trasa w Fastify moze (i powinna) miec schemat. Fastify uzywa ajv do kompilacji schematu do funkcji walidacyjnej przy starcie, nie przy kazdym zapytaniu. Pakiet @sinclair/typebox pozwala pisac schematy jako typy TypeScript — zero duplikacji kodu.

import { Type, Static } from '@sinclair/typebox';

// Schemat zdefiniowany raz — uzyty do walidacji I typowania
const UserSchema = Type.Object({
  id:    Type.String({ format: 'uuid' }),
  name:  Type.String({ minLength: 2, maxLength: 100 }),
  email: Type.String({ format: 'email' }),
  role:  Type.Union([Type.Literal('admin'), Type.Literal('user')]),
  age:   Type.Optional(Type.Integer({ minimum: 0, maximum: 120 })),
});

type User = Static<typeof UserSchema>;  // TypeScript type z schematu

const CreateUserBody = Type.Omit(UserSchema, ['id']);
type CreateUserBody = Static<typeof CreateUserBody>;

// Trasa z pelnym typowaniem i walidacja
fastify.post<{ Body: CreateUserBody; Reply: User }>(
  '/users',
  {
    schema: {
      body: CreateUserBody,
      response: {
        201: UserSchema,
        400: Type.Object({ error: Type.String() }),
      },
    },
  },
  async (request, reply) => {
    // request.body jest w pelni typowany jako CreateUserBody
    const user = await userService.create(request.body);
    return reply.status(201).send(user);
    // Fastify serializuje odpowiedz uzywajac schematu — szybko i bezpiecznie
  }
);

Hooki cyklu zycia

Fastify definiuje precyzyjny cykl zycia zapytania. Hooki pozwalaja wtretic sie w kazdy etap. Sa rejestrowane przez fastify.addHook() (globalnie) lub jako opcja trasy (lokalnie).

Hook Etap Typowe zastosowanie Mozliwy wynik
onRequest Pierwsze zdarzenie — przed parsowaniem Rate limiting, metryki, IP blocking Przerwanie z reply.send()
preParsing Przed parsowaniem body Transformacja strumienia, HMAC weryfikacja body Modyfikacja strumienia
preValidation Przed walidacja schematu Deserializacja, transformacja danych wejsciowych Modyfikacja request.body
preHandler Przed handlerem trasy Autentykacja JWT, autoryzacja (RBAC) Przerwanie lub modyfikacja request
preSerialization Przed serializacja odpowiedzi Filtrowanie pol odpowiedzi, logowanie Modyfikacja payload
onSend Przed wyslaniem — po serializacji Ustawianie nagłówkow, kompresja Modyfikacja serializowanego payload
onResponse Po wyslaniu odpowiedzi Logowanie czasu odpowiedzi, metryki Tylko side effects
onError Po wystapnieniu bledu Mapowanie bledow, alerting Modyfikacja bledu 
// Hook globalny — autentykacja JWT dla wszystkich tras
fastify.addHook('preHandler', async (request, reply) => {
  try {
    await request.jwtVerify(); // @fastify/jwt dekorator
  } catch (err) {
    reply.status(401).send({ error: 'Brak autoryzacji' });
  }
});

// Hook lokalny — tylko dla tej trasy (nadpisuje globalny)
fastify.get('/public', {
  onRequest: [], // pusta tablica — brak hookow preHandler dla tej trasy
  handler: async (request, reply) => {
    return { message: 'Publiczny endpoint' };
  }
});

// Hook onSend — dodanie naglowkow
fastify.addHook('onSend', async (request, reply, payload) => {
  reply.header('X-Request-Id', request.id);
  reply.header('X-Response-Time', `${Date.now() - request.startTime}ms`);
  return payload; // zwroc niezmieniony payload
});

System pluginow i dekoratory

System pluginow Fastify oparty jest na Avvio — bibliotece asynchronicznej inicjalizacji z izolacja kontekstu. Kazdy plugin dostaje wlasny "zakres" — zmienne i dekoratory zarejestrowane wewnatrz nie sa widoczne na zewnatrz (chyba ze uzyjemy fastify-plugin).

fastify-plugin (fp)

Uzycie fastify-plugin (importowanego jako fp) wylacza enkapsulacje — plugin rejestruje swoje dekoratory w kontekscie nadrzednym. Uzywa sie go dla wspoldzielonych uslug: bazy danych, cache, konfiguracji.

Dekoratory

Dekoratory rozszerzaja instancje fastify, request lub reply o nowe wlasciwosci lub metody. Przykladowo @fastify/jwt dodaje request.jwtVerify() i reply.jwtSign().

reply.send vs return

W Fastify mozna wyslac odpowiedz na dwa sposoby. Oba sa poprawne, ale roznia sie semantyką w kontekscie hookow i asynchronicznosci.

  • return wartosci — Fastify automatycznie serializuje zwrocona wartosc i wysyla jako odpowiedz. Preferowany sposob w async handlerach.
  • reply.send(dane) — jawne wyslanie. Konieczne gdy chcesz wyslac odpowiedz wewnatrz callbacku lub gdy zwrocona wartosc ma byc inna niz payload odpowiedzi.
Uwaga: nie mieszaj return i reply.send()

Wywolanie reply.send() a nastepnie return innej wartosci spowoduje blad. Fastify wykrywa podwojne wysylanie i loguje ostrzezenie. Wybierz jeden styl i trzymaj sie go konsekwentnie w projekcie.

Kiedy wybrac Fastify?

Fastify to idealny wybor gdy: zalezy Ci na wydajnosci, pracujesz z TypeScript, chcesz schema-first development z automatyczna walidacja i serializacja, lub budujesz API, gdzie czas odpowiedzi jest krytyczny (fintech, gaming, IoT).
