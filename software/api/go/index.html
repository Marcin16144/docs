Glowna / API / Go

API w Go

net/http stdlib, Gin, Echo, Fiber, Chi. gRPC. Performance king.

Podstawy Go API

net/http, handler functions, ServeMux, goroutines + channels. Stdlib jako fundament — bez zewnetrznych zaleznosci.

Gin Framework

Routing, middleware, binding, validation (go-playground/validator). Najpopularniejszy framework Go — szybki i prosty.

Echo Framework

Routing groups, middleware chain, binder, validator. Elegancki framework z dobrym wsparciem dla WebSocket i HTTP/2.

Fiber

Express-inspired, fasthttp, middleware ecosystem. Najszybszy framework Go — idealny dla wysokiego throughput.

Chi

Lightweight, idiomatic, middleware composable. Minimalistyczny router — blizko stdlib, zero magic.

Database

database/sql, GORM, sqlx, pgx (PostgreSQL driver). Praca z bazami danych w Go — od raw SQL po ORM.

gRPC w Go

protoc-gen-go, gRPC server, streaming, interceptors. Wydajne API binarne — Protocol Buffers i generowanie kodu.

Uwierzytelnianie

golang-jwt/jwt, OAuth2 (golang.org/x/oauth2), Casbin (RBAC). Bezpieczne API — tokeny, role, polityki dostepu.

Testing

testing package, httptest, testify, gomock, integration tests. Testowanie API w Go — unit, integracyjne, benchmark.

Deployment

go build static binary, Docker scratch image, Kubernetes, k8s probes. Minimalne obrazy Docker — od kompilacji do k8s.
