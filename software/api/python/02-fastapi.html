FastAPI — podstawy

Path operations, parametry, schematy Pydantic, automatyczna dokumentacja, APIRouter, Depends

Tworzenie aplikacji FastAPI

FastAPI to nowoczesny framework webowy dla Pythona zbudowany na Starlette (ASGI) i Pydantic. Oferuje automatyczna generacje dokumentacji OpenAPI, pelne wsparcie dla async/await oraz najlepsza wydajnosc wsrod frameworkow Python.

Instalacja

uv add fastapi uvicorn[standard] pydantic
Uruchomienie deweloperskie: uvicorn main:app --reload --port 8000

from fastapi import FastAPI, status
from pydantic import BaseModel
from datetime import datetime

app = FastAPI(
    title="Moje API",
    description="Przykladowe API zbudowane z FastAPI",
    version="1.0.0",
    docs_url="/docs",       # Swagger UI
    redoc_url="/redoc",     # ReDoc
    openapi_url="/openapi.json",
)

@app.get("/", tags=["root"])
async def root() -> dict[str, str]:
    return {"message": "Witaj w API!", "status": "ok"}

Path operations — dekoratory HTTP

Kazda operacja HTTP jest definiowana przez dekorator na funkcji. FastAPI automatycznie parsuje parametry, waliduje dane i generuje dokumentacje na podstawie sygnatur funkcji i adnotacji typow.

Dekorator Metoda HTTP Typowe zastosowanie Domyslny status
@app.get()GETPobieranie zasobow200 OK
@app.post()POSTTworzenie zasobow200 (zmien na 201)
@app.put()PUTZastapienie zasobu200 OK
@app.patch()PATCHCzesciowa aktualizacja200 OK

Parametry: path, query, body

FastAPI rozroznia trzy rodzaje parametrow na podstawie ich umiejscowienia — nie potrzebujesz dodatkowych dekoratorow, framework dedukuje typ automatycznie.

from fastapi import FastAPI, Path, Query, Body, HTTPException, status
from pydantic import BaseModel, Field
from typing import Annotated

app = FastAPI()

# ---- Schematy Pydantic ----
class ProduktTworz(BaseModel):
    nazwa: str = Field(min_length=1, max_length=200)
    cena: float = Field(gt=0)
    kategoria: str
    dostepny: bool = True

class ProduktOdpowiedz(ProduktTworz):
    id: int
    utworzono: str

# ---- PATH parameter ----
# {produkt_id} w URL staje sie argumentem funkcji
@app.get("/produkty/{produkt_id}", response_model=ProduktOdpowiedz)
async def pobierz_produkt(
    produkt_id: Annotated[int, Path(title="ID produktu", ge=1)]
) -> ProduktOdpowiedz:
    # symulacja bazy danych
    if produkt_id > 1000:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND,
            detail=f"Produkt {produkt_id} nie istnieje",
        )
    return ProduktOdpowiedz(
        id=produkt_id,
        nazwa="Przykladowy produkt",
        cena=99.99,
        kategoria="elektronika",
        utworzono="2024-01-01",
    )

# ---- QUERY parameters ----
# argumenty bez {} w URL to query params (?skip=0&limit=10)
@app.get("/produkty/", response_model=list[ProduktOdpowiedz])
async def lista_produktow(
    skip: Annotated[int, Query(ge=0)] = 0,
    limit: Annotated[int, Query(ge=1, le=100)] = 10,
    kategoria: str | None = None,
    tylko_dostepne: bool = False,
) -> list[ProduktOdpowiedz]:
    # logika filtrowania...
    return []

# ---- BODY parameter ----
# Pydantic BaseModel automatycznie staje sie body
@app.post(
    "/produkty/",
    response_model=ProduktOdpowiedz,
    status_code=status.HTTP_201_CREATED,
    tags=["produkty"],
    summary="Utworz nowy produkt",
)
async def utworz_produkt(produkt: ProduktTworz) -> ProduktOdpowiedz:
    # zapis do bazy...
    return ProduktOdpowiedz(id=1, **produkt.model_dump(), utworzono="2024-01-01")

# ---- PATCH — aktualizacja czesciowa ----
class ProduktAktualizuj(BaseModel):
    nazwa: str | None = None
    cena: float | None = None
    dostepny: bool | None = None

@app.patch("/produkty/{produkt_id}", response_model=ProduktOdpowiedz)
async def aktualizuj_produkt(
    produkt_id: Annotated[int, Path(ge=1)],
    dane: ProduktAktualizuj,
) -> ProduktOdpowiedz:
    # model_dump(exclude_unset=True) zwraca tylko pola ktore uzytkownik podal
    zmiany = dane.model_dump(exclude_unset=True)
    # ... aktualizacja tylko zmienionych pol
    return ProduktOdpowiedz(
        id=produkt_id, nazwa="Zaktualizowany", cena=50.0,
        kategoria="elektronika", utworzono="2024-01-01"
    )

APIRouter — organizacja kodu

Dla wiekszych aplikacji warto podzielic endpointy na modul przy uzyciu APIRouter. Kazdy router moze miec wlasny prefix, tagi i zaleznosci.

Zaleznosci — Depends()

System zaleznosci FastAPI pozwala na wstrzykiwanie dowolnych wartosci do endpointow: sesji bazy danych, biezacego uzytkownika, ustawien. Zaleznosci moga byc zagniezdzane i sa automatycznie zarzadzane (takze cleanup po request).

from fastapi import APIRouter, Depends, Security
from typing import AsyncGenerator

# ---- Router dla uzytkownikow ----
router_uzytkownicy = APIRouter(
    prefix="/uzytkownicy",
    tags=["uzytkownicy"],
    responses={404: {"description": "Nie znaleziono"}},
)

# ---- Zaleznosc: sesja bazy danych ----
async def pobierz_sesje_db() -> AsyncGenerator:
    """Tworzy sesje DB, zamyka po request."""
    session = None  # tu: AsyncSession(engine)
    try:
        yield session
    finally:
        if session:
            await session.close()

# ---- Zaleznosc: biezacy uzytkownik ----
class UzytkownikDTO(BaseModel):
    id: int
    email: str
    rola: str

async def biezacy_uzytkownik(
    # token: str = Security(oauth2_scheme),
    db=Depends(pobierz_sesje_db),
) -> UzytkownikDTO:
    """Dekoduje token JWT i zwraca uzytkownika."""
    return UzytkownikDTO(id=1, email="jan@example.com", rola="admin")

# ---- Endpoint z wieloma zaleznosci ----
@router_uzytkownicy.get("/moj-profil")
async def moj_profil(
    uzytkownik: UzytkownikDTO = Depends(biezacy_uzytkownik),
    db=Depends(pobierz_sesje_db),
) -> UzytkownikDTO:
    return uzytkownik

@router_uzytkownicy.get("/{user_id}")
async def profil_uzytkownika(
    user_id: int,
    db=Depends(pobierz_sesje_db),
) -> UzytkownikDTO:
    return UzytkownikDTO(id=user_id, email="test@example.com", rola="user")

# ---- Rejestracja routera w glownej aplikacji ----
app.include_router(router_uzytkownicy)

Automatyczna dokumentacja

FastAPI generuje dokumentacje automatycznie na podstawie kodu. Po uruchomieniu serwera masz dostep do:

  • /docs — Swagger UI z mozliwoscia interaktywnego testowania
  • /redoc — ReDoc — czytelniejszy widok dokumentacji
  • /openapi.json — surowy schemat OpenAPI 3.0 do importu do Postmana, generowania klientow itd.

Status codes

Uzywaj stalych z fastapi.status zamiast liczb. Przyklady: status.HTTP_200_OK, status.HTTP_201_CREATED, status.HTTP_204_NO_CONTENT, status.HTTP_404_NOT_FOUND, status.HTTP_422_UNPROCESSABLE_ENTITY. Poprawia czytelnosc i unika literowek.
