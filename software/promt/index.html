Prompty do odtworzenia dokumentacji

Kolekcja gotowych promptow ktore pozwola wygenerowac podobna dokumentacje technicznej z LLM (Claude, GPT-5, Gemini). Meta-dokumentacja: jak powstala ta dokumentacja.

Po co ten folder?

Cala dokumentacja w tym repozytorium (architektura, llm, vst, lang/*, serwer, net, www, api itp.) zostala wygenerowana przy pomocy LLM-a (Claude). Te prompty pozwalaja odtworzyc podobna dokumentacje, rozbudowac istniejaca lub zaadaptowac ja do innego stosu technologicznego.

Wszystkie prompty sa testowane i gotowe do uzycia z Claude Sonnet 4.6, Claude Opus 4.7, GPT-5, Gemini 2.5 Pro.

Quick start — odtworz cala dokumentacje

3-krokowa procedura

  1. Krok 1: Skopiuj Master prompt do Claude/GPT — ustaw style i format.
  2. Krok 2: Wybierz kategorie (np. Jezyki programowania) i skopiuj prompty per rozdzial.
  3. Krok 3: Po wygenerowaniu MD/HTML — uzyj prompt na index aby wygenerowac glowna strone.

Szacunkowy koszt odtworzenia

Cala dokumentacja (~250 plikow HTML, ~110 plikow MD, ~30 sekcji) wymaga okolo:

  • ~3-5M input tokens (prompty + kontekst)
  • ~10-15M output tokens (wygenerowana zawartosc)
  • Claude Sonnet 4.6: ~$30-50 (z prompt caching ~$15-25)
  • GPT-5: ~$60-100
  • Czas: 4-8 godzin z parallel agents (Claude Code) lub 20-40h sekwencyjnie
