05. Prompty per narzedzia developerskie

IDE, AI tools, debuggery, profilery, monitoring — prompty generujace praktyczne dokumentacje narzedziowe.

Filozofia rozdzialow narzedziowych

Narzedzia opisujemy z perspektywy uzycia, nie feature-listy. Zamiast "VS Code ma N rozszerzen", pokaz "10 najlepszych extensions dla TypeScript developera w 2026". Konkrety, wersje, ceny.

Decision tree — wybor IDE

Glowny stack to .NET / Unity?
+- Tak: Visual Studio (Windows) lub Rider (cross-OS)
+- Nie: idz dalej

Java / Kotlin enterprise?
+- IntelliJ IDEA Ultimate

Python heavy (Django, Jupyter, ML)?
+- PyCharm Pro lub VS Code z Python extension

AI-first workflow z multi-file refactoring?
+- Cursor (paid) lub Windsurf (free hojne)

Performance critical, Vim user?
+- Zed

Wszystko inne, najwiekszy ekosystem extensions?
+- VS Code (default w 2026)

Wskazowki redakcyjne

Pokazuj konkretne wersje i ceny

"VS Code 1.96 (grudzien 2025)", "Copilot $10/mo personal, $19/mo business", "JetBrains All Products $169/yr". To dane uzytkowe, nie marketing.

Cena moze sie zmienic — zaznacz date

Pisz "stan na Q1 2026". Czytelnik za rok bedzie wiedzial ze cena moze byc inna. Lepsze niz milczenie.

NIE pisz "to najlepsze IDE"

Najlepsze nie istnieje. Pisz "dla X scenariusza wybierz Y". Subiektywne ranking budza waterfall i flame wars.
