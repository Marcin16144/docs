Decision tree — wybor framework

Komercyjny plugin za $50+, ma byc na rynku w 6-12 miesiecy?
+- JUCE (ergonomic, docs, community)

Open-source plugin lub eksperyment / chcesz web demo?
+- iPlug2 (Web Audio build) lub JUCE 8 (preview)

Maksymalna kontrola, edge cases (HW integration, custom hosts)?
+- VST3 SDK raw

Targetujesz Bitwig + u-he users + Reaper?
+- CLAP (lub multi: VST3 + CLAP via JUCE 8)

Pro Tools target?
+- Musisz dodac AAX (Avid SDK paid, NDA)

Real-world insights

Valhalla DSP — case study

Sean Costello, jednoosobowa firma, $25-50/plugin, brak DRM, brak ilok. Powtarzajaca lojalnosc fanow. Modne plug-iny (Vintageverb, Supermassive free). Lekcja: jakosc + uczciwa cena > DRM.

u-he — case study

Urs Heckmann, niemiecki, premium synthy ($150-200), CLAP + VST3 + AU + AAX, free (Zebralette, Tyrell N6) jako wprowadzenie do platnych. Lekcja: free tier napedza paid sales.

iLok = friction

iLok (Pace) to deterrent, ale customers nienawidza go. Forum w 2025: "I won't buy plugins with iLok". Rozwaz prosty machine ID + grace period zamiast iLok dla indie.

Anti-pattern: weryfikacja przy kazdym uruchomieniu

Online check przy kazdym starcie wtyczki = uzytkownik bez netu nie moze otworzyc projektu. Catastrophic UX. Rob raz na 30 dni z grace period.
