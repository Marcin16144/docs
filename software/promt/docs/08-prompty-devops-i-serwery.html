08. Prompty per DevOps i serwery

Windows Server, Linux, Docker, Kubernetes, CI/CD, sieci, observability, IaC.

Filozofia rozdzialow DevOps

DevOps to praktyka, nie teoria. Pokazuj pelne pliki konfiguracyjne (Dockerfile, docker-compose.yml, k8s manifesty, GitHub Actions YAML). Tlumacz kazda linijke. Bez kompletnych examples czytelnik nie skopiuje.

Decision tree — wybor orchestracji

Liczba kontenerow / replik?
+- 1-5: Docker Compose (single host)
+- 5-50: Docker Swarm lub maly K8s (k3s) lub managed K8s
+- 50+: Kubernetes (EKS/GKE/AKS managed)

Stateful workloads (bazy, kolejki)?
+- Tak: K8s z StatefulSets + persistent storage
+- Nie: deployment z replicas

Multi-region?
+- K8s federation, service mesh (Istio/Linkerd), Cilium ClusterMesh

Compliance heavy (HIPAA, PCI)?
+- Managed K8s on enterprise cloud (separate accounts, controls)

Pokazuj cale pliki YAML/HCL

Polowa Dockerfile, polowa kubectl apply -f - bez kontekstu = czytelnik nie skopiuje. Daj kompletne pliki z komentarzami.

Anti-pattern: secrets w Git

Nie commituj .env, kluczy AWS, kluczy SSH. Uzywaj GitHub Secrets, Vault, External Secrets Operator. gitleaks w pre-commit hook.
