03. Prompty per jezyk programowania

Per-jezyk wzorce promptow generujacych dokumentacje. Kazdy jezyk ma swoja specyfike — Rust ownership, PHP security, C++ memory.

Wspolny szkielet rozdzialow per jezyk

Kazdy jezyk dostaje 5 standardowych rozdzialow w identycznej kolejnosci:

  1. 01-podstawy — syntax, types, control flow, hello world
  2. 02-modern-features — nowe konstrukcje (PHP attributes, C# records, Rust async, Python pattern matching)
  3. 03-frameworki — najpopularniejsze frameworki / biblioteki
  4. 04-bezpieczenstwo — OWASP top 10 dla danego jezyka, sanitization, escaping
  5. 05-narzedzia — IDE, linter, formatter, package manager, CI

Specyficzne wskazowki per jezyk

Rust — dodaj rozdzial o ownership/borrowing

Rust ma unikalna cecha (borrow checker). Bez glebokiego rozumienia ownership, czytelnik bedzie walczyl z kompilatorem. Dodaj 02-ownership-borrowing.html z decision tree: "kiedy clone, kiedy borrow, kiedy Arc, kiedy RefCell".

PHP — security to osobny duzy rozdzial

PHP ma reputacje "niebezpiecznego". Pokaz nowoczesne praktyki (PDO prepared statements, htmlspecialchars wszedzie, password_hash z Argon2id). Ostrzez przed deprecated mysql_* i naive escapingiem.

C++ — explicit memory model

Bez sekcji o smart pointerach i RAII, czytelnik bedzie pisal C-style C++. Daj decision tree: "kiedy unique_ptr, kiedy shared_ptr, kiedy raw pointer (nigdy w API publicznym)".

Python — wolnosc skoku do nowych narzedzi

W 2026 ekosystem Python radykalnie sie zmienil: uv zastapilo pip+poetry, ruff zastapilo black+flake8+isort, pyright dominuje nad mypy. Pisz o tym, nie o przeszlosci.

Decision tree — ktory jezyk kiedy

Performance critical, low-level system code?
+- Tak: Rust (memory safe) lub C++ (legacy/embedded)
+- Nie: idziesz dalej

Web backend?
+- High-throughput API: Go, Rust, .NET
+- Rapid CRUD app: Python (FastAPI/Django) lub PHP (Laravel)
+- Enterprise z legacy: C# .NET lub Java

Frontend / web?
+- TypeScript (default w 2026)

Data science / ML?
+- Python (PyTorch, JAX, polars)
+- R dla statystyki akademickiej

Mobile?
+- Cross-platform: Flutter (Dart), React Native (TS)
+- Native iOS: Swift
+- Native Android: Kotlin

Game dev?
+- AAA: C++ (Unreal) lub C# (Unity)
+- Indie: Godot (GDScript), Bevy (Rust)

Desktop GUI?
+- C# (WinUI, MAUI, Avalonia)
+- Rust (Tauri, egui)
+- C++ (Qt 6)
