Wskazowki specyficzne per framework

React — pokazuj hooks (nie classes)

Class components to legacy. Wszystkie examples w hooks. Wspomnij o classes tylko w kontekscie "co spotkasz w starych codebases".

Vue — Composition API jako default

Pisz <script setup> z Composition API. Options API tylko w "legacy migration" sekcji. Pinia (nie Vuex) dla state.

Svelte — Runes wszedzie

Svelte 5 = Runes ($state, $derived, $effect). Stary $: reactive syntax tylko w migration guide.

Angular — signals priority

Angular 19 to signals + standalone components. RxJS tam gdzie ma sens (HTTP, complex streams), ale signals jako default state.
