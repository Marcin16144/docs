07. Prompty per LLM i AI

Foundations LLM, RAG, Agents, fine-tuning, evaluation, prompt engineering, MCP, model comparison.

Filozofia rozdzialow LLM/AI

AI/LLM ekosystem zmienia sie miesiacami. Pisz z dat ("stan na Q1 2026"), pokazuj konkretne modele (Claude Opus 4.7, GPT-5, Gemini 2.5), ceny ($/MTok input, $/MTok output), context windows. Bez aktualnych liczb dokumentacja jest bezuzyteczna w 6 miesiecy.

Prompt: RAG patterns

Prompt — RAG 
Stworz dokumentacje RAG (Retrieval Augmented Generation) (rok 2026).

01-czym-jest-rag.html: kiedy potrzebne (knowledge cutoff, prywatne
dokumenty, faktualnosc), pipeline (chunk -> embed -> store ->
retrieve -> augment -> generate)

02-chunking.html: fixed-size, recursive, semantic, structural
(headings), kolejnosc (overlap, no-overlap), wielkosc (256/512/1024

03-embeddings.html: openai text-embedding-3, voyage-3, cohere embed,

co wybrac (Voyage = best dla retrieval w 2026)

04-vector-stores.html: Pinecone (managed, drogi), Weaviate, Qdrant,
Milvus, pgvector (Postgres extension, prostsze), ChromaDB
(local), LanceDB (file-based)

05-retrieval-strategies.html:
- top-k similarity
- hybrid (BM25 + dense)
- reranking (Cohere Rerank, Voyage rerank)
- query rewriting / HyDE / multi-query
- contextual retrieval (Anthropic 2024 paper)

06-eval-rag.html: faithfulness, answer relevance, context precision/
recall, RAGAS framework, LLM-as-judge dla RAG

ANTI-PATTERN: chunk size 100 tokens (zbyt krotki), no-reranker,
solely vector search bez BM25.

Prompt: Fine-tuning vs Prompt-tuning vs LoRA

Wskazowki redakcyjne LLM

Aktualne ceny i wersje

Pisz "Claude Opus 4.7 ($15 input / $75 output / MTok, stan Q1 2026)". Ceny zmieniaja sie kwartalnie. Bez dat: dokumentacja przestaje byc aktualna.

Halucynacje sa REALNE

Nie pisz "Claude nigdy sie nie myli". Pisz "halucynacje sa zmniejszone w Claude 4.7 vs 3.5 ale nadal mozliwe — uzywaj retrieval/citations dla faktow".

Unikaj hype

"AGI w 2027", "model X przewyzsza wszystkich" — to marketing. Pisz benchmarks (MMLU, SWE-bench), real-world use cases, trade-offs.
