Pliki projektu

w3app/ = public_html/ na hostingu
├── index.php punkt wejścia, wykrywa domenę, ładuje config + composer autoload
├── .htaccess routing przez index.php, blokada folderów systemowych
├── core/ silnik — namespace Core\
│   ├── Config.php / Connection.php loader configu + singleton PDO
│   ├── db/ drivery PDO (Driver, MySql, PgSql, Sqlite)
│   ├── Migrations/ warstwa migracji — szczegóły
│   └── Models/ warstwa modeli tabel — szczegóły
├── app/ komponenty — namespace App\
│   ├── Appdb/ Application Main — baza każdego projektu (Models + Migrations)
│   ├── Cms/ CMS — opcjonalna nadbudowa (Models + Migrations)
│   └── Shop/ sklep — opcjonalna nadbudowa (pusty szablon)
├── admin/ panel admin (stub) — wyzwala MigrationRunner
├── bin/ CLI: php bin/migrate <komponent> <komenda>
├── tests/ PHPUnit 11 — 58 testów (Models, Migrations, db)
├── configs/ db + tenant.prefix + theme per host
├── var/schema-lock/ lock-pliki migratora (gitignore)
├── docs/ Markdown + HTML (ten katalog)
│   ├── changelog.md / changelog-db.md
│   ├── bazy-danych.md / vscode.md
│   ├── prompt/ prompty LLM
│   └── html/ wersja HTML (style.css + structure / bazy-danych / vscode)
└── composer.json / phpunit.xml PSR-4 (App\, Core\), test config

Komponenty modułowe

Każdy komponent żyje w app/<Pascal>/, wykrywany przez ComponentDiscovery. Appdb jest bazą każdego projektu; CMS/Shop — opcjonalne nadbudowy. Pełne tabele/kolumny per komponent: Bazy danych.

index.php

  • 1. require vendor/autoload.php
  • 2. Config::load($_SERVER['HTTP_HOST'])
  • 3. Connection::get() → autoloader driver
  • 4. render strony (frontend bez migratora)

Reguły .htaccess

1
Options -Indexes — blokada listowania folderów
2
^(core|configs|app|tests|var|vendor|bin|docs) → 403 Forbidden — ochrona folderów systemowych
3
plik fizyczny istnieje → serwuj bezpośrednio — CSS, JS, obrazki
4
wszystko inne → index.php — routing CMS
