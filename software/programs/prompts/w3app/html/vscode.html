VS Code — rozszerzenia projektu

Konfiguracja workspace + lista rozszerzeń wymaganych i rekomendowanych

Szybka instalacja

Otwórz projekt w VS Code — wyświetli popup "This workspace has extension recommendations". Klik Install All instaluje wszystkie wymienione w .vscode/extensions.json.

Jeśli popup nie wyskoczył: Ctrl+Shift+P → "Show Recommended Extensions" → klik Install Workspace Recommended Extensions.

Alternatywa z terminala (PowerShell):

code --install-extension recca0120.vscode-phpunit ` --install-extension xdebug.php-debug ` --install-extension bmewburn.vscode-intelephense-client ` --install-extension eamodio.gitlens

Po instalacji: Ctrl+Shift+P → Developer: Reload Window.

Wymagane rozszerzenia

Konieczne, żeby pliki w .vscode/ działały poprawnie.

PHPUnit Test Explorer wymagane

Integracja z wbudowanym panelem Testing.

  • ID: recca0120.vscode-phpunit
  • Skróty: Ctrl+; A (all), Ctrl+; F (file), Ctrl+; T (cursor)
  • Konfig: .vscode/settings.json (klucze phpunit.*)
  • Tryb debug uruchamia Xdebug automatycznie

PHP Debug (Xdebug) wymagane

Debugowanie PHP przez Xdebug 3.

  • ID: xdebug.php-debug
  • Wymaga Xdebug w PHP (XAMPP 8.2 ma natywnie)
  • Konfig: .vscode/launch.json (port 9003)
  • F5 → wybierz profil → ustaw breakpoint → odpal stronę

Rekomendowane rozszerzenia

Nie są wymagane do działania configów, ale znacząco poprawiają komfort pracy z PHP.

PHP Intelephense rekomendowane

De facto standard dla PHP w VS Code.

  • ID: bmewburn.vscode-intelephense-client
  • Autouzupełnianie, hinty typów
  • "Go to definition", "Find references"
  • Rename symbol, inline błędy składni
  • Po instalacji wyłącz wbudowane PHP Language Features (popup zaproponuje)

GitLens rekomendowane

Eksplorator historii git wewnątrz VS Code.

  • ID: eamodio.gitlens
  • Inline blame przy każdej linii (autor, commit, czas)
  • Historia pliku, porównania wersji
  • Eksplorator branchy, tagów, stashów
  • Bezcenne przy archeologii bugów

Co jeszcze warto rozważyć

Opcjonalne — nie ma w extensions.json.

  • EditorConfig.EditorConfig — wspólny styl formatowania
  • streetsidesoftware.code-spell-checker — literówki w komentarzach
  • cweijan.vscode-mysql-client2 — klient MySQL w edytorze
  • humao.rest-client — testowanie API z plików .http

Pliki w .vscode/

PlikStatus w gitRola
extensions.json wersjonowany Lista rekomendowanych rozszerzeń — popup przy otwarciu projektu. Wyjątek od .vscode/ w .gitignore.
settings.json lokalny Ustawienia per-workspace: ścieżka PHP, config PHPUnit, preferencje git/edytora.
launch.json lokalny Konfiguracja Xdebug — listener na 9003 z mapowaniem ścieżek XAMPP-a.
tasks.json lokalny Task na otwarcie folderu (runOn: folderOpen).

Konfiguracja PHPUnit w settings.json

"phpunit.php": "W:\\XAMPP82\\php\\php.exe", "phpunit.phpunit": "vendor/bin/phpunit", "phpunit.args": ["--configuration", "phpunit.xml"], "phpunit.environment": { "XDEBUG_MODE": "off" // ~10x szybciej; debug włącza się automatycznie }

Manualna instalacja pojedynczego rozszerzenia

1
Ctrl+Shift+X — otwórz panel Extensions
2
W polu szukania wpisz @id:<rozszerzenie> — np. @id:recca0120.vscode-phpunit
3
Install
4
Ctrl+Shift+P → Developer: Reload Window
