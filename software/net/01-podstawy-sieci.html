Podstawy sieci komputerowych

Fundamentalne pojecia: model OSI, TCP/IP, sprzet, topologie, kable Ethernet

Co to jest siec komputerowa

Siec komputerowa to grupa urzadzen polaczonych ze soba w celu wymiany danych i wspoldzielenia zasobow (plikow, drukarek, dostepu do internetu, aplikacji). Siec moze sie skladac z dwoch komputerow w jednym pokoju lub miliardow urzadzen na calym swiecie.

Model OSI - 7 warstw

Model OSI (Open Systems Interconnection) z 1984 roku opisuje funkcje sieci podzielone na 7 warstw. Kazda warstwa pelni inna role i komunikuje sie tylko z warstwa bezposrednio nad i pod soba.

NrWarstwaFunkcjaPrzyklady protokolow
7ApplicationInterfejs uzytkownika i aplikacjiHTTP, HTTPS, FTP, SMTP, DNS, SSH
6PresentationKodowanie, szyfrowanie, kompresjaTLS/SSL, JPEG, ASCII, MIME
5SessionZarzadzanie sesjamiNetBIOS, RPC, PPTP
4TransportNiezawodna transmisja end-to-endTCP, UDP, QUIC
3NetworkRouting, adresacja logicznaIP, ICMP, IGMP, OSPF
2Data LinkRamki, MAC, kontrola dostepuEthernet, ARP, PPP, 802.11
1PhysicalSygnal elektryczny/optycznyCat6, fiber, RJ45, sygnaly radiowe
Mnemotechnika - kolejnosc warstw od dolu do gory: Please Do Not Throw Sausage Pizza Away (Physical, Data Link, Network, Transport, Session, Presentation, Application).

Model TCP/IP - 4 warstwy

Model TCP/IP (DoD Model) jest praktyczny i uzywany w prawdziwym internecie. Zostal opracowany przez DARPA przed modelem OSI i jest prostszy.

Warstwa TCP/IPOdpowiednik OSIPrzyklady

Network Access1-2 (Physical, Data Link)Ethernet, WiFi, PPP, kable

Pakiety vs ramki - enkapsulacja

Dane przechodzac przez warstwy sa "opakowywane" - kazda warstwa dodaje wlasny naglowek (header). To proces enkapsulacji.

# Przykladowa enkapsulacja HTTP request:
[Ethernet Header | IP Header | TCP Header | HTTP Data | Ethernet Trailer]
       14B            20B         20B        zmienne          4B

# Terminologia per warstwa:
Application:    "data" lub "message"
Transport:      "segment" (TCP) lub "datagram" (UDP)
Network:        "packet"
Data Link:      "frame" (ramka)
Physical:       "bit" / "symbol"

Adresy MAC

MAC (Media Access Control) to fizyczny adres karty sieciowej - 48 bitow zapisany w formacie hex. Pierwsze 24 bity to OUI (Organizationally Unique Identifier) identyfikujace producenta, a kolejne 24 bity to numer urzadzenia.

# Format MAC:
AA:BB:CC:DD:EE:FF
[--OUI--][--ID--]

# Przyklady OUI znanych producentow:
00:1B:21  -  Intel
00:50:56  -  VMware
00:1A:11  -  Google
B8:27:EB  -  Raspberry Pi Foundation
DC:A6:32  -  Raspberry Pi (newer)
F0:18:98  -  Apple

# Komendy do wyswietlania MAC:
ip link show              # Linux
ifconfig                  # Linux/macOS (legacy)
ipconfig /all             # Windows
arp -a                    # ARP cache (cross-platform)

ARP - Address Resolution Protocol

ARP mapuje adresy IP na MAC w sieci lokalnej. Kiedy host A chce wyslac pakiet do hosta B w tej samej podsieci, musi znac jego MAC.

# Proces ARP:
1. Host A: "Kto ma 192.168.1.50? Powiedz 192.168.1.10" (broadcast FF:FF:FF:FF:FF:FF)
2. Host B: "192.168.1.50 ma MAC AA:BB:CC:DD:EE:FF" (unicast do A)
3. Host A zapisuje (192.168.1.50 -> AA:BB:CC:DD:EE:FF) w ARP cache

# Wyswietlenie ARP cache:
arp -a
ip neigh show            # Linux modern
arp -d 192.168.1.50      # Usuniecie wpisu
ARP poisoning - atakujacy moze sfalszowac ARP reply i przekierowac ruch przez siebie (Man-in-the-Middle). Zabezpieczenia: dynamic ARP inspection (DAI), static ARP entries dla krytycznych hostow.

Sprzet sieciowy

Hub (legacy)

Najprostsze urzadzenie warstwy 1 - replikuje sygnal na wszystkie porty. Powoduje kolizje, brak inteligencji. Praktycznie wycofany od 2010 roku.

Switch (przelacznik)

Warstwa 2 (Data Link) - uczy sie adresow MAC podlaczonych urzadzen i przelacza ramki tylko do docelowego portu. To podstawa nowoczesnej sieci LAN.

Router

Warstwa 3 (Network) - laczy rozne sieci (rozne podsieci IP), wybiera najlepsza droge dla pakietow. Posiada tablice routingu.

Modem

MOdulator-DEModulator - konwertuje sygnal cyfrowy na analogowy (DSL, kablowy modem). W modelach domowych czesto polaczony z routerem i switchem w jednym urzadzeniu.

Access Point (AP)

Punkt dostepowy WiFi - bridge miedzy ethernetem a siecia bezprzewodowa. Profesjonalne AP (Ubiquiti, Cisco, Aruba) sa zarzadzane centralnie przez kontroler.

Firewall

Filtruje ruch wedlug zdefiniowanych regul. Moze byc software (iptables, Windows Firewall) lub hardware (Cisco ASA, FortiGate, pfSense box).

Swiatlowod

  • Single-mode (SMF) - cienki rdzen 9 mikronow, laser, dystans do dziesiatkow km, drozszy. Stosowany w WAN i ISP.
  • Multi-mode (MMF) - grubszy rdzen (50/62.5 mikronow), LED/VCSEL, do 550 m. Tanszy, do data center i kampusow.
  • Zlacza: LC (najpopularniejsze), SC, ST, MPO/MTP (multi-fiber)
Praktyczna wskazowka - dla nowych instalacji domowych/biurowych w 2026 roku stosuj Cat6a. Zapewni 10 Gbps na 100 m i bedzie dlugo przyszlosciowy. Cat5e juz tylko do prostych setupow gigabitowych.
