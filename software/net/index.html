Sieci komputerowe

Kompendium o sieciach: model OSI/TCP-IP, IP/IPv6, routing, DNS, domeny, certyfikaty SSL/TLS, VPN, firewall, zarzadzanie ruterami, troubleshooting.

Podstawy

Podstawy sieci

Model OSI (7 warstw), TCP/IP (4 warstwy), pakiety, ramki, MAC adresy, ARP, hub/switch/router/modem, topologie sieci, klasyfikacja (LAN/WAN/MAN).

 Podstawy

IP i adresacja (IPv4 + IPv6)

IPv4 (klasy, CIDR, podsieci, NAT), IPv6 (struktura, link-local, dual-stack), prywatne vs publiczne, multicast, broadcast, anycast, subnetting kalkulacje.

 Podstawy

Protokoly TCP, UDP, ICMP

TCP (3-way handshake, kontrola przeplywu, retransmisja), UDP (bezpolaczeniowe, szybkie), ICMP (ping, traceroute), QUIC (HTTP/3), porty (well-known, registered, dynamic).

 Routing

Routing i ruterowanie

Tablica routingu, default gateway, OSPF, BGP, EIGRP, RIP, statyczny vs dynamiczny routing, multipath, ECMP, redystrybucja, MPLS basics.

 Sprzet

Routery i przelaczniki

Cisco IOS, MikroTik RouterOS, Ubiquiti UniFi, OPNsense/pfSense (open source), VLAN, trunk, STP, port aggregation (LACP), Layer 2 vs Layer 3 switche.

 Podstawy

DNS i domeny

DNS hierarchia (root, TLD, authoritative), rekordy (A, AAAA, CNAME, MX, TXT, NS, SOA, CAA, SRV), DNSSEC, DNS over HTTPS/TLS, zarzadzanie domena.

 Bezpieczenstwo

Certyfikaty SSL/TLS

X.509, lancuch zaufania, CA (DigiCert, Sectigo, Let's Encrypt), DV/OV/EV, SAN/wildcard, OCSP, CRL, ACME protocol, automatyzacja (certbot, Caddy auto-HTTPS).

 Bezpieczenstwo

VPN i tunelowanie

OpenVPN, WireGuard (modern standard), IPsec, L2TP, SSTP, site-to-site vs remote access, split tunneling, Tailscale, ZeroTier (overlay networks).

 Bezpieczenstwo

Firewall i bezpieczenstwo sieci

Firewalls (stateless vs stateful), iptables/nftables (Linux), pfSense, Windows Defender Firewall, IDS/IPS (Suricata, Snort), DDoS protection (Cloudflare, AWS Shield).

 Sprzet

WiFi i sieci bezprzewodowe

Standardy 802.11 (WiFi 6/6E/7), WPA2/WPA3, kanaly, mesh networks, enterprise (RADIUS), Bluetooth, Zigbee, Z-Wave, LoRaWAN dla IoT.

 Praktyka

Monitoring i troubleshooting

ping, traceroute, mtr, dig, nslookup, tcpdump, Wireshark, nmap, ss/netstat, iperf3, SNMP, NetFlow, monitoring (Zabbix, Grafana, PRTG, LibreNMS).

 Cloud

Cloud networking

VPC (AWS, Azure VNet, GCP), CDN (Cloudflare, CloudFront), load balancers (L4/L7), edge computing, service mesh (Istio, Linkerd), zero-trust networking.
