Visual Studio Code

Najpopularniejszy editor kodu (2026, ~75% market share). Konfiguracja, najlepsze rozszerzenia per stack — z naciskiem na PHP i React.js.

Podstawy VS Code

Visual Studio Code (VSC, "Code") — darmowy, open source, cross-platform editor od Microsoft. Wbudowany Git, terminal, debugger, IntelliSense, marketplace z 60k+ rozszerzeniami.

Instalacja i wybór wersji

  • VS Code — oficjalna wersja Microsoft (telemetria opt-out)
  • VSCodium — community build bez telemetrii (dla privacy-conscious)
  • Cursor — fork z głęboką integracją AI (Claude, GPT) — popular w 2026 dla AI-assisted coding
  • Windsurf (Codeium) — alternatywa dla Cursora

Pobieranie: code.visualstudio.com (lub winget install Microsoft.VisualStudioCode / brew install --cask visual-studio-code)

Konfiguracja settings.json

Settings (Ctrl/Cmd+,) → click ikona {} w prawym górnym rogu → otwiera JSON.

Lokalizacja:

  • Windows: %APPDATA%\Code\User\settings.json
  • macOS: ~/Library/Application Support/Code/User/settings.json
  • Linux: ~/.config/Code/User/settings.json

Profile (workspace per stack)

VS Code od 2023 ma Profiles — różne sety extensions/settings per typ projektu.

File → Preferences → Profiles → Create Profile

Przykładowe profile:
- "PHP Laravel"     — Intelephense, Laravel ext, Pint, PHPUnit
- "PHP Symfony"     — Intelephense, Symfony, Twig, PHPStan
- "React + TS"      — ESLint, Prettier, Tailwind, Vitest, ES7 snippets
- "Python ML"       — Pylance, Jupyter, Ruff, Black
- "Go"              — Go ext, Delve debugger
- "Minimal"         — tylko core extensions (szybki start)

Tip: Workspace settings (.vscode/settings.json w repo) override user settings — commit do Git dla team consistency.

Workspace settings — .vscode w repo

Trzymaj per-projekt config w .vscode/ folder w repo (commit do Git):

.vscode/
├── settings.json          # workspace-specific settings
├── launch.json            # debug configurations
├── tasks.json             # custom tasks (npm scripts, build commands)
├── extensions.json        # recommended extensions for the project
└── snippets/
    └── typescript.json   # team snippets

extensions.json

{
    "recommendations": [
        "esbenp.prettier-vscode",
        "dbaeumer.vscode-eslint",
        "bradlc.vscode-tailwindcss",
        "yoavbls.pretty-ts-errors"
    ]
}

Performance tips

  • Wyłącz Minimap — szybciej na dużych plikach
  • Wyłącz files.watcher dla node_modules: "files.watcherExclude": {"**/node_modules/**": true}
  • files.exclude — ukryj node_modules, .git, build z explorer
  • Ogranicz rozszerzenia — każde działa w background, zjada RAM
  • Workspace > User settings — workspace ładuje się tylko przy otwarciu projektu
  • Use Profiles żeby nie ładować wszystkich extensions na każdy projekt
  • Dev Containers dla heavy projects (izolacja zasobów)
