Apache NetBeans IDE

Klasyczne IDE od Apache Software Foundation. Specjalizacja: Java EE, PHP, HTML5/JS. Stan w 2026 + porownanie do alternatyw.

Czym jest NetBeans?

Apache NetBeans to open-source IDE (Integrated Development Environment) z dluga historia (od 1996, IBM/Sun, od 2017 Apache Foundation). W 2026 dziala jako top-level Apache project z otwarta spolecznoscia.

Aktualna wersja (2026): Apache NetBeans 22+ (release co ~6-9 miesiecy)

Glowne zalety NetBeans

  • W pelni darmowy i open source (Apache License 2.0)
  • Zero konfiguracji dla Java — bardzo dobry out-of-the-box
  • Najlepsze wsparcie JavaFX sposrod free IDEs
  • Maven/Gradle integracja first-class
  • Profiler wbudowany (analiza CPU, memory, threads)
  • GUI builder dla Swing (Matisse) — najlepszy w ekosystemie Java
  • Multi-language — Java, PHP, JS, HTML, C/C++, Groovy
  • Cross-platform — Windows, macOS, Linux
  • Bardzo niskie wymagania jak na Java IDE

Wady NetBeans w 2026

  • Mniejsza spolecznosc niz IntelliJ IDEA / VS Code
  • Wolniejszy rozwoj features
  • Slabsze wsparcie nowoczesnych frameworkow (Spring Boot — OK ale IntelliJ Ultimate lepszy)
  • Brak natywnego wsparcia AI assistants (mniej rozszerzen niz VS Code)
  • Wolniejszy startup niz VS Code
  • Plugin ecosystem znacznie mniejszy
  • Mlodsi developerzy uzywaja VS Code lub IntelliJ Community

Kiedy wybrac NetBeans?

NetBeans jest doskonalym wyborem dla:

  • Klasyczna Java SE / Java EE z Maven lub Gradle
  • JavaFX desktop apps — najlepsze wsparcie sposrod IDE
  • Swing legacy applications (Matisse GUI Builder)
  • PHP development — drugi najlepszy free PHP IDE (po VS Code z Intelephense)
  • Studenci / nauczanie programowania (zero konfiguracji)
  • Maven / Ant projects (excellent integration)
  • Profiling-heavy work (wbudowany profiler bez Ultimate license)
  • Open-source-only stack (filozoficzne preferencje)
  • Stare Linuxy / starszy hardware (mniejsze wymagania)

NetBeans jest slabszym wyborem dla:

  • Modern Spring Boot / Quarkus / Micronaut (IntelliJ Ultimate lepszy)
  • Kotlin (IntelliJ best, NetBeans ma podstawowe)
  • Modern JS/TS frontend (VS Code czy WebStorm)
  • AI-assisted coding (Cursor/VS Code z Copilotem)
  • Microservices / cloud-native (IntelliJ ma lepsze tooling)
  • Container / Kubernetes development (IntelliJ Ultimate / VS Code)

Instalacja

Wymagania (2026)

  • JDK 17+ (zalecane JDK 21 LTS lub 25 LTS)
  • RAM: minimum 2GB, zalecane 8GB+
  • Dysk: ~1GB dla IDE + projekty
  • OS: Windows 10+, macOS 11+, Linux (most distros)

Konfiguracja po instalacji

Wskazanie JDK

NetBeans uzywa netbeans.conf do okreslenia ktora JDK uruchamia samo IDE:

# Lokalizacja netbeans.conf:
# Windows: C:\Program Files\NetBeans-22\netbeans\etc\netbeans.conf
# macOS:   /Applications/NetBeans/Apache NetBeans 22.app/Contents/Resources/NetBeans/netbeans/etc/netbeans.conf
# Linux:   /opt/netbeans/etc/netbeans.conf  (lub gdzie zainstalowane)

# Wskazanie JDK:
netbeans_jdkhome="/usr/lib/jvm/temurin-21-jdk-amd64"

# Pamiec dla IDE (poprawia wydajnosc duzych projektow):
netbeans_default_options="-J-Xms256m -J-Xmx2048m -J-XX:+UseG1GC ..."

Java Platform Manager

Tools → Java Platforms — dodaj kolejne JDK (8, 11, 17, 21, 25). NetBeans pozwala na multi-JDK — kazdy projekt moze uzywac innej wersji Java.

Maven settings.xml

NetBeans uzywa systemowego Maven settings (~/.m2/settings.xml). Tools → Options → Java → Maven pozwala wskazac alternatywna lokalizacje.

NetBeans dla Java

Tworzenie projektu Maven

1. File → New Project (Ctrl+Shift+N)
2. Categories: Maven → Java Application
3. Wpisz Project Name, Group ID (com.example), Artifact ID
4. Wybierz JDK
5. Finish — NetBeans wygeneruje pom.xml + Main.java

Wbudowane funkcje Java

  • Code completion — Ctrl+Space
  • Quick Fix — Alt+Enter (poprawia errors automatycznie)
  • Refactoring — Ctrl+R (rename), Ctrl+M (move), Alt+Shift+E (extract method)
  • Generate Code — Alt+Insert (constructor, getters/setters, equals/hashCode, toString)
  • Format — Alt+Shift+F (zgodnie z JavaCodeConvention lub Google)
  • Find Usages — Alt+F7
  • Go to Declaration — Ctrl+B
  • Hierarchy view — Alt+F12 (class hierarchy)
  • Run — F6 (Run Project), Shift+F6 (Run File)
  • Debug — Ctrl+F5 (Debug Project), Shift+F8 (step over)

Java EE / Jakarta EE

NetBeans ma najlepsze free wsparcie dla Java EE / Jakarta EE:

  • Servlets, JSPs, JSF
  • EJB (Enterprise JavaBeans)
  • JPA (Persistence) + Hibernate
  • Web Services (JAX-RS REST, JAX-WS SOAP)
  • CDI (Contexts and Dependency Injection)
  • Application servers: Payara, WildFly, Open Liberty, Apache Tomcat, Apache TomEE, GlassFish

JavaFX

NetBeans + JavaFX = match made in heaven:

  • Wbudowane JavaFX project templates
  • Scene Builder integration (free od Gluon)
  • FXML editor z preview
  • CSS support dla JavaFX styling
  • Najlepszy debugging JavaFX apps

Swing GUI Builder (Matisse)

Wbudowany visual designer dla Swing — drag & drop UI komponentow. Generuje czysty kod:

1. New File (Ctrl+N) → Swing GUI Forms → JFrame Form
2. Przeciagnij JButton, JLabel, JTextField z palety
3. Property panel po prawej — ustawiaj atrybuty
4. Right-click button → Events → actionPerformed → kod handler
5. F6 — Run

Kod generowany jest w sekcji // <editor-fold> — nie edytuj manualnie!

NetBeans dla PHP

NetBeans to drugi najlepszy free PHP IDE (po VS Code + Intelephense). Lepszy niz Eclipse PDT.

Funkcje PHP

  • PHP 8.3 / 8.4 syntax support (od NetBeans 22)
  • Composer integration (Tools → Composer)
  • Symfony / Laravel project templates
  • Twig template support
  • PHPUnit integration (run/debug tests)
  • Xdebug debugging support
  • Code completion z PHPDoc
  • Refactoring (rename, extract method)
  • Database integration (Tools → Services)

Konfiguracja Xdebug

# 1. Zainstaluj Xdebug (PHP extension)
# php.ini:
zend_extension=xdebug.so
xdebug.mode=debug
xdebug.client_host=127.0.0.1
xdebug.client_port=9003
xdebug.start_with_request=trigger

# 2. NetBeans: Tools → Options → PHP → Debugging
# - Debugger Port: 9003
# - Session ID: netbeans-xdebug
# - Stop at First Line: false

# 3. W projekcie: Properties → Run Configuration
# - Run As: Local Web Site
# - Project URL: http://localhost/myproject
# - Index File: index.php

NetBeans dla C/C++

Wymaga aktywacji modulu C/C++ (Tools → Plugins).

Funkcje

  • GCC, Clang, MSVC (Windows) support
  • GDB / LLDB debugger integration
  • Make / CMake project support
  • Code completion + refactoring
  • Remote development (przez SSH na linuksowe maszyny)

Konkurenci dla C/C++ w 2026

Mimo solid wsparcia, lepsi konkurenci dla C/C++:

  • CLion (JetBrains, $99-249/yr) — best in class
  • VS Code z C/C++ Extension Pack — popular, free
  • Visual Studio (Windows) — najlepszy dla Windows-only
  • Eclipse CDT — alternatywa free

NetBeans dla HTML5 / JavaScript

Wsparcie istnieje, ale w 2026 VS Code lub WebStorm sa znacznie lepsze.

Co NetBeans ma:

  • HTML5/CSS3 syntax
  • JavaScript / TypeScript podstawowe (ES2015+)
  • Chrome debugger integration
  • npm / Yarn integration
  • Node.js project templates

Czego brakuje:

  • Modern React / Vue / Svelte tooling
  • Vite integration
  • Zaawansowane TypeScript features (vs WebStorm/VS Code)
  • AI assistants (Copilot integration limited)

Profiler

NetBeans Profiler — wbudowane narzedzie do profilowania aplikacji Java. Bezplatne — w IntelliJ Profiler wymaga Ultimate ($169/yr).

Co potrafi:

  • CPU Profiling — sampling i instrumentation modes
  • Memory Profiling — heap dumps, allocation tracking
  • Threads — analiza thread states, deadlocks
  • JDBC Queries — czas wykonania zapytan
  • Memory Leaks — detection algorithms
  • Snapshots — zapisywanie sesji do analizy

Uzycie

1. Profile → Profile Project (Alt+F2)
2. Wybierz typ: CPU, Memory, Object Allocation
3. Run — aplikacja uruchamiana z agentem
4. W trakcie wykonywania:
   - Live results (CPU hotspots, alokacje)
   - Take Snapshot (Ctrl+F2) — zapisuje stan
5. Analiza:
   - Hot methods (najwiecej czasu)
   - Memory consumption (top consumers)
   - Garbage collection patterns

Wydajnosc — tipy

Optymalizacja netbeans.conf

netbeans_default_options="-J-Xms512m -J-Xmx4096m \
    -J-XX:+UseG1GC \
    -J-XX:+UseStringDeduplication \
    -J-XX:+UnlockExperimentalVMOptions \
    -J-XX:G1NewSizePercent=20 \
    -J-XX:MaxGCPauseMillis=200 \
    -J-Dawt.useSystemAAFontSettings=on \
    -J-Dswing.aatext=true \
    -J-Dnetbeans.logger.console=true"

Wylacz niepotrzebne moduly

Tools → Plugins → Installed → odznacz pluginy ktorych nie uzywasz. To znacznie przyspieszy startup.

Indeksowanie projektow

NetBeans indeksuje projekty przy otwarciu. Dla duzych projektow:

  • Wykluczaj node_modules, target, build z indeksowania
  • Project Properties → Sources → Includes/Excludes

Werdykt 2026

NetBeans w 2026 — kto powinien uzywac?

TAK, jesli:

  • Piszesz klasyczna Java SE / Java EE z Maven
  • Pracujesz z JavaFX (najlepsze wsparcie)
  • Maintainujesz Swing legacy applications (Matisse Builder)
  • Potrzebujesz profilera za darmo (IntelliJ Profiler = $169/yr)
  • Filozoficznie wybierasz w pelni open source stack
  • Nauczasz programowania (zero konfiguracji)
  • Pracujesz na starszym hardware (mniejsze zuzycie RAM niz IntelliJ)

NIE, jesli:

  • Nowoczesny Spring Boot / Quarkus / Micronaut → IntelliJ Ultimate
  • Frontend / TS / React → VS Code lub WebStorm
  • AI-assisted coding to priorytet → VS Code z Copilotem lub Cursor
  • Microservices / cloud-native / Kubernetes-heavy → IntelliJ Ultimate / VS Code
  • Najszerszy plugin ecosystem → VS Code (60k+) lub IntelliJ (1000+)

Trend 2026: NetBeans ma stabilna ale malejaca user base. Wciaz silny w edukacji (uniwersytety) i klasycznym Java enterprise development. Apache aktywnie rozwija project — releases co 6-9 miesiecy.
