Zarzadzanie pakietami w Ubuntu

apt, dpkg, snap, flatpak, AppImage - kompletny przewodnik

Wprowadzenie

Ubuntu, jako dystrybucja oparta na Debianie, korzysta z systemu pakietow .deb oraz menedzera APT (Advanced Package Tool). Oprocz tradycyjnego apt, wspolczesne Ubuntu integruje rowniez nowsze formaty: snap (rozwijany przez Canonical), flatpak (uniwersalny standard) oraz AppImage (przenosny format). Kazde z nich ma swoje zalety i przypadki uzycia.

Zlote zasady:
  • Aktualizuj indeks pakietow przed instalacja: apt update
  • Nigdy nie uruchamiaj apt z dwoch sesji jednoczesnie - blokuje baze dpkg
  • Po dodaniu PPA zawsze sprawdzaj klucz GPG przed zaufaniem repozytorium

APT - podstawowe operacje

Polecenie apt to wysoko-poziomowy interfejs uzytkownika do APT, zaprojektowany dla terminalu. Jest nastepca apt-get oraz apt-cache, lacz ich funkcje w jednym narzedziu z czytelniejszym wyjsciem.

Aktualizacja systemu

# Pobranie aktualnej listy pakietow z repozytoriow
sudo apt update

# Aktualizacja zainstalowanych pakietow
sudo apt upgrade

# Pelna aktualizacja (moze usunac pakiety dla rozwiazania zaleznosci)
sudo apt full-upgrade

# Aktualizacja dystrybucji do nowszej wersji
sudo do-release-upgrade

# Wszystko w jednej komendzie (z zalozenia "tak" na pytania)
sudo apt update && sudo apt upgrade -y

Instalacja i usuwanie

# Instalacja pakietu
sudo apt install nginx

# Instalacja wielu pakietow naraz
sudo apt install git curl wget htop

# Instalacja konkretnej wersji
sudo apt install nginx=1.24.0-2ubuntu7

# Usuniecie pakietu (zachowuje pliki konfiguracyjne)
sudo apt remove nginx

# Usuniecie pakietu wraz z konfiguracja
sudo apt purge nginx

# Usuniecie nieuzywanych zaleznosci
sudo apt autoremove

# Usuniecie cache pobranych .deb (oszczedza miejsce w /var/cache/apt/archives)
sudo apt clean

Wyszukiwanie i informacje o pakietach

# Wyszukanie pakietu po nazwie/opisie
apt search docker

# Szczegoly o pakiecie (wersja, zaleznosci, opis)
apt show nginx

# Lista zainstalowanych pakietow
apt list --installed

# Lista pakietow do aktualizacji
apt list --upgradable

# Sprawdzenie czy pakiet jest zainstalowany
dpkg -l | grep nginx

dpkg - operacje niskopoziomowe

dpkg to narzedzie niskopoziomowe pracujace bezposrednio z plikami .deb. APT korzysta z dpkg pod spodem, ale dpkg sam nie obsluguje zaleznosci - musisz je rozwiazac recznie.

KomendaOpis
dpkg -lLista wszystkich zainstalowanych pakietow
dpkg -l nginxStatus konkretnego pakietu
dpkg -L nginxPliki nalezace do pakietu
dpkg -S /etc/nginx/nginx.confDo jakiego pakietu nalezy plik
dpkg -i package.debInstalacja lokalnego pliku .deb
dpkg -r nginxUsuniecie pakietu
dpkg --configure -aKonfiguracja niedokonczonych pakietow

Instalacja pliku .deb z naprawa zaleznosci

# Instalacja pliku .deb
sudo dpkg -i ./google-chrome-stable.deb

# Jesli brakuje zaleznosci - apt zalatwi sprawe
sudo apt install -f

# Alternatywnie - apt sam pobierze zaleznosci dla lokalnego deb
sudo apt install ./google-chrome-stable.deb

Repozytoria PPA

PPA (Personal Package Archive) to repozytoria spolecznosciowe hostowane na Launchpad. Pozwalaja instalowac oprogramowanie nieobecne w oficjalnych repozytoriach Ubuntu lub jego nowsze wersje.

# Dodanie PPA (przyklad - Mozilla Firefox z PPA Mozilla Team)
sudo add-apt-repository ppa:mozillateam/ppa

# Aktualizacja indeksu po dodaniu repozytorium
sudo apt update

# Instalacja pakietu z PPA
sudo apt install firefox-esr

# Usuniecie PPA
sudo add-apt-repository --remove ppa:mozillateam/ppa

# Lista skonfigurowanych zrodel
ls /etc/apt/sources.list.d/

Klucze GPG i nowoczesne podejscie

Od Ubuntu 22.04 zalecanym sposobem dodawania repozytoriow jest umieszczanie kluczy GPG w /usr/share/keyrings/ i odwolywanie sie do nich przez parametr signed-by. Stara metoda apt-key add jest deprecated.

# Pobranie i zapisanie klucza GPG (przyklad Docker)
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | \
  sudo gpg --dearmor -o /usr/share/keyrings/docker-archive-keyring.gpg

# Dodanie repozytorium z odwolaniem do klucza
echo "deb [arch=$(dpkg --print-architecture) \
  signed-by=/usr/share/keyrings/docker-archive-keyring.gpg] \
  https://download.docker.com/linux/ubuntu \
  $(lsb_release -cs) stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

# Aktualizacja i instalacja
sudo apt update
sudo apt install docker-ce docker-ce-cli containerd.io

Snap

Snap to format paczek od Canonical. Pakiety snap sa izolowane (sandbox) i zawieraja wszystkie zaleznosci. Aktualizuja sie automatycznie. W Ubuntu 22+ wiele aplikacji jak Firefox czy Chromium dystrybuowanych jest tylko jako snap.

# Lista zainstalowanych snapow
snap list

# Wyszukanie pakietu
snap find code

# Instalacja
sudo snap install code --classic

# Aktualizacja konkretnego snapa
sudo snap refresh code

# Aktualizacja wszystkich
sudo snap refresh

# Usuniecie
sudo snap remove code

# Sprawdzenie kanalow (stable, candidate, beta, edge)
snap info code

# Instalacja z konkretnego kanalu
sudo snap install nodejs --channel=20/stable

Flatpak

Flatpak to uniwersalny format dzialajacy na wszystkich dystrybucjach. Glowne repozytorium to Flathub. W przeciwienstwie do snap, flatpak nie ma centralnego procesu autoryzacji - kazdy moze publikowac.

# Instalacja flatpak na Ubuntu (nie jest preinstalowany)
sudo apt install flatpak

# Dodanie repozytorium Flathub
flatpak remote-add --if-not-exists flathub \
  https://flathub.org/repo/flathub.flatpakrepo

# Po dodaniu warto zrestartowac sesje

# Wyszukanie aplikacji
flatpak search blender

# Instalacja (z Flathub)
flatpak install flathub org.blender.Blender

# Uruchomienie
flatpak run org.blender.Blender

# Lista zainstalowanych
flatpak list

# Aktualizacja wszystkich
flatpak update

# Usuniecie
flatpak uninstall org.blender.Blender

# Czyszczenie nieuzywanych runtime
flatpak uninstall --unused

AppImage

AppImage to przenosny format - jeden plik wykonywalny zawierajacy aplikacje wraz ze wszystkimi zaleznosciami. Nie wymaga instalacji, nie potrzebuje uprawnien roota. Idealny do testowania aplikacji bez ingerencji w system.

# Pobranie AppImage (przyklad)
wget https://github.com/AppImage/AppImageKit/releases/download/13/appimagetool-x86_64.AppImage

# Nadanie uprawnien wykonywalnosci
chmod +x appimagetool-x86_64.AppImage

# Uruchomienie
./appimagetool-x86_64.AppImage

# Integracja z menu (opcjonalna - przez narzedzie AppImageLauncher)
sudo apt install appimagelauncher

Najlepsze praktyki

  • Dla aplikacji systemowych i narzedzi developerskich - preferuj APT
  • Dla aplikacji desktop, ktore chcesz miec zawsze aktualne - flatpak
  • Dla aplikacji firmowych z gwarancja od Canonical - snap
  • Dla testowania aplikacji bez instalacji - AppImage
  • Po dodaniu PPA zawsze przejrzyj /etc/apt/sources.list.d/ i klucze GPG
  • Regularnie wykonuj sudo apt autoremove i flatpak uninstall --unused
  • Konfiguruj automatyczne aktualizacje bezpieczenstwa: sudo apt install unattended-upgrades
