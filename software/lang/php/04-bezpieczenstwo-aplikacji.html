SQL Injection - prepared statements

Najczestszy blad: konkatenacja stringow w SQL.

// ZLE - SQL Injection
$id = $_GET['id'];
$result = $pdo->query("SELECT * FROM users WHERE id = $id");

// DOBRZE - prepared statement (PDO)
$stmt = $pdo->prepare("SELECT * FROM users WHERE id = :id");
$stmt->execute(['id' => $_GET['id']]);
$user = $stmt->fetch();

// DOBRZE - mysqli prepared
$stmt = $mysqli->prepare("SELECT * FROM users WHERE id = ?");
$stmt->bind_param('i', $_GET['id']);
$stmt->execute();

CSRF tokens

Cross-Site Request Forgery - atakujacy zmusza zalogowanego uzytkownika do wykonania akcji.

// Generowanie tokenu (PHP 8.2+ ma Random\Randomizer)
$token = bin2hex(random_bytes(32));
$_SESSION['csrf_token'] = $token;

// W formularzu
<input type="hidden" name="_token" value="<?= htmlspecialchars($token) ?>">

// Weryfikacja
if (!hash_equals($_SESSION['csrf_token'] ?? '', $_POST['_token'] ?? '')) {
    http_response_code(419);
    exit('CSRF token mismatch');
}

Password hashing - Argon2id

// Hashowanie - PASSWORD_DEFAULT to argon2id w PHP 8.4+
$hash = password_hash($password, PASSWORD_ARGON2ID, [
    'memory_cost' => 65536,  // 64 MB
    'time_cost' => 4,
    'threads' => 1,
]);

// Weryfikacja
if (password_verify($password, $hash)) {
    // Sprawdz czy potrzebne re-hash (nowsze parametry)
    if (password_needs_rehash($hash, PASSWORD_ARGON2ID)) {
        $newHash = password_hash($password, PASSWORD_ARGON2ID);
        // Zapisz $newHash w bazie
    }
}

NIGDY nie uzywaj do hasel:

  • md5() — zlamane od 2004
  • sha1() — zlamane od 2017
  • crypt() bez salt — tylko z PASSWORD_BCRYPT
  • Plain text — nigdy

File upload - bezpieczenstwo

function safeUpload(array $file, string $dest): string {
    // 1. Sprawdz blad
    if ($file['error'] !== UPLOAD_ERR_OK) {
        throw new RuntimeException('Upload error');
    }

    // 2. Limit rozmiaru
    if ($file['size'] > 5 * 1024 * 1024) {
        throw new RuntimeException('File too large');
    }

    // 3. Wykryj prawdziwy MIME (nie ufaj $file['type'])
    $finfo = new finfo(FILEINFO_MIME_TYPE);
    $mime = $finfo->file($file['tmp_name']);

    $allowed = ['image/jpeg', 'image/png', 'image/webp'];
    if (!in_array($mime, $allowed, true)) {
        throw new RuntimeException('Invalid file type');
    }

    // 4. Wygeneruj unikalna nazwe (nie uzywaj user filename)
    $ext = match($mime) {
        'image/jpeg' => '.jpg',
        'image/png' => '.png',
        'image/webp' => '.webp',
    };
    $name = bin2hex(random_bytes(16)) . $ext;

    // 5. Przenies poza document root!
    $path = $dest . '/' . $name;
    if (!move_uploaded_file($file['tmp_name'], $path)) {
        throw new RuntimeException('Cannot move file');
    }

    return $name;
}

SSRF prevention

// ZLE - SSRF: atakujacy moze wymusic request do internal services
$content = file_get_contents($_GET['url']);

// DOBRZE - allowlist
$parsed = parse_url($_GET['url']);
$allowedHosts = ['api.example.com', 'cdn.example.com'];
if (!in_array($parsed['host'] ?? '', $allowedHosts, true)) {
    throw new InvalidArgumentException('Host not allowed');
}

// + sprawdzenie czy IP nie jest internal
$ip = gethostbyname($parsed['host']);
if (filter_var($ip, FILTER_VALIDATE_IP, FILTER_FLAG_NO_PRIV_RANGE | FILTER_FLAG_NO_RES_RANGE) === false) {
    throw new InvalidArgumentException('Internal IP blocked');
}
