Nowoczesny PHP (8.1 - 8.4)

Najwazniejsze cechy nowoczesnego PHP - readonly, enums, attributes, fibers, JIT, asymmetric visibility i wiecej.

strict_types — podstawa nowoczesnego PHP

Domyslnie PHP wykonuje konwersje typow. declare(strict_types=1) wylacza to zachowanie i wymusza pelna zgodnosc typow.

// Bez strict_types
function dodaj(int $a, int $b): int { return $a + $b; }
echo dodaj(1, "5"); // 6 - automatyczna konwersja

// Z declare(strict_types=1)
declare(strict_types=1);
echo dodaj(1, "5"); // TypeError

Readonly properties (PHP 8.1+)

Wartosc mozna ustawic tylko raz - w konstruktorze. Idealne dla DTO i value objects.

final class Money {
    public function __construct(
        public readonly int $amount,
        public readonly string $currency,
    ) {}
}

$m = new Money(100, 'PLN');
$m->amount = 200; // Error: Cannot modify readonly property

// PHP 8.2+ - readonly classes (cala klasa readonly)
readonly class Point {
    public function __construct(
        public float $x,
        public float $y,
    ) {}
}

Enums (PHP 8.1+)

Pelnoprawne typy enum - wreszcie, po dlugich latach uzywania stalych klasowych.

// Pure enum
enum Status {
    case Active;
    case Inactive;
    case Pending;
}

// Backed enum (z wartoscia)
enum Color: string {
    case Red = 'red';
    case Green = 'green';
    case Blue = 'blue';

    public function hex(): string {
        return match($this) {
            Color::Red => '#ff0000',
            Color::Green => '#00ff00',
            Color::Blue => '#0000ff',
        };
    }
}

$c = Color::Red;
echo $c->value;     // 'red'
echo $c->hex();     // '#ff0000'
echo $c->name;      // 'Red'

// Z wartosci
$c2 = Color::from('green');
$c3 = Color::tryFrom('invalid'); // null

// Wszystkie cases
foreach (Color::cases() as $case) {
    echo $case->value;
}

Attributes (PHP 8.0+)

Metadane przyczepiane do klas, metod, properties, parametrow. Zastapily docblock-based annotations (Doctrine).

#[Attribute(Attribute::TARGET_METHOD)]
class Route {
    public function __construct(
        public string $path,
        public string $method = 'GET',
    ) {}
}

class UserController {
    #[Route('/users', method: 'GET')]
    public function index() { /* ... */ }

    #[Route('/users/{id}', method: 'GET')]
    public function show(int $id) { /* ... */ }
}

// Reflection
$ref = new ReflectionMethod(UserController::class, 'index');
foreach ($ref->getAttributes(Route::class) as $attr) {
    $route = $attr->newInstance();
    echo $route->path; // /users
}

Constructor property promotion

Skraca boilerplate definicji klas o ~70%.

// Stary styl
class User {
    private string $name;
    private string $email;

    public function __construct(string $name, string $email) {
        $this->name = $name;
        $this->email = $email;
    }
}

// Nowy styl (PHP 8.0+)
class User {
    public function __construct(
        private string $name,
        private string $email,
    ) {}
}

Fibers (PHP 8.1+)

Lekkie korutyny - umozliwiaja prawdziwa wspolbieznosc bez zmian w istniejacym kodzie. Podstawa dla bibliotek async (ReactPHP, Amp).

$fiber = new Fiber(function (): void {
    echo "Fiber start\n";
    $value = Fiber::suspend('zawieszony');
    echo "Wznowiony z: $value\n";
});

$ret = $fiber->start();
echo "Otrzymano: $ret\n";
$fiber->resume('hello');
// Output:
// Fiber start
// Otrzymano: zawieszony
// Wznowiony z: hello

Match expression (PHP 8.0+)

Lepsza wersja switch - z type-safe porownaniem (===), grupowanie wartosci, zwraca wartosc.

$wynik = match($code) {
    200, 201, 204 => 'Sukces',
    301, 302 => 'Przekierowanie',
    400, 401, 403, 404 => 'Blad klienta',
    500, 502, 503 => 'Blad serwera',
    default => 'Nieznany status',
};

// Bez default - rzuca UnhandledMatchError jesli brak dopasowania

JIT (Just-In-Time compilation)

Od PHP 8.0 dostepny jest JIT compiler. Konfiguracja w php.ini:

; opcache wymagane dla JIT
opcache.enable=1
opcache.enable_cli=1
opcache.jit_buffer_size=128M
opcache.jit=tracing

JIT najbardziej pomaga w: obliczeniach matematycznych, manipulacjach na duzych tablicach, kodzie CPU-bound. Dla typowych aplikacji webowych (CRUD, API) JIT nie daje znaczacej poprawy — tam wygrywa OPcache.

Asymmetric visibility (PHP 8.4)

Inna widocznosc dla odczytu i zapisu. Czesto chcemy public-read, private-write.

class User {
    public private(set) string $email;

    public function __construct(string $email) {
        $this->email = $email; // OK - z wewnatrz
    }
}

$u = new User('a@b.pl');
echo $u->email;        // OK - public read
$u->email = 'x@y.pl';  // Error - private set

Property hooks (PHP 8.4)

Computed properties bez magicznych metod __get/__set.

class User {
    public string $firstName;
    public string $lastName;

    public string $fullName {
        get => "$this->firstName $this->lastName";
    }

    public string $email {
        set(string $value) {
            $this->email = strtolower(trim($value));
        }
    }
}

$u = new User();
$u->firstName = 'Anna';
$u->lastName = 'Kowalska';
echo $u->fullName;    // 'Anna Kowalska'

Migracja: stary kod → nowoczesny PHP

  • array() → [] (krotsza skladnia tablic)
  • Stale klasowe na statusy → enum
  • Stary konstruktor z $this->x = $x → property promotion
  • switch → match dla zwracajacych wartosc
  • DTO bez setterow → readonly
  • __get/__set → property hooks (8.4+)
