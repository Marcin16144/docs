Podstawy PHP

Historia, instalacja, skladnia, typy, OOP i ekosystem PHP 8.3/8.4 jako baseline w 2026.

Krotka historia PHP

PHP narodzilo sie w 1995 roku. Rasmus Lerdorf stworzyl pierwsza wersje (Personal Home Page Tools, FI — Forms Interpreter) jako zestaw skryptow CGI w C do obslugi prostych formularzy na swojej stronie internetowej.

RokWersjaKluczowe nowosci
1995PHP/FIPierwsze publiczne wydanie, formularze i CGI
1998PHP 3Andi Gutmans i Zeev Suraski, nowy parser, OOP-light
2000PHP 4Zend Engine 1.0, znaczne przyspieszenie
2004PHP 5Pelne OOP, PDO, SPL, exceptions
2015PHP 72x szybszy niz PHP 5.6, scalar type hints, return types
2020PHP 8.0JIT, named arguments, attributes, match expression
2023PHP 8.3Typed class constants, json_validate(), Randomizer
2024PHP 8.4Property hooks, asymmetric visibility, lazy objects

Skladnia podstawowa

PHP osadza sie w plikach .php miedzy tagami <?php ... ?>. Konwencja od 2026 to pliki czysto-PHP bez tagu zamykajacego (zapobiega problemom z whitespace w outputcie).

<?php
declare(strict_types=1);

// Komentarz jednoliniowy
# Inny komentarz jednoliniowy
/* Komentarz
   wieloliniowy */

// Wypisanie tekstu
echo "Witaj, swiecie!\n";
print("Alternatywa\n");
printf("Sformatowane: %d\n", 42);

Zmienne i typy

Zmienne w PHP zaczynaja sie od $. PHP jest dynamicznie typowany, ale od 7.0 wspiera scalar type hints, a od 8.0 union types.

<?php
// Typy skalarne
$liczba_calkowita = 42;             // int
$liczba_zmiennoprzecinkowa = 3.14;  // float
$tekst = "Witaj";                   // string
$prawda = true;                     // bool

// Tablice (associative + indexed)
$lista = [1, 2, 3, 4];
$slownik = ['imie' => 'Jan', 'wiek' => 30];

// gettype / is_*
var_dump($liczba_calkowita);        // int(42)
echo gettype($tekst);               // string
echo is_array($lista) ? 'tak' : 'nie';

Kontrola przeplywu

// if / elseif / else
$wiek = 18;
if ($wiek >= 18) {
    echo "Dorosly";
} elseif ($wiek >= 13) {
    echo "Nastolatek";
} else {
    echo "Dziecko";
}

// match (PHP 8.0+) - lepsze niz switch
$status = 'active';
$opis = match($status) {
    'active', 'pending' => 'Aktywny lub oczekujacy',
    'banned' => 'Zablokowany',
    default => 'Nieznany'
};

// foreach
foreach ($slownik as $klucz => $wartosc) {
    echo "$klucz => $wartosc\n";
}

// while / do-while / for
$i = 0;
while ($i < 5) {
    echo $i++;
}

Funkcje

<?php
declare(strict_types=1);

// Funkcja z type hints
function dodaj(int $a, int $b): int {
    return $a + $b;
}

// Domyslne argumenty
function powitaj(string $imie, string $tytul = 'Pan'): string {
    return "Witaj, $tytul $imie";
}

// Named arguments (PHP 8.0+)
echo powitaj(imie: 'Anna', tytul: 'Pani');

// Arrow functions (PHP 7.4+)
$kwadrat = fn($x) => $x * $x;

// Variadic
function suma(int ...$liczby): int {
    return array_sum($liczby);
}
echo suma(1, 2, 3, 4, 5); // 15

Klasy i OOP

PHP od wersji 5 ma pelne wsparcie OOP. Wersja 8 dodaje constructor property promotion, ktore drastycznie skraca kod.

<?php
declare(strict_types=1);

namespace App\Models;

class Uzytkownik {
    // Constructor promotion (PHP 8.0+)
    public function __construct(
        public readonly string $imie,
        public readonly string $email,
        private int $wiek = 0
    ) {}

    public function pelnyOpis(): string {
        return "$this->imie ($this->email), wiek: $this->wiek";
    }
}

// Interfejsy
interface Powitanie {
    public function przywitaj(): string;
}

// Dziedziczenie + implementacja
class Pracownik extends Uzytkownik implements Powitanie {
    public function __construct(
        string $imie,
        string $email,
        public readonly string $stanowisko
    ) {
        parent::__construct($imie, $email);
    }

    public function przywitaj(): string {
        return "Witam, $this->imie, $this->stanowisko";
    }
}

$p = new Pracownik('Anna', 'anna@example.com', 'Developer');
echo $p->przywitaj();

Namespaces i autoloading PSR-4

// plik: src/Service/UserService.php
<?php
namespace App\Service;

use App\Models\Uzytkownik;

    public function findById(int $id): ?Uzytkownik {
        // ...
    }
}

composer.json - PSR-4 autoloading

{
    "name": "moja/aplikacja",
    "require": {
        "php": "^8.3"
    },
    "autoload": {
        "psr-4": {
            "App\\": "src/"
        }
    }
}

Composer init

Composer to package manager dla PHP - odpowiednik npm/pip. Inicjalizacja projektu:

# Instalacja Composer (lokalnie)
curl -sS https://getcomposer.org/installer | php
mv composer.phar /usr/local/bin/composer

# Inicjalizacja projektu
composer init

# Dodanie zaleznosci
composer require monolog/monolog
composer require --dev phpunit/phpunit

# Zaladowanie autoloadera w skrypcie
require __DIR__ . '/vendor/autoload.php';

Najlepsze praktyki w 2026

  • readonly properties dla DTO i value objects
  • Type hints wszedzie - argumenty, return types, properties
  • PSR-4 autoloading + Composer
  • PHPStan/Psalm level 8/max - statyczna analiza
