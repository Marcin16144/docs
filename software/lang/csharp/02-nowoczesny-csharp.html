Nowoczesny C# (9-13)

Records, primary constructors, pattern matching, raw strings, collection expressions, source generators, required members.

Records (C# 9+)

Records to immutable types z value-based equality — idealne dla DTO, value objects, message types.

// Pozycyjny record - jeden wiersz
public record Person(string Name, int Age);

// Z dodatkowymi cialami
public record User(string Email, string Name)
{
    public DateTime CreatedAt { get; init; } = DateTime.UtcNow;

    public string Display() => $"{Name} <{Email}>";
}

// Value equality (struktural)
var u1 = new Person("Anna", 30);
var u2 = new Person("Anna", 30);
Console.WriteLine(u1 == u2);  // True (records!)

// Klasy: u1 == u2 byloby False (reference equality)

// Non-destructive mutation - 'with'
var u3 = u1 with { Age = 31 };

// Record struct (C# 10+) - value type
public record struct Point(double X, double Y);

// Inheritance
public record Animal(string Name);
public record Dog(string Name, string Breed) : Animal(Name);

Primary constructors (C# 12+)

Wczesniej tylko records mialy primary constructors. C# 12 dodaje je do klas i strukt.

// Stary styl
public class UserService
{
    private readonly IRepository _repo;
    private readonly ILogger _logger;

    public UserService(IRepository repo, ILogger logger)
    {
        _repo = repo;
        _logger = logger;
    }
}

// Nowy styl (C# 12)
public class UserService(IRepository repo, ILogger logger)
{
    public async Task<User?> FindAsync(int id)
    {
        logger.LogInformation("Finding user {Id}", id);
        return await repo.FindAsync<User>(id);
    }
}

Pattern matching

C# 9-12 znacznie rozszerzaja pattern matching - jeden z najbardziej wyrazistych systemow w mainstreamowych jezykach.

// Type pattern + property pattern
object obj = new Person("Anna", 30);
if (obj is Person { Age: > 18 } p)
{
    Console.WriteLine($"{p.Name} jest dorosly");
}

// Switch expression
public static decimal CalculateDiscount(Customer c) => c switch
{
    { Type: CustomerType.Vip, YearsActive: >= 5 } => 0.20m,
    { Type: CustomerType.Vip } => 0.15m,
    { OrdersCount: > 100 } => 0.10m,
    { OrdersCount: > 10 } => 0.05m,
    _ => 0m
};

// List patterns (C# 11)
int[] numbers = [1, 2, 3, 4, 5];
var first = numbers switch
{
    [] => "pusta",
    [var x] => $"jeden: {x}",
    [var x, var y] => $"dwa: {x}, {y}",
    [var first, .., var last] => $"pierwszy {first}, ostatni {last}",
};

// Tuple pattern
public string GetQuadrant(int x, int y) => (x, y) switch
{
    (> 0, > 0) => "I",
    (< 0, > 0) => "II",
    (< 0, < 0) => "III",
    (> 0, < 0) => "IV",
    _ => "On axis"
};

Raw string literals (C# 11)

Stringi bez escape - idealne dla JSON, XML, regex, SQL.

// Stary sposob (escape pieklo)
string json = "{\"name\":\"Anna\",\"age\":30}";

// Raw string (C# 11)
string json = """
    {
        "name": "Anna",
        "age": 30
    }
    """;

// Z interpolacja - $$
string name = "Anna";
string json = $$"""
    { "name": "{{name}}" }
    """;
// Liczba $ = liczba { dla interpolacji

Async/await - nowoczesny styl

public async Task<User> GetUserAsync(int id, CancellationToken ct = default)
{
    // ConfigureAwait(false) w bibliotekach
    var data = await _http.GetAsync($"/users/{id}", ct).ConfigureAwait(false);
    return await data.Content.ReadFromJsonAsync<User>(ct).ConfigureAwait(false)
        ?? throw new InvalidOperationException();
}

// IAsyncEnumerable<T> - async streams (C# 8+)
public async IAsyncEnumerable<User> StreamUsersAsync(
    [EnumeratorCancellation] CancellationToken ct = default)
{
    await foreach (var batch in FetchBatchesAsync(ct))
    {
        foreach (var user in batch)
        {
            yield return user;
        }
    }
}

// Konsumpcja
await foreach (var user in StreamUsersAsync())
{
    Console.WriteLine(user.Name);
}

Nullable reference types

// W .csproj: <Nullable>enable</Nullable>

string nieNullowalne = "abc";
string? nullowalne = null;

// Kompilator wymusi sprawdzenie
if (nullowalne is not null)
{
    Console.WriteLine(nullowalne.Length);  // OK, narrowing
}

// Null-conditional / null-coalescing
int? len = nullowalne?.Length;
string text = nullowalne ?? "default";

// null-forgiving (kiedy wiesz lepiej niz kompilator)
string forced = nullowalne!.ToUpper();
