Historia, instalacja, skladnia, OOP, CLR i ekosystem .NET 9 jako baseline w 2026.

Krotka historia C#

C# powstal w 2000 roku jako jezyk dla platformy .NET firmy Microsoft. Glowny architekt — Anders Hejlsberg (autor Turbo Pascala i Delphi). C# czerpie z C++, Javy i Delphi.

Od C# 9.0 mozna pisac programy bez Main() - top-level statements:

// Program.cs - C# 9+
Console.WriteLine("Witaj, swiecie!");

string name = Console.ReadLine() ?? "Nieznajomy";
Console.WriteLine($"Witaj, {name}!");

// Stary styl (wciaz dziala)
namespace App;

{

        Console.WriteLine("Witaj!");
    }
}

Skladnia podstawowa

Typy i zmienne

// Typy wbudowane
int liczba = 42;                     // System.Int32
long duza = 9_000_000_000L;          // System.Int64
double pi = 3.14159;                 // System.Double
decimal cena = 99.99m;               // System.Decimal (precyzyjny)
bool prawda = true;                  // System.Boolean
char znak = 'A';                     // System.Char
string tekst = "Witaj";              // System.String

// var - inferencja typu (statycznie typowane!)
var x = 42;                          // int
var s = "tekst";                     // string
var lista = new List<int>();         // List<int>

// Const i readonly
const double Pi = 3.14159;           // compile-time
readonly DateTime created = DateTime.Now;  // runtime, raz

Properties (gettery/settery)

// Auto-property
public class User
{
    public string Name { get; set; } = "";
    public string Email { get; init; } = "";  // init-only (C# 9+)
    public int Age { get; private set; }       // mixed access
    public required string Username { get; init; }  // required (C# 11)
}

// Property z polem
private string _name;
public string Name
{
    get => _name;
    set => _name = value?.Trim() ?? throw new ArgumentNullException();
}

OOP w C#

// Klasy
public class Animal
{
    public string Name { get; }

    public Animal(string name) => Name = name;

    public virtual string Speak() => "...";
}

public class Dog : Animal
{
    public Dog(string name) : base(name) { }

    public override string Speak() => "Hau hau";
}

// Interfejsy
public interface IRepository<T>
{
    Task<T?> FindByIdAsync(int id);
    Task SaveAsync(T entity);
}

// Struct (value type) - dla malych typow
public struct Point
{
    public double X { get; }
    public double Y { get; }

    public Point(double x, double y) => (X, Y) = (x, y);
}

// Record (C# 9+) - immutable, value-based equality
public record Person(string Name, int Age);

var p1 = new Person("Anna", 30);
var p2 = p1 with { Age = 31 };       // non-destructive mutation
bool same = p1 == p2;                // value equality, false

CLR - Common Language Runtime

CLR to virtual machine .NET-u — odpowiada za kompilacje JIT, garbage collection, type safety, security. C# kompiluje sie do IL (Intermediate Language), ktory CLR konwertuje do natywnego kodu w runtime.

source .cs → csc.exe (Roslyn) → .dll/.exe (IL bytecode) → CLR → native code (JIT)

Glowne komponenty CLR:

  • JIT compiler — kompilacja IL do native w runtime
  • Garbage Collector — zarzadzanie pamiecia (generations 0/1/2)
  • Type system — CTS (Common Type System)
  • Assembly loader — ladowanie .dll
  • AOT — opcjonalna pre-compilation (NativeAOT, ReadyToRun)
