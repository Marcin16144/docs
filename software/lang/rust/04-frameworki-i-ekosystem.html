Frameworki i ekosystem Rust

Mapa popularnych bibliotek Rust w 2026 roku — co wybrac do web, async, baz, gier, GUI, embedded i WASM.

Web frameworki

Web ekosystem w Rust dojrzal i ma kilka stabilnych opcji. W 2026 dominuje Axum, ktory wygral wojne z Actix i Rocket dzieki ekosystem fit z Tokio i prostocie.

Axum — Hello World

use axum::{routing::get, Router, Json};
use serde::Serialize;

#[derive(Serialize)]
struct Powitanie {
    wiadomosc: String,
}

async fn hello() -> Json<Powitanie> {
    Json(Powitanie {
        wiadomosc: "Witaj w Axum!".to_string(),
    })
}

#[tokio::main]
async fn main() {
    let app = Router::new()
        .route("/", get(hello))
        .route("/zdrowie", get(|| async { "OK" }));

    let listener = tokio::net::TcpListener::bind("0.0.0.0:3000")
        .await.unwrap();
    println!("Serwer na http://0.0.0.0:3000");
    axum::serve(listener, app).await.unwrap();
}

Serializacja — Serde to monopol

Serde jest uniwersalnym frameworkiem serializacji. Praktycznie kazda biblioteka i format buduje na nim. Wspiera JSON, YAML, TOML, MessagePack, BSON, CBOR i dziesiatki innych.

use serde::{Serialize, Deserialize};

#[derive(Serialize, Deserialize, Debug)]
struct Uzytkownik {
    id: u64,
    imie: String,
    email: String,
    aktywny: bool,
}

let u = Uzytkownik {
    id: 1, imie: "Anna".into(),
    email: "anna@i4n.pl".into(), aktywny: true
};

let json = serde_json::to_string(&u).unwrap();
let toml = toml::to_string(&u).unwrap();
let z_powrotem: Uzytkownik = serde_json::from_str(&json).unwrap();

Game engines

Rust w gamedev jeszcze nie wygral z C++/Unity, ale jest wyrazne momentum. Bevy przekrocznyl 35k gwiazdek na GitHub i ma aktywna spolecznosc.

  • Bevy — najpopularniejszy, ECS-based, data-driven, modular
  • Fyrox — pelny silnik z editor (3D, animacje, physics)
  • Macroquad — prosty, idealny dla 2D i game jamow
  • Ggez — inspirowany LOVE2D
  • RG3D — silnik pelny 3D (rebrandowany do Fyrox)

Bevy — Hello World

use bevy::prelude::*;

fn main() {
    App::new()
        .add_plugins(DefaultPlugins)
        .add_systems(Startup, setup)
        .add_systems(Update, ruszaj_kamera)
        .run();
}

fn setup(mut commands: Commands) {
    commands.spawn(Camera2d::default());
    commands.spawn((
        Sprite::from_color(Color::srgb(0.8, 0.3, 0.2), Vec2::new(100.0, 100.0)),
        Transform::default(),
    ));
}

fn ruszaj_kamera(time: Res<Time>, mut q: Query<&mut Transform, With<Camera2d>>) {
    for mut t in q.iter_mut() {
        t.translation.x += 10.0 * time.delta_secs();
    }
}

Embedded — Rust dominuje wsrod nowoczesnych jezykow

Rust ma jeden z najlepszych ekosystemow embedded wsrod jezykow systemowych nowej generacji. embassy przyspieszyl adopcje async w mikrokontrolerach.

  • embassy — modern async no_std runtime, doskonale wsparcie dla nRF, STM32, ESP32, RP2040
  • embedded-hal — hardware abstraction layer (uniwersalny interfejs do peripheriow)
  • RTIC — Real-Time Interrupt-driven Concurrency framework
  • esp-rs — oficjalne wsparcie Rust dla Espressif (ESP32-C3, S3, P4)
  • defmt — efficient logging dla embedded (deferred formatting)
  • probe-rs — flashing i debugging tool, alternatywa dla OpenOCD

WASM — Rust to Tier 1

Rust generuje najmniejsze i najszybsze WASM bundles wsrod jezykow general-purpose.

  • wasm-bindgen — most miedzy Rust a JS
  • wasm-pack — narzedzie buildujace
  • Yew — React-like framework w Rust
  • Leptos — fine-grained reactivity (jak SolidJS)
  • Dioxus — cross-platform (wspomniany w GUI)
  • Trunk — dev server i bundler dla SPA

Machine Learning

  • candle — Hugging Face ML framework w Rust (alternatywa dla PyTorch w produkcji)
  • tch-rs — bindings PyTorch C++ (libtorch)
  • burn — pure Rust deep learning, multiple backends (CPU, CUDA, Metal, WGPU)
  • linfa — classical ML (jak scikit-learn)
  • ort — ONNX Runtime bindings (najpopularniejsze dla inference)
  • tokenizers — Hugging Face tokenizers (uzywane przez Pythona, ale to Rust)

clap — Hello World

use clap::Parser;

#[derive(Parser, Debug)]
#[command(version, about = "Moje narzedzie CLI")]
struct Args {
    /// Nazwa do powitania
    #[arg(short, long, default_value = "swiat")]
    nazwa: String,

    /// Liczba powtorzen
    #[arg(short, long, default_value_t = 1)]
    powtorzenia: u8,
}

fn main() {
    let args = Args::parse();
    for _ in 0..args.powtorzenia {
        println!("Witaj, {}!", args.nazwa);
    }
}

Testing

Rust ma built-in test framework — wystarczy #[test] nad funkcja. Brak zaleznosci od JUnit / xUnit / pytest.

  • cargo test — wbudowany runner (unit + integration + doctests)
  • criterion — statistical benchmarking framework
  • proptest / quickcheck — property-based testing (Hypothesis-style)
  • mockall — generowanie mockow dla traitow
  • insta — snapshot testing
  • cargo-nextest — szybszy alternatywny test runner
  • cargo-llvm-cov — code coverage przez LLVM

gRPC i GraphQL

  • tonic — gRPC implementation (oficjalnie wspierany przez tokio team)
  • prost — Protocol Buffers w Rust (uzywany przez tonic)
  • async-graphql — najpopularniejsza biblioteka GraphQL (server)
  • juniper — starsza alternatywa GraphQL
  • graphql-client — typed GraphQL client (codegen ze schemas)

Inne wazne crates 2026

  • tracing — structured logging i instrumentation (zastapil log)
  • thiserror + anyhow — must-have dla error handling
  • chrono / time — daty i czasy
  • uuid — UUID v4/v7 generation
  • rayon — data parallelism (parallel iterators)
  • crossbeam — concurrent data structures
  • once_cell / lazy_static — global static initialization
  • bytes — efficient byte buffers (uzywany przez Tokio)

Praktyczna rada

Sprawdzaj blessed.rs i lib.rs — community-curated listy najlepszych bibliotek w danej kategorii. Crates.io pokazuje surowe metryki, ale blessed.rs daje opinie ekspertow.
