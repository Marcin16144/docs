WAF i ochrona przed DDoS

Web Application Firewall, OWASP CRS i strategie ochrony przed atakami volumetricznymi i L7.

Web Application Firewall (WAF)

WAF analizuje ruch HTTP/HTTPS na warstwie L7 (aplikacyjnej) i blokuje zlosliwe requesty zanim trafia do aplikacji. Dziala na zasadzie regul (signatures), heurystyk (anomaly detection) lub ML-based.

Kategorie WAF

TypCharakterystykaPrzyklady

Cloud (Azure/AWS native)Integracja z VNet/VPC, granularne regulyAzure Application Gateway WAF, AWS WAF v2
On-premise hardwareAppliance fizyczny, najwieksza kontrolaF5 BIG-IP ASM, Imperva, Barracuda

Embedded (IIS module)W IIS bezposrednioMicrosoft URL Scan, IIS Dynamic IP Restrictions

OWASP Core Rule Set (CRS)

OWASP CRS to standardowy ruleset open source dla WAF. Zaprojektowany dla ModSecurity, ale wsperany przez wiele platform (Coraza, Cloudflare, Azure App Gateway WAF).

Tryby pracy WAF

TrybOpisZastosowanie
Detection / AuditLoguje matche, nie blokujeTuning - eliminacja false positives przed wlaczeniem blocking
Prevention / BlockBlokuje match (HTTP 403)Produkcja po tuningu
ChallengeJavaScript challenge / CAPTCHA dla podejrzanychMitygacja botow bez calkowitego blokowania

Antywzorzec: Wlaczenie WAF od razu w trybie blocking bez tuningu. Wynik: false positives blokuja legitnych uzytkownikow. Zawsze zaczynac od Detection mode przez 2-4 tygodnie, analizowac logi, dostraja reguly, dopiero potem wlaczyc Prevention.

Onboarding Cloudflare

  • Rejestracja domeny w Cloudflare
  • Zmiana NS rekordow w rejestrarze na Cloudflare nameservers
  • Cloudflare automatycznie wykrywa rekordy A/AAAA i ustawia proxied (orange cloud)
  • Ruch klientow trafia do Cloudflare, ktory robi reverse proxy do origin
  • Konfiguracja: SSL/TLS Mode = Full Strict (cert na origin musi byc valid)
  • WAF Rules: Cloudflare Managed Rules + OWASP Core Rule Set

Azure Application Gateway WAF

Microsoft cloud-native WAF integrowany z Azure VNet. Wspiera OWASP CRS 3.2 i 4.0 oraz Microsoft Threat Intelligence rules.

TierCechy
WAF v2 (current)Auto-scaling, zone redundancy, custom rules, geo filtering, bot manager
WAF v1 (legacy)Limited scale, deprecated
# Tworzenie WAF policy w Azure CLI
az network application-gateway waf-policy create `
    --name MyWafPolicy `
    --resource-group MyRG `
    --type OWASP `
    --version 3.2

# Custom rule - blokowanie konkretnego User-Agenta
az network application-gateway waf-policy custom-rule create `
    --policy-name MyWafPolicy --resource-group MyRG `
    --name BlockBadBot `
    --priority 100 `
    --rule-type MatchRule `
    --action Block

az network application-gateway waf-policy custom-rule match-condition add `
    --policy-name MyWafPolicy --resource-group MyRG `
    --name BlockBadBot `
    --match-variables RequestHeaders.User-Agent `
    --operator Contains `
    --values "BadBot/1.0"

AWS WAF

Integruje sie z CloudFront, Application Load Balancer (ALB), API Gateway, AppSync. Pricing per WebACL + per million requests.

  • Managed rule groups: AWS Managed Rules (Core, Anonymous IP List, SQLi, Linux/Windows attacks)
  • Marketplace rules: Imperva, F5, Cyberark
  • Custom rules: rate limiting, geo blocking, IP whitelist/blacklist
  • WCU (Web ACL Capacity Units) - kazda regula ma koszt WCU, max 1500 per WebACL

F5 BIG-IP / Imperva (enterprise on-prem)

  • F5 ASM (Application Security Manager) - dojrzaly enterprise WAF
  • Imperva (dawniej SecureSphere) - cloud + on-prem
  • Hardware appliances + virtual editions
  • ML-based bot detection, advanced behavioral analysis
  • Wysokie koszty - typowo dla enterprise/banking/medical

Atak DDoS - rodzaje

Volumetric (L3/L4)

Ataki przepelniajace pasmo i zasoby sieciowe, mierzone w Gbps lub Mpps (packets per second).

UDP floodMasa pakietow UDP do losowych portowFiltracja na CDN/scrubbing center
SYN floodHalf-open TCP connections, wyczerpanie kolejkiSYN cookies, rate limiting
ICMP floodPing floodBlokowanie ICMP echo na perimeter
NTP/DNS amplificationSpoofed source IP, amplifier reflektuje na ofiareBCP38 ingress filtering, rate limit zrodel
Memcached amplification50000x amplification ratio (rekordowo)Closed amplifier services, ISP filtering

Protocol (L4)

AtakMechanizm

Application (L7)

Ataki na warstwe aplikacyjna - mniejsze pasmo, ale wykorzystuje slabosci aplikacji.

Rate limiting w IIS

Wbudowane mozliwosci IIS dla L7 ochrony:

<system.webServer>
  <security>
    <dynamicIpSecurity enableLoggingOnlyMode="false">
      <denyByConcurrentRequests
        enabled="true" maxConcurrentRequests="20" />
      <denyByRequestRate
        enabled="true"
        maxRequests="50"
        requestIntervalInMilliseconds="1000" />
      <!-- Whitelist (np. monitoring) -->
      <ipSecurity>
        <add ipAddress="10.0.0.0" subnetMask="255.0.0.0" allowed="true" />
      </ipSecurity>
    </dynamicIpSecurity>

    <requestFiltering>
      <requestLimits maxAllowedContentLength="10485760"
                      maxUrl="4096"
                      maxQueryString="2048" />
    </requestFiltering>
  </security>
</system.webServer>

Multi-layer defense

Bezpieczenstwo to wiele warstw. Pojedynczy WAF nie wystarczy.

  1. CDN/Cloud WAF (Cloudflare, Azure FD) - L3/4/7 DDoS, edge filtering, bot management
  2. Reverse proxy (IIS+ARR, Nginx) w DMZ - SSL termination, dodatkowe rate limiting
  3. Application WAF (ModSecurity, IIS modules) - aplikacyjne reguly
  4. Aplikacja - input validation, parametrized queries, output encoding (last line of defense)
  5. Database firewall (np. Imperva DAM) - L4 DB activity monitoring

Best practices

  • WAF z OWASP CRS jako baseline
  • Tuning w Detection mode minimum 2 tygodnie przed Block mode
  • Bot management dla zapytan API (rate limit, JWT, signed requests)
  • DDoS Standard tier dla zasobow krytycznych biznesowo
  • "I'm Under Attack" jako pull-the-cord opcja w Cloudflare
  • Geo-blocking regionow nieobslugiwanych biznesowo
  • WAF logs do SIEM - korelacja z innymi zdarzeniami
  • Regular WAF rule reviews i aktualizacje (CRS 4.x co rok)
  • DDoS playbook + tabletop exercises
  • Kontakt 24/7 do dostawcy WAF/DDoS protection
  • Defense in depth - wiele warstw, nie poleganie na pojedynczym rozwiazaniu
