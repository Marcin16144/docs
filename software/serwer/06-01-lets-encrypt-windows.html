Let's Encrypt na Windows Server

Darmowe, automatycznie odnawiane certyfikaty TLS przez ACME - win-acme i Posh-ACME.

Czym jest Let's Encrypt

Let's Encrypt to publiczne CA (Certificate Authority) wydajace darmowe certyfikaty TLS przez protokol ACME (Automatic Certificate Management Environment, RFC 8555). Certyfikaty waznosc 90 dni - co wymusza automatyzacje odnawiania.

CechaWartosc
CenaDarmowy (0 zl)
Waznosc90 dni (zaplanowane skrocenie do 6 dni)
TypDomain Validated (DV) - tylko walidacja domeny
WildcardyTak (*.example.com), wymaga DNS-01 challenge
SAN (Subject Alternative Names)Tak, do 100 domen w jednym certyfikacie
Rate limit50 certyfikatow per zarejestrowana domena na tydzien
OCSP staplingWspierany

win-acme - najpopularniejszy klient

win-acme (WACS) to dojrzaly klient ACME dla Windows pisany w .NET. Latwo integruje sie z IIS, automatycznie konfiguruje binding HTTPS i tworzy Scheduled Task do odnawiania.

Instalacja

# Pobranie najnowszej wersji
$url = "https://github.com/win-acme/win-acme/releases/latest/download/win-acme.v2.2.x.x64.pluggable.zip"
$dest = "C:\Tools\win-acme"
New-Item -ItemType Directory -Force -Path $dest
Invoke-WebRequest -Uri $url -OutFile "$dest\wacs.zip"
Expand-Archive "$dest\wacs.zip" -DestinationPath $dest -Force

# Uruchomienie (wymaga uprawnien Administrator)
Set-Location $dest
.\wacs.exe

Interaktywne wydanie certyfikatu

.\wacs.exe

# Menu glowne:
# N: Create certificate (default settings)
# M: Create certificate (full options)
# R: Run renewals
# A: Manage renewals
# O: More options
# Q: Quit

# Wybor: N (najprostsze - dla witryny IIS)
# WACS pobiera liste witryn z IIS i pyta ktora wybrac.
# Po zatwierdzeniu wykonuje:
# 1. Generuje key pair RSA/ECDSA
# 2. Tworzy CSR
# 3. Wysyla zlecenie do Let's Encrypt
# 4. HTTP-01 challenge: zapisuje token w .well-known/acme-challenge
# 5. LE walid uje, wydaje certyfikat
# 6. Importuje cert do Cert:\LocalMachine\WebHosting
# 7. Konfiguruje HTTPS binding na porcie 443
# 8. Tworzy Scheduled Task "win-acme renew" - codziennie 09:00

Pelne opcje (M)

Tryb pelnych opcji daje pelna kontrole nad: HTTP-01 vs DNS-01 challenge, wybor walidatora (FTP, SFTP, plik), miejsce zapisu certyfikatu, format eksportu (PFX, PEM), instalacja w wielu miejscach, hooki przed/po.

Unattended (skrypt)

# Skrypt automatyczny dla wielu serwerow / CI/CD
.\wacs.exe `
    --target manual `
    --host "app.example.com,www.example.com" `
    --webroot "C:\inetpub\wwwroot" `
    --validation http-01 `
    --installation iis `
    --installationsiteid 1 `
    --emailaddress "admin@example.com" `
    --accepttos `
    --closeonfinish

# Listing certyfikatow Let's Encrypt
Get-ChildItem Cert:\LocalMachine\WebHosting |
    Where-Object { $_.Issuer -like "*Let's Encrypt*" } |
    Select Subject, Thumbprint, NotAfter, FriendlyName

# Eksport do PFX (np. dla innych aplikacji)
$cert = Get-ChildItem Cert:\LocalMachine\WebHosting |
    Where-Object { $_.Subject -like "*example.com*" } |
    Sort-Object NotAfter -Descending |
    Select-Object -First 1
$pwd = ConvertTo-SecureString "ExportPass!" -AsPlainText -Force
Export-PfxCertificate -Cert $cert `
                      -FilePath "C:\export\example.com.pfx" `
                      -Password $pwd

Automatyczne odnawianie

WACS tworzy Scheduled Task "win-acme renew" uruchamiany codziennie. Zadanie sprawdza czy ktores certyfikaty wygasaja w ciagu 30 dni i odnawia je. Jezeli odnawianie sie powiedzie, automatycznie aktualizuje binding IIS.

# Manualne uruchomienie odnowien
.\wacs.exe --renew

# Sprawdzenie listy zarejestrowanych odnowien
.\wacs.exe --list

# Konkretne odnowienie (test)
.\wacs.exe --renew --force --id "renewal-id-here"

# Sprawdzenie scheduled task
Get-ScheduledTask -TaskName "win-acme renew*"

Posh-ACME - alternatywa PowerShell

Posh-ACME to natywny modul PowerShell wspierajacy ACME z poziomu skryptow. Dobry dla automatyzacji, srodowisk bez IIS lub gdzie potrzebna pelna kontrola programowa.

# Instalacja
Install-Module Posh-ACME -Scope AllUsers -Force

# Konfiguracja serwera ACME (production)
Set-PAServer LE_PROD

# Akceptacja TOS i rejestracja konta
Set-PAAccount -KeyLength 2048 -Contact "admin@example.com" -AcceptTOS

# Wydanie certyfikatu z DNS-01 (Cloudflare)
$pArgs = @{
    CFToken = (Read-Host "Cloudflare token" -AsSecureString)
}
New-PACertificate "*.example.com","example.com" `
    -DnsPlugin Cloudflare `
    -PluginArgs $pArgs `
    -AcceptTOS

# Lokalizacja certyfikatow:
# %LocalAppData%\Posh-ACME\acme-v02.api.letsencrypt.org\
# Pliki: cert.cer, chain.cer, fullchain.cer, cert.key, cert.pfx

# Odnawianie wszystkich
Submit-Renewal -AllOrders

Best practices

  • HTTP-01 dla pojedynczych domen - prostota
  • DNS-01 dla wildcardow + dla serwerow nieosiagalnych z Internetu
  • Wildcard zamiast wielu pojedynczych - 1 cert dla *.example.com
  • WebHosting store zamiast Personal - wspoldzielony przez wiele witryn
  • Monitorowac waznosc certyfikatow (alert 14 dni przed wygasnieciem)
  • Backup konta ACME (klucz rejestracji) - utrata = nowa rejestracja
  • Staging environment LE do testow (LE_STAGE w Posh-ACME)
  • Hooki post-renewal: aktualizacja certyfikatu w innych aplikacjach (Postfix, RDS, RDP Gateway)
