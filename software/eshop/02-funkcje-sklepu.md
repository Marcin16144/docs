# 02: Funkcje sklepu internetowego

## Funkcje podstawowe (must-have)

| Obszar | Funkcja | Po co |
|--------|---------|-------|
| Katalog | Kategorie, podkategorie, atrybuty | Klient szybko znajduje produkt |
| Produkt | Warianty (rozmiar, kolor), galeria, opis | Pelna prezentacja oferty |
| Wyszukiwarka | Szukanie po nazwie, filtrowanie, sortowanie | Skraca sciezke do zakupu |
| Koszyk | Dodawanie, edycja ilosci, podsumowanie | Zbieranie zamowienia |
| Checkout | Dane, dostawa, platnosc w kilku krokach | Finalizacja zakupu |
| Konto klienta | Historia zamowien, adresy, sledzenie paczki | Powracajacy klienci |
| Platnosci | Bramka platnicza, przelew, pobranie | Przyjmowanie pieniedzy |
| Wysylka | Wybor kuriera, kalkulacja kosztu | Dostarczenie towaru |
| Magazyn | Stany, rezerwacja przy zamowieniu | Brak sprzedazy niedostepnego towaru |
| Dokumenty | Faktura / paragon, potwierdzenie zamowienia | Wymogi prawne i ksiegowe |

## Karta produktu — serce konwersji

Elementy, ktore realnie wplywaja na decyzje zakupowa:

- Wyrazne zdjecia (kilka ujec, zoom, kontekst uzycia)
- Cena, dostepnosc i czas wysylki widoczne bez przewijania
- Warianty z natychmiastowa zmiana ceny/zdjecia/stanu
- Konkretny opis + parametry techniczne w tabeli
- Opinie i oceny klientow
- Koszt i czas dostawy policzony juz na karcie
- Wyrazny przycisk "Dodaj do koszyka"
- Produkty powiazane / "klienci kupili rowniez"

## Checkout — gdzie traci sie zamowienia

Porzucenia koszyka to najwiekszy wyciek przychodu. Zasady dobrego checkoutu:

- **Zakupy bez rejestracji** (guest checkout) — rejestracja jako opcja, nie wymog.
- Minimum pol formularza; autouzupelnianie adresu po kodzie pocztowym.
- Wszystkie koszty (dostawa, podatek) widoczne przed ostatnim krokiem — zadnych niespodzianek.
- Pasek postepu / liczba krokow.
- Wiele metod platnosci i dostawy.
- Walidacja pol na biezaco, czytelne komunikaty bledow.
- Mobile-first — wiekszosc ruchu to telefony.

## Funkcje sprzedazowe i marketingowe

| Funkcja | Opis |
|---------|------|
| Kody rabatowe | Procentowe, kwotowe, na darmowa dostawe |
| Promocje | Ceny przekreslone, wyprzedaze, pakiety |
| Cross-sell / up-sell | Produkty powiazane, droższy wariant |
| Newsletter | Zapis do bazy mailingowej, lead magnet |
| Porzucony koszyk | Automatyczny mail przypominajacy |
| Program lojalnosciowy | Punkty, rabaty dla powracajacych |
| Lista zyczen (wishlist) | Zapis produktow na pozniej |
| Opinie i recenzje | Spoleczny dowod sluzy, wplyw na SEO |
| Powiadom o dostepnosci | Mail gdy produkt wroci na magazyn |

## Panel administracyjny

To, czego klient nie widzi, a co decyduje o kosztach obslugi:

- Zarzadzanie zamowieniami (statusy, zmiana, anulowanie)
- Zarzadzanie produktami i stanami magazynowymi
- Import/eksport katalogu (CSV, XML)
- Obsluga zwrotow i reklamacji
- Raporty sprzedazy, najlepsze produkty, marza
- Role uzytkownikow (admin, magazynier, obsluga klienta)
- Powiadomienia mailowe i SMS dla klienta

## Funkcje zaawansowane (gdy sklep rosnie)

- Wielojezycznosc i wielowalutowosc
- Ceny B2B, indywidualne cenniki, sprzedaz hurtowa
- Konfigurator produktu (personalizacja)
- Wyszukiwarka oparta o AI / rekomendacje
- Subskrypcje i platnosci cykliczne
- Sprzedaz wielokanalowa (omnichannel) — sklep + marketplace + POS
- PWA / aplikacja mobilna
