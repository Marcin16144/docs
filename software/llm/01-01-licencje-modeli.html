Komercja = uzywanie w produktach komercyjnych. Resale = sprzedaz modelu jako produkt. CPT = Continued Pre-training.

Trzy kategorie licencji

1. Apache 2.0 / MIT — najbardziej liberalne

Mozesz prawie wszystko:

  • ✓ Komercyjne uzycie
  • ✓ Modyfikacja
  • ✓ Dystrybucja
  • ✓ Sublicensing
  • ✓ Sprzedaz jako produkt
  • ✓ Continued pre-training i fine-tuning
  • ✓ Closed-source pochodne

Ograniczenia: zachowac copyright notice. Apache 2.0: zaznaczyc zmiany.

2. Custom Source-Available (Llama, Gemma)

Generalnie pozwalaja komercje, ALE z restrykcjami:

  • ⚠ Limity skali (np. 700M MAU dla Llamy)
  • ⚠ Acceptable Use Policy
  • ⚠ Atrybucja
  • ⚠ Restrykcje na trenowanie konkurencyjnych modeli
  • ⚠ Trademark restrictions

3. Non-Commercial / Research Only

NIE mozesz uzywac komercyjnie:

  • ✗ CC-BY-NC (Cohere Command, niektore research modele)
  • ✗ Custom non-commercial licenses

Najlepsze opcje dla scenariuszy

Najlepsze (najbardziej liberalne):

  2. Mistral 7B / Mixtral — Apache 2.0
  3. Phi-4 — MIT
  4. Qwen 2.5 — Apache 2.0

Dobrze, ale uwazaj:

  1. Llama 4 — najlepsza jakosc, ale 700M MAU limit i atrybucja
  2. Gemma 3 — AUP restrictions

Unikaj: Cohere Command (CC-BY-NC = research only)

"Chce continued pre-training na danych prawniczych"

Najlepsze:

  1. OLMo 2 — w pelni open
  2. DeepSeek V3 — najlepsza baza w 2026
  3. Llama 4 — sprawdzona
  4. Mistral 7B / Mixtral — Apache 2.0

Wszystkie pozwalaja na CPT. Wybor zalezy od skali, jezyka, domeny.

"Chce sprzedawac sam model (data product)"

Najlepsze: Apache 2.0 / MIT modele — Mistral 7B, Mixtral, OLMo, Pythia, Phi-4, DeepSeek

Trudniejsze: Llama, Gemma — szare strefy (skonsultuj z prawnikiem)

Co to dokladnie "Continued Pre-training"?

CPT = bierzesz pretrenowany model i trenujesz go DALEJ na nowych danych.

Llama 3 8B (pretrained)
     ↓
[Continued pre-training na 50B tokenow polskich tekstow]
     ↓
Polski-Llama-3-8B
     ↓
[SFT + DPO]
     ↓
Polski-Llama-3-8B-Instruct

Wszystkie wymienione open source modele pozwalaja na CPT. Ograniczenia tylko na: skale dystrybucji (Llama 700M MAU), use case (AUP), sprzedaz samego modelu.

Praktyczne zasady prawne

  1. Przeczytaj licencje — 2-10 stron tekstu, ma znaczenie
  2. Sprawdz AUP — Acceptable Use Policy (hate speech, weapons, CSAM, medical diagnosis itd.)
  3. Atrybucja — Apache 2.0: copyright notice. Llama: "Built with Llama"
  4. MAU limits — tylko Llama (700M) i niektore Qwen
  5. Skonsultuj z prawnikiem — przed sprzedaza produktu

NIE do komercji bez licencji

  • Books3 — prawnie ryzykowne, wycofane
  • News articles — copyright
  • Reddit data — zmieniona licencja, wymaga umowy
  • Twitter / X data — wymaga umowy

Quick decision tree

Czy chcesz tylko uzywac API?
├─ Tak → Anthropic / OpenAI / Google → ✓ Komercja OK
└─ Nie, chce self-host
   ├─ Najwyzsza jakosc?
   │  └─ Llama 4 70B / DeepSeek V3 → ✓ ale uwazaj na restrykcje
   ├─ Pelna swoboda prawna?
   │  └─ Apache 2.0 / MIT (Mistral, Phi-4, OLMo, DeepSeek)
   ├─ Sprzedaz samego modelu?
   │  └─ Apache 2.0 / MIT only (nie Llama)
   └─ Continued pre-training?
      └─ Wszystkie open source modele OK
