Podstawy LLM (Large Language Models)

Wprowadzenie do duzych modeli jezykowych - kluczowe pojecia, historia i rodzaje modeli.

Czym jest LLM?

Duzy Model Jezykowy (Large Language Model, LLM) to model uczenia maszynowego wytrenowany na ogromnych ilosciach tekstu, zdolny do rozumienia i generowania jezyka naturalnego. LLM przewiduje nastepny token (fragment slowa) na podstawie poprzednich, co pozwala mu prowadzic rozmowy, pisac kod, tlumaczyc teksty i rozwiazywac zlozone zadania.

Kluczowe pojecia

PojecieWyjasnienie
TokenNajmniejsza jednostka tekstu (~3-4 znaki w angielskim). Modele przetwarzaja tokeny, nie znaki/slowa.
EmbeddingWektorowa reprezentacja tokenu - np. 4096 liczb opisujacych znaczenie.
ParameterPojedyncza wartosc wagi w sieci neuronowej. Llama 3 70B = 70 mld parametrow.
Context windowMaksymalna liczba tokenow, ktore model moze przetworzyc naraz (np. 200k dla Claude).
InferenceProces generowania odpowiedzi przez wytrenowany model.
TrainingProces uczenia modelu na danych.
Fine-tuningDostosowanie wytrenowanego modelu do specyficznego zadania.
TemperatureParametr losowosci (0 = deterministyczny, 1 = kreatywny).
Top-p / Top-kStrategie samplowania kolejnego tokenu.
HallucinationGenerowanie nieprawdziwych, ale przekonujacych informacji.

Krotka historia

1950s - Modele n-gramowe (statystyka)
1980s - Sieci neuronowe (Hopfield, Boltzmann)
1997  - LSTM (Long Short-Term Memory)
2013  - Word2Vec (embeddingi slow)
2017  - Transformer ("Attention is All You Need")
2018  - BERT (Google), GPT-1 (OpenAI)
2019  - GPT-2 (1.5B parametrow)
2020  - GPT-3 (175B parametrow)
2022  - ChatGPT - przelom dla mainstreamu
2023  - GPT-4, Claude, Llama 2 (open source)
2024  - Claude 3.5/3.7, GPT-4o, Llama 3, multimodal
2025  - Claude 4, GPT-5, agentic systems, reasoning models
2026  - Claude Opus 4.6/4.7, AI agents w produkcji

Open source vs closed source

Closed-source (API)

Zalety:

  • Najnowsze, najmocniejsze modele
  • Bez kosztow infrastruktury
  • Skalowanie automatyczne
  • Wsparcie producenta

Wady:

  • Zaleznosc od dostawcy (vendor lock-in)
  • Koszt per token (drogie przy duzej skali)
  • Dane wysylane na zewnatrz
  • Brak kontroli nad modelem

Open-source (lokalnie)

Zalety:

  • Pelna kontrola nad modelem i danymi
  • Brak kosztow per request (po inwestycji w hardware)
  • Mozliwosc fine-tuningu
  • Privacy - dane zostaja u Ciebie
  • Brak limitow rate

Wady:

  • Wymagany hardware (GPU)
  • Slabsze niz najwieksze modele zamkniete (roznica sie jednak zmniejsza)
  • Koniecznosc zarzadzania infrastruktura
  • Brak najnowszych funkcji (tool use czesto slabszy)

Czego oczekiwac od LLM?

Co LLM robia dobrze:

  • Rozumienie jezyka naturalnego
  • Generowanie tekstu (artykuly, e-maile, kod)
  • Tlumaczenie miedzy jezykami
  • Streszczanie i parafrazowanie
  • Klasyfikacja tekstu i analiza sentymentu
  • Odpowiadanie na pytania na podstawie kontekstu
  • Pomoc w programowaniu (Claude Code, GitHub Copilot)

Co LLM robia slabo:

  • Liczenie i precyzyjna matematyka (bez tools)
  • Aktualne informacje (cutoff date)
  • Spojnosc dlugich rozumowan
  • Faktografia bez RAG (halucynacje)
  • Operacje na bardzo dlugich dokumentach (mimo duzego kontekstu)
  • Deterministyczne, powtarzalne wyniki

Skala modeli

~1B params   -> Phi-3-mini, Llama 3.2 (1B)
              + Dziala na laptopie
              + Proste zadania, klasyfikacja
              - Slabe rozumowanie

~7B params   -> Llama 3.1 8B, Mistral 7B
              + Dziala na 8GB VRAM (kwantyzacja)
              + Dobre do wiekszosci zastosowan
              ~ Rozumowanie ograniczone

~70B params  -> Llama 3.3 70B
              + Bardzo zdolne
              - Wymaga 40+ GB VRAM (lub kwantyzacja na 24GB)
              + Bliskie GPT-4 w wielu zadaniach

~400B+ params -> Llama 3.1 405B, Claude Opus, GPT-4
              + Najwyzsza jakosc
              - Trudne do uruchomienia lokalnie
              -> Najczesciej via API
