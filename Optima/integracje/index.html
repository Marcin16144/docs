Integracje i API

Wymiana danych Comarch ERP Optima z innymi programami — API, Excel, CSV, XML, JPK/KSeF, bank, usługi web

Aktualizacja: 2026-06 · na podstawie dokumentacji Comarch (pomoc.comarch.pl) i źródeł partnerskich

ℹ️ Optima nie ma jednego, jednolitego „API" — pod tym pojęciem kryje się kilka równoległych mechanizmów (COM, WebService, REST, wymiana plikowa). Wybór zależy od architektury, wymagań i zakresu synchronizacji. Część szczegółów technicznych API i Migratora jest dostępna tylko na zamkniętych Stronach Partnerów Comarch — oznaczono je jako „do weryfikacji".
Spis: API · Excel · CSV/TXT · XML / Migrator · JPK / KSeF / Płatnik · Bank · Usługi web · Ekosystem · Kadry i Płace · Tabela zbiorcza

1. API Optima (interfejs programistyczny)

Obiekty COM / Automation („API stacjonarne")

Najstarszy i najgłębszy sposób komunikacji z logiką biznesową i bazą Optimy — operacje na dokumentach, kontrahentach, towarach, operatorach i bazie SQL Server. Model sesyjny: logowanie → operacje → wylogowanie. Do logowania wykorzystuje się biblioteki Common.dll i Common.Logic.dll z katalogu instalacyjnego, a do pracy z obiektami — bibliotekę CDNBase (i pozostałe CDN*). Wymaga wysokich kompetencji i znajomości struktury bazy MSSQL.

WebService (SOAP/XML/WSDL) i REST / Web API

  • WebService (SOAP) — starsze integracje B2B i systemy legacy.
  • REST / Web API (HTTP/HTTPS, JSON) — najnowocześniejsze podejście dla aplikacji webowych, e-commerce, mobile i SaaS; dodawanie/modyfikacja dokumentów w modułach handlowym, magazynowym, księgowym i kadrowo-płacowym; autoryzacja tokenami sesyjnymi + HTTPS.
⚠ Do weryfikacji: znaczna część rozwiązań „Web API do Optimy" to produkty firm partnerskich (nakładki na model COM/bazę), a nie natywny komponent Comarch. Istnienie osobno licencjonowanego, natywnego modułu „Comarch ERP Optima API" w aktualnym cenniku nie jest jednoznacznie potwierdzone — sprawdź u partnera. Dla integracji opartych na bazie/COM kluczowy jest moduł dający dostęp do bazy (najczęściej Kasa/Bank).

Robotyzacja (RPA) — wbudowana automatyzacja

Optima zawiera standardowy, bezpłatny moduł Robotyzacja (RPA) + funkcje AI: automatyczne przenoszenie dokumentów kosztowych z Handlu do Rejestrów VAT, księgowanie, wymianę z bankiem (eksport przelewów / import wyciągów), pobieranie kursów NBP, fakturowanie cykliczne, windykację. To wewnętrzny mechanizm (nie zewnętrzne API), ale istotny w scenariuszach integracyjnych.

2. Import / eksport przez MS Excel

  • Eksport list i raportów — praktycznie każdą listę/raport można wyeksportować do Excela (ikona na listach). Zalecany format: MS Excel 97-2003 (.xls).
  • Import/eksport cennika i towarów — z poziomu listy towarów; od wersji 2021.4 obejmuje też dane dla e-Sklepu (nazwy/opisy w językach, dostępność, atrybuty). Można wybrać aktualizowane pola (nazwa, VAT, EAN, ceny, jednostki…).
  • Import kontrahentów — min. 3 kolumny: Kod, Nazwa, NIP. Import towarów — min. Kod, Nazwa, J.M. (biuletyn OPT009 – Import danych z arkusza MS Excel).
  • Comarch ERP Optima Analizy BI — dodatek analityczny: ~197 raportów, 9 dashboardów, analizy ad-hoc (drag&drop), subskrypcje, dane z zewnętrznych źródeł (pliki Excel, zewnętrzne bazy). Rozszerzalny o Comarch BI Point (platforma webowa).

3. Pliki CSV i tekstowe

  • Optima wymienia dane głównie w .XML i .TXT; obsługuje też CSV/PLI/TXT.
  • Import wyciągów bankowych z CSV/TXT — konfiguracja separatora pól (np. średnik), separatora tekstu, formatu daty (RRRR-MM-DD), separatora dziesiętnego. Ograniczenia: tylko jeden wiersz nagłówka, format bez stopki.
  • Strony kodowe dla polskich znaków: Windows-1250, Latin II, ISO-8859-2, Mazovia, UTF-8.
  • Własne formaty: Ogólne / Inne / Formaty przelewów.

4. Pliki XML i wymiana między bazami

  • Comarch Migrator — migracja danych do Optimy z innych systemów (arkusze Excel + pliki XML), przycisk „Migruj Dane". ⚠ Przeznaczony wyłącznie dla Autoryzowanych Partnerów (struktura arkuszy na Stronach Partnerów).
  • Praca rozproszona — wymiana offline plikami XML między Działem Sprzedaży/Płac a Księgowością (typowo biuro rachunkowe ↔ klient): rejestry VAT, dokumenty sprzedaży/zakupu, listy płac, dane słownikowe. Od wersji 2017.5.1 plik XML jest kompresowany (.zip).
  • Internetowa Wymiana Dokumentów (IWD) — wariant online pracy rozproszonej przez serwer wymiany Comarch (biuletyn OPT039).
  • Comarch ERP XL ↔ Optima — pliki .XLO (spakowane XML). Comarch DMS/BPM zasila moduł księgowy (FK) rejestrami VAT i wyciągami przez wymianę XML.

5. JPK, KSeF, e-Deklaracje, Płatnik

JPK (Jednolity Plik Kontrolny)

Generowane struktury: JPK_V7 (V7M/V7K), JPK_FA, JPK_KR, JPK_MAG, JPK_WB, JPK_EWP, JPK_PKPIR. JPK_V7 — obowiązkowy, miesięcznie do 25. dnia; bezpośrednia wysyłka z programu (podpis kwalifikowany / niekwalifikowany / Profil Zaufany). Od lutego 2026 obowiązuje JPK_V7(3) z numerem KSeF i nowymi kodami (m.in. OFF — faktury offline); obsługa w Optimie od 2026.3.1.

KSeF (Krajowy System e-Faktur)

  • Wysyłka i odbiór faktur ustrukturyzowanych — pojedyncza i wsadowa (paczki ZIP, błąd jednego pliku nie blokuje paczki).
  • Automat wysyłki (interwał lub przy zatwierdzeniu dokumentu). Konfiguracja: KSeF 2.0 — Token lub Certyfikat KSeF; w Konfiguracja/Firma/Dane firmy/KSeF.
  • ⚠ Komunikacja z KSeF jest bezpłatna (model subskrypcyjny i nowi klienci — okres bezpłatny do końca 2026); dla starszych licencji wieczystych — do weryfikacji w cenniku.

e-Deklaracje i Program Płatnik (ZUS)

  • e-Deklaracje — bezpośrednia wysyłka PIT/CIT/VAT i JPK_V7 do systemu MF, z odbiorem UPO.
  • Płatnik / ZUS — „Eksport do programu Płatnik" (plik KEDU XML) lub „Wyślij bezpośrednio do ZUS"; deklaracje DRA, RCA, RSA. Możliwy też import z KEDU oraz import danych kadrowych z Płatnika (na podstawie ZUS ZUA).

7. Usługi zewnętrzne (web)

  • GUS/REGON — pobieranie danych kontrahenta po NIP/REGON i zakładanie kartoteki.
  • VIES — weryfikacja statusu VAT-UE po NIP (baza Komisji Europejskiej).
  • Status VAT (Portal Podatkowy MF) — czynny/zwolniony/niezarejestrowany; ręcznie lub automatycznie na dokumentach.
  • Biała lista (Wykaz podatników VAT) — automatyczne pobieranie rachunków bankowych kontrahenta i weryfikacja.
  • e-Doręczenia — realizowane przez Comarch DMS/BPM (wymaga licencji BPM Premium, pieczęci i certyfikatu), nie bezpośrednio w samej Optimie. ⚠ do weryfikacji.
⚠ Funkcje weryfikacji/pobierania danych z GUS/VIES/białej listy dostępne są tylko dla programów na gwarancji (aktualna asysta/subskrypcja).

8. Ekosystem Comarch i e-commerce

  • Comarch e-Sklep / e-Sale — dwukierunkowa synchronizacja: eksport towarów, cen, stanów, zdjęć; import zamówień. Automat synchronizacji (cykliczny).
  • wszystko.pl — platforma sprzedażowa Comarch (eksport oferty/cen/stanów, import zamówień i kategorii).
  • Allegro i inne platformy — przez e-Sklep/e-Sale lub integratory partnerskie; wbudowana integracja z kurierami (DHL, DPD, Poczta Polska, InPost/Paczkomaty).
  • Comarch HRM — praca/urlopy/czas pracy (współdzieli bazę z Kadrami i Płacami). Comarch DMS/BPM — obieg dokumentów. Comarch Mobile (Sprzedaż/Serwis) i Comarch WMS (magazyn). Comarch BI Point — analityka webowa. iBard — backup w chmurze.
