Mastering (Project Page)

Strona Project, montaż albumu, metering, loudness, dithering oraz eksport DDP i Red Book

Aktualizacja: 2026-06

Wyróżnikiem Studio One jest zintegrowana Project Page — pełnoprawne środowisko masteringu w tym samym programie. Składasz w niej gotowe utwory w album, dbasz o spójną głośność i eksportujesz finalny materiał: do plików cyfrowych, jako DDP lub obraz płyty Red Book.

Czym jest Project Page

Project to osobny typ dokumentu obok Songu. Zamiast ścieżek wielośladowych pracujesz na gotowych miksach (zmasterowanych utworach) ułożonych jeden po drugim na osi albumu. Najważniejsza cecha to żywy link do Songów:

🎵 Song

  • Wielośladowa produkcja
  • Miks na busy i master
  • Źródło utworu
⇄ żywy link
(Update Mastering File)

💿 Project

  • Album z gotowych miksów
  • Metering i loudness
  • Eksport cyfra / DDP

Gdy poprawisz coś w Songu, Project zaznaczy, że dany utwór jest nieaktualny — jednym poleceniem Update pobierzesz świeży miks bez ręcznego eksportu i importu.

⚠ Project Page jest dostępna wyłącznie w edycji Professional. W Prime i Artist mastering wykonasz w obrębie Songu lub w zewnętrznym narzędziu.

Montaż albumu

Po dodaniu utworów do Projektu układasz z nich spójną całość:

  1. Przeciągnij gotowe Songi/pliki do listy ścieżek Projektu i ustaw ich kolejność.
  2. Dopasuj przerwy między utworami oraz crossfade'y tam, gdzie mają płynnie przechodzić.
  3. Wyrównaj gain poszczególnych utworów, by album grał równo.
  4. Dodaj znaczniki ścieżek (track markers) — trafią do metadanych płyty/DDP.
Element montażuRola
Track / PausePunkty startu utworów i przerwy między nimi (dla płyty CD).
CrossfadePłynne przejście jednego utworu w kolejny (albumy ciągłe, koncertowe).
MetadaneTytuły, wykonawca, kody — zapisywane w DDP / CD-Text.

Metering i loudness

Project Page ma wbudowane metrowanie, które pomaga utrzymać spójną i zgodną z normami głośność całego albumu:

MiernikCo pokazuje
LUFS (Integrated)Uśredniona głośność postrzegana — kluczowa dla streamingu.
True PeakRzeczywiste szczyty międzypróbkowe — pilnuj zapasu, by uniknąć przesterowań po konwersji.
RMSŚrednia energia sygnału — pomocnicza ocena „gęstości".
✅ Dla większości serwisów streamingowych celuj w okolice −14 LUFS (integrated) i trzymaj true peak z zapasem (np. −1 dBTP). Dla płyty CD głośność bywa wyższa — dopasuj do charakteru wydania.

Na magistrali masteringu Projektu wstawisz finalne procesory (np. EQ, kompresor, limiter) działające na cały album spójnie.

Dithering i eksport (cyfra, DDP, Red Book)

Na końcu Project eksportuje materiał w docelowym formacie. Jeśli zmniejszasz rozdzielczość do 16 bitów (np. dla CD), włącz dithering, by zamaskować błędy kwantyzacji.

Cel eksportuOpis
Digital ReleasePliki audio (WAV/FLAC itp.) całego albumu, z metadanymi — pod dystrybucję cyfrową.
DDPDisc Description Protocol — standardowy „master" wysyłany do tłoczni płyt.
Red Book (obraz płyty)Obraz CD zgodny ze standardem Red Book, gotowy do wypalenia/replikacji.
💽 Dither stosuj tylko raz, na ostatnim etapie redukcji bitów. Jeśli eksportujesz wersję 24-bit (np. do streamingu hi-res), dither nie jest potrzebny.
