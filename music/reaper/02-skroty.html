Action List i własne skróty

To największa siła REAPER. Naciśnij ?, aby otworzyć Action List — listę wszystkich akcji programu.

  • Przypisanie skrótu: zaznacz akcję → Add… w sekcji „Shortcuts for selected action" → naciśnij wybraną kombinację.
  • Custom actions: połącz wiele akcji w jedną makro-akcję (przycisk New action → New custom action) i przypisz jej skrót.
  • Konteksty: osobne zestawy skrótów dla Main, MIDI Editor, Media Explorer (rozwijana lista u góry Action List).
  • Eksport/import: zapisz swój układ skrótów (KeyMap) i przenoś między komputerami.
✅ F12 przełącza Shortcut Help — po włączeniu naciśnięcie dowolnego klawisza pokazuje, jaka akcja jest do niego przypisana. Świetne do nauki.
