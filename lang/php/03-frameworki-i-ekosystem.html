Symfony 7 - kiedy uzyc

Symfony to fundament wielu PHP frameworkow (Laravel, Drupal, ezPlatform). Komponenty Symfony sa uzywane wszedzie - HttpFoundation, Routing, Console, Serializer, Validator.

# Tworzenie nowego projektu
composer create-project symfony/skeleton:^7.0 my-app
cd my-app
composer require webapp  # pelny pakiet (Twig, Doctrine, etc.)

# Uruchomienie dev server
symfony server:start

Przykladowy controller w Symfony 7

<?php
namespace App\Controller;

use Symfony\Bundle\FrameworkBundle\Controller\AbstractController;
use Symfony\Component\HttpFoundation\JsonResponse;
use Symfony\Component\Routing\Attribute\Route;

class ApiController extends AbstractController
{
    #[Route('/api/users/{id}', methods: ['GET'])]
    public function show(int $id): JsonResponse
    {
        return $this->json([
            'id' => $id,
            'name' => 'Anna',
        ]);
    }
}

Laravel 11

Laravel to najpopularniejszy PHP framework, znany z eleganckiej skladni i ogromnego ekosystemu (Forge, Vapor, Nova, Livewire, Inertia).

# Instalator Laravel
composer global require laravel/installer

# Lub przez composer
composer create-project laravel/laravel:^11.0 my-app

# Artisan - CLI
php artisan serve
php artisan make:controller UserController
php artisan migrate

Eloquent ORM w Laravel

<?php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\HasMany;

class User extends Model
{
    protected $fillable = ['name', 'email'];

    public function posts(): HasMany
    {
        return $this->hasMany(Post::class);
    }
}

// Uzycie
$user = User::find(1);
$posts = $user->posts;

// Eager loading
$users = User::with('posts')->where('active', true)->get();

Composer - package manager

# Najczesciej uzywane komendy

Statyczna analiza: PHPStan / Psalm

To dwa konkurencyjne narzedzia static analysis - znajduja bledy bez uruchamiania kodu. PHPStan jest popularniejszy w 2026.

# Instalacja PHPStan
composer require --dev phpstan/phpstan

# phpstan.neon
parameters:
    level: 8                # 0-9, 9 = strict
    paths:
        - src
        - tests

# Uruchomienie
vendor/bin/phpstan analyse

Testowanie: PHPUnit / Pest

PHPUnit to klasyk, a Pest to nowoczesna nakladka z prostsza skladnia (na bazie PHPUnit).

// Pest - przyklad
test('user can be created', function () {
    $user = new User('Anna', 'anna@example.com');

    expect($user->name)->toBe('Anna')
        ->and($user->email)->toBe('anna@example.com');
});

it('throws on invalid email', function () {
    new User('X', 'invalid');
})->throws(InvalidArgumentException::class);

Rector - automatyczne refaktoryzacje

Rector przepisuje kod do nowoczesnych standardow - migracje wersji PHP, framework upgrades, itp.

# rector.php
return RectorConfig::configure()
    ->withPaths([__DIR__ . '/src'])
    ->withPhpSets(php83: true)
    ->withTypeCoverageLevel(0);

# Uruchomienie
vendor/bin/rector process

Runtime - PHP-FPM, FrankenPHP, RoadRunner

PHP-FPM (klasyk)

FastCGI Process Manager - tradycyjny sposob serwowania PHP. Kazdy request to nowy proces / worker (z poola).

FrankenPHP (nowoczesny)

Modern application server na bazie Caddy, napisany w Go. Wbudowany HTTP/2, HTTP/3, automatyczne SSL. Worker mode - utrzymuje aplikacje w pamieci miedzy requestami.

# Docker
docker run -v $PWD:/app/public dunglas/frankenphp

# Kompilacja PHP do statycznego binary z FrankenPHP
frankenphp php-cli script.php

RoadRunner (Go-based)

Application server w Go, podobny do FrankenPHP. Pozwala uruchomic dlugozyjace workery PHP - bez kosztow boot na kazdym requeste.
