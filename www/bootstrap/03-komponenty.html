Komponenty Bootstrap

Przyciski, formularze, navbar, modale, dropdowns, accordion, tabs, toasts, offcanvas, carousel

Buttons

Klasa .btn tworzy stylizowany przycisk. Wariant koloru dodajesz suffixem.

<button class="btn btn-primary">Primary</button>
<button class="btn btn-success">Success</button>
<button class="btn btn-outline-danger">Outline Danger</button>
<button class="btn btn-lg btn-warning">Duzy</button>
<button class="btn btn-sm btn-info">Maly</button>

Dostepne warianty: primary, secondary, success, danger, warning, info, light, dark, link. Kazda z opcja outline.

Forms

Klasa .form-control stylizuje inputy. Razem z .form-label tworza spojne pola formularza. Klasa .is-invalid/.is-valid wyswietla state po walidacji.

<form>
  <div class="mb-3">
    <label for="email" class="form-label">Email</label>
    <input type="email" class="form-control" id="email" placeholder="user@example.com">
    <div class="form-text">Nigdy nie pokazemy go publicznie.</div>
  </div>
  <div class="form-check">
    <input class="form-check-input" type="checkbox" id="zgoda">
    <label class="form-check-label" for="zgoda">Akceptuje regulamin</label>
  </div>
  <button type="submit" class="btn btn-primary">Wyslij</button>
</form>

Navbar

Pasek nawigacji typowy dla aplikacji webowych. Dziala z gridem i jest responsywny — na malym ekranie zwija sie do hamburger menu.

<nav class="navbar navbar-expand-lg bg-body-tertiary">
  <div class="container-fluid">
    <a class="navbar-brand" href="#">Logo</a>
    <button class="navbar-toggler" type="button" data-bs-toggle="collapse" data-bs-target="#navMain">
      <span class="navbar-toggler-icon"></span>
    </button>
    <div class="collapse navbar-collapse" id="navMain">
      <ul class="navbar-nav me-auto">
        <li class="nav-item"><a class="nav-link active" href="#">Home</a></li>
        <li class="nav-item"><a class="nav-link" href="#">O nas</a></li>
      </ul>
    </div>
  </div>
</nav>

Modal

Okienko dialogowe z overlay. Otwierane za pomoca atrybutow data lub przez API JS.

<button class="btn btn-primary" data-bs-toggle="modal" data-bs-target="#exampleModal">
  Otworz modal
</button>

<div class="modal fade" id="exampleModal" tabindex="-1">
  <div class="modal-dialog">
    <div class="modal-content">
      <div class="modal-header">
        <h5 class="modal-title">Tytul</h5>
        <button class="btn-close" data-bs-dismiss="modal"></button>
      </div>
      <div class="modal-body">Tresc okna.</div>
      <div class="modal-footer">
        <button class="btn btn-secondary" data-bs-dismiss="modal">Zamknij</button>
        <button class="btn btn-primary">Zapisz</button>
      </div>
    </div>
  </div>
</div>

API w JS:

const modal = new bootstrap.Modal('#exampleModal');
modal.show();
modal.hide();

Tabs

<ul class="nav nav-tabs" role="tablist">
  <li class="nav-item">
    <button class="nav-link active" data-bs-toggle="tab" data-bs-target="#tab1">Tab 1</button>
  </li>
  <li class="nav-item">
    <button class="nav-link" data-bs-toggle="tab" data-bs-target="#tab2">Tab 2</button>
  </li>
</ul>
<div class="tab-content">
  <div id="tab1" class="tab-pane fade show active">Zawartosc 1</div>
  <div id="tab2" class="tab-pane fade">Zawartosc 2</div>

Toasts

Lekkie powiadomienia, dobre dla informacji o zapisaniu, blednych dzialaniach itp.

<div class="toast-container position-fixed bottom-0 end-0 p-3">
  <div id="myToast" class="toast" role="alert">
    <div class="toast-header">
      <strong class="me-auto">Powiadomienie</strong>
      <button class="btn-close" data-bs-dismiss="toast"></button>
    </div>
    <div class="toast-body">Plik zostal zapisany.</div>
  </div>
</div>
<script>
  const t = new bootstrap.Toast('#myToast');
  t.show();
</script>

Offcanvas

Wysuwany panel boczny — np. menu mobilne lub szuflada filtrow.

<button class="btn btn-primary" data-bs-toggle="offcanvas" data-bs-target="#filtry">
  Filtry
</button>

<div class="offcanvas offcanvas-end" id="filtry">
  <div class="offcanvas-header">
    <h5 class="offcanvas-title">Filtry</h5>
    <button class="btn-close" data-bs-dismiss="offcanvas"></button>
  </div>
  <div class="offcanvas-body">
    Tresc panelu...
  </div>
</div>

Carousel

Slider z slajdami obrazow lub kart.

<div id="carousel1" class="carousel slide" data-bs-ride="carousel">
  <div class="carousel-inner">
    <div class="carousel-item active">
      <img src="slide1.jpg" class="d-block w-100">
    </div>
    <div class="carousel-item">
      <img src="slide2.jpg" class="d-block w-100">
    </div>
  </div>
  <button class="carousel-control-prev" data-bs-target="#carousel1" data-bs-slide="prev">
    <span class="carousel-control-prev-icon"></span>
  </button>
</div>

Tooltips i popovers

Wymagaja inicjalizacji w JS, bo z opt-in:

const tooltipList = document.querySelectorAll('[data-bs-toggle="tooltip"]');
tooltipList.forEach(el => new bootstrap.Tooltip(el));

const popoverList = document.querySelectorAll('[data-bs-toggle="popover"]');
popoverList.forEach(el => new bootstrap.Popover(el));
<button data-bs-toggle="tooltip" title="Komunikat">Hover mnie</button>
<button data-bs-toggle="popover" data-bs-content="Tresc">Klik mnie</button>

Cards

<div class="card" style="width: 18rem;">
  <img src="thumb.jpg" class="card-img-top">
  <div class="card-body">
    <h5 class="card-title">Tytul</h5>
    <p class="card-text">Krotki opis karty.</p>
    <a href="#" class="btn btn-primary">Akcja</a>
  </div>
</div>
