Bulma CSS

Modern CSS framework w czystym Sass — flexbox-first, bez JS, niezalezny od Bootstrap

Co to jest Bulma?

Bulma to open-source CSS framework stworzony przez Jeremy Thomas w 2016. Wyroznia sie tym, ze nie zawiera zadnego JavaScript — to czyste CSS oparte na Sass. Filozofia "minimum CSS, maximum kontroli". Bardzo popularny wsrod CSS purystow i tych, ktorzy chca przejrzystego kodu bez zaleznosci.

W 2026 Bulma ma stabilnie utrzymywana wersje 1.x. Konkurencja z Tailwind i Bootstrap go zepchnela do niszy, ale dalej ma okolo 50000 GitHub stars i aktywne community.

Kluczowe cechy

  • 100% Sass — pelna mozliwosc customizacji przez zmienne
  • Flexbox-first — nowoczesny layout, brak floats
  • Bez JS — brak zaleznosci, brak bundle JS
  • Modular — importuj tylko to, czego uzywasz
  • Responsive — mobile-first, breakpointy dostosowane
  • Modern syntax — klasy semantyczne (.button, .card, .navbar)
  • Accessibility-friendly

Instalacja

npm install bulma

// SCSS
@import "bulma/bulma";

// Albo CDN
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bulma@1.0.0/css/bulma.min.css">

Kiedy uzyc Bulma?

  • Aplikacje proste, bez wymagan unikalnego designu
  • Zespol preferujacy czyste CSS nad utility-first
  • Projekty bez build pipeline (CDN dziala od razu)
  • Przypadki gdzie nie chcesz dolaczac JS bundle
  • Nauka CSS — Bulma kod jest czytelny
