Rendering i materiały

Silniki Eevee i Cycles, materiały (Principled BSDF), oświetlenie, kamera i ustawienia renderu

Aktualizacja: 2026-06

Rendering to wyliczenie finalnego obrazu z modeli, materiałów i świateł. O wyniku decydują trzy rzeczy: wybrany silnik, materiały obiektów i oświetlenie sceny.

Silniki renderujące: Eevee vs Cycles

EeveeCycles
Typrasteryzacja (jak w grach) — czas rzeczywistypath tracing — fizyczne śledzenie promieni
Szybkośćbardzo szybkiwolniejszy (ale fotorealistyczny)
Jakość światłaprzybliżona (odbicia, GI z ograniczeniami)realistyczna — odbicia, refrakcja, caustics
Najlepszy doanimacja, stylizacja, podgląd, szybkie projektyfotorealizm, render produktowy, finalne ujęcia

Silnik wybierasz w Render Properties (ikona aparatu z tyłem). Podgląd materiałów i świateł w oknie 3D włączysz klawiszem Z → Material Preview lub Rendered.

✅ Ucz się i animuj w Eevee (natychmiastowy podgląd), a finalny, „ładny" kadr wyrenderuj w Cycles z włączonym GPU. Ten sam materiał Principled BSDF działa w obu silnikach.

Materiały (Principled BSDF)

Materiał nadajesz w Material Properties (ikona kuli). Domyślny shader Principled BSDF jednym węzłem opisuje niemal każdą powierzchnię:

ParametrZa co odpowiada
Base Colorkolor podstawowy powierzchni
Metallicczy to metal (0 = dielektryk, 1 = metal)
Roughnesschropowatość — 0 = lustro, 1 = mat
IOR / Transmissionprzezroczystość i załamanie (szkło, woda)
Emissionświecenie własne (neony, ekrany)
Normalmapa wypukłości (detale bez geometrii)
🎨 Tekstury (zdjęcia) podpinasz w Shader Editor (workspace Shading) węzłem Image Texture. By tekstura legła poprawnie na modelu, trzeba go rozwinąć (UV unwrap) — zaznacz wszystko w Edit Mode i naciśnij U → Smart UV Project.

Oświetlenie

Bez światła render jest czarny. Dodaj je przez Shift+A → Light:

LampaCharakter
Pointpunktowa, świeci równo we wszystkie strony (żarówka)
Sunrównoległe promienie o stałej mocy (słońce) — kierunek, nie pozycja
Spotstożek światła (reflektor)
Areamiękkie światło z powierzchni (softbox, okno) — najładniejsze cienie
✅ Najszybszy realizm daje HDRI: w World Properties podłącz węzeł Environment Texture z mapą .hdr — scena dostaje naturalne światło i tło otoczenia. Klasyka oświetlenia postaci to three-point lighting: key, fill i rim.

Kamera

  • Patrz przez kamerę: Num0. Ustaw kamerę do bieżącego widoku: Ctrl+Alt+Num0.
  • Ogniskowa (Focal Length): w Object Data Properties kamery — mniejsza (18 mm) = szeroki kąt, większa (85 mm) = „teleobiektyw", ładne portrety.
  • Głębia ostrości (DoF): włącz Depth of Field i wskaż punkt ostrości — rozmywa tło (efekt „bokeh").

Ustawienia renderu (jakość)

UstawienieOpis
Samples (Cycles)liczba próbek na piksel — więcej = mniej szumu, dłuższy render
Denoiseodszumianie (OptiX / OpenImageDenoise) — pozwala zejść z próbkami i renderować szybciej
Resolutionrozdzielczość wyjściowa i procent skali (np. 50% do testów)
GPU Computew Render Properties → Device — wybierz GPU zamiast CPU dla Cycles
⚠️ Render w Cycles potrafi być pamięciożerny. Jeśli scena nie mieści się w VRAM, włącz „GPU+CPU" lub zmniejsz tekstury. Eevee jest pod tym względem znacznie lżejszy.

Eksport — obraz i animacja

  • Pojedyncza klatka: F12 → Image → Save As (PNG/JPEG).
  • Animacja: w Output Properties ustaw format i ścieżkę, potem Render → Render Animation (Ctrl+F12). Szczegóły — patrz Animacja → Render animacji.
  • Przezroczyste tło: Render Properties → Film → Transparent (do kompozycji na wideo).
