Routing

React Router 7, Next.js App Router, Tanstack Router

Trzy glowne opcje

React sam nie posiada routera — to oddzielna biblioteka. W 2026 dominuja:

  • React Router 7 — standard SPA, w 2024 polaczyl sie z Remix
  • Next.js App Router — file-based routing w meta-frameworku
  • Tanstack Router — type-safe routing z file-based lub code-based

React Router 7

W 2024 Remix (meta-framework od tworcow React Router) zostal wlaczony do React Router 7. Mozesz uzywac go jako:

  • SPA mode — klasyczny client-side routing (jak v6)
  • Framework mode — full-stack z loaders, actions, SSR (dawny Remix)
# Instalacja
npm i react-router

// app.jsx — SPA mode
import { BrowserRouter, Routes, Route, Link, Outlet, useParams } from 'react-router';

function Layout() {
  return (
    <>
      <nav>
        <Link to="/">Home</Link>
        <Link to="/posts">Posty</Link>
      </nav>
      <main><Outlet /></main>
    </>
  );
}

function Post() {
  const { id } = useParams();
  return <h1>Post {id}</h1>;
}

export default function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<Layout />}>
          <Route index element={<Home />} />
          <Route path="posts">
            <Route index element={<PostList />} />
            <Route path=":id" element={<Post />} />
          </Route>
          <Route path="*" element={<NotFound />} />
        </Route>
      </Routes>
    </BrowserRouter>
  );
}

Framework mode (loaders i actions)

// routes/posts.$id.jsx
export async function loader({ params }) {
  const post = await db.posts.find(params.id);
  if (!post) throw new Response('Not found', { status: 404 });
  return post;
}

export async function action({ request, params }) {
  const fd = await request.formData();
  await db.posts.update(params.id, { title: fd.get('title') });
  return redirect(`/posts/${params.id}`);
}

export default function PostRoute() {
  const post = useLoaderData();
  return (
    <Form method="post">
      <input name="title" defaultValue={post.title} />
      <button>Zapisz</button>
    </Form>
  );
}

Next.js App Router

W Next.js 13+ App Router uzywa konwencji file-based — struktura folderow staje sie struktura URL.

app/
+- layout.jsx          <- root layout (zastepuje _app)
+- page.jsx            <- /
+- about/
|  +- page.jsx         <- /about
+- blog/
|  +- layout.jsx       <- layout dla /blog/*
|  +- page.jsx         <- /blog
|  +- [slug]/
|     +- page.jsx      <- /blog/[slug]
+- shop/
|  +- [...categories]/
|     +- page.jsx      <- /shop/foo, /shop/foo/bar (catch-all)
+- (admin)/            <- route group, nie widoczne w URL
|  +- dashboard/
|     +- page.jsx      <- /dashboard
+- api/
   +- users/
      +- route.js      <- API endpoint /api/users

// app/blog/[slug]/page.jsx — Server Component
export default async function BlogPost({ params }) {
  const { slug } = await params; // Next 15: params is Promise
  const post = await db.posts.findBySlug(slug);
  return (
    <article>
      <h1>{post.title}</h1>
      <p>{post.body}</p>
    </article>
  );
}

// generateMetadata — tytul, OG, etc.
export async function generateMetadata({ params }) {
  const { slug } = await params;
  const post = await db.posts.findBySlug(slug);
  return { title: post.title, description: post.excerpt };
}

// generateStaticParams — SSG
export async function generateStaticParams() {
  const posts = await db.posts.all();
  return posts.map(p => ({ slug: p.slug }));
}

Tanstack Router

Tanstack Router — nowoczesny router z type-safe linkami i parametrami. File-based lub code-based. 100% TypeScript-first.

# Instalacja
npm i @tanstack/react-router @tanstack/react-router-devtools

// routes/posts.$postId.tsx
import { createFileRoute } from '@tanstack/react-router';

export const Route = createFileRoute('/posts/$postId')({
  loader: async ({ params }) => {
    return await fetchPost(params.postId);
  },
  component: PostComponent,
});

function PostComponent() {
  const post = Route.useLoaderData(); // typed!
  const { postId } = Route.useParams(); // typed string
  return <h1>{post.title}</h1>;
}

// W komponencie — typed Link
import { Link } from '@tanstack/react-router';

<Link to="/posts/$postId" params={{ postId: '123' }}>Zobacz</Link>
// TS error gdy zapomnisz parametru!
