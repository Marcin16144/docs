Zapis i eksport

Formaty plików, Save / Save As / Save a Copy, Save for Web i ImageReady

Aktualizacja: 2026-06

Photoshop 6.0 oferuje trzy warianty zapisu przez menu File oraz osobne narzędzie Save for Web zoptymalizowane pod kąt grafiki internetowej. Wybór formatu jest kluczowy — PSD zachowuje wszystkie dane do dalszej edycji, a formaty docelowe (JPEG, PNG, GIF) służą dystrybucji.

Polecenia zapisu (File)

PolecenieSkrótDziałanie
File > SaveCtrl+SZapisuje plik w bieżącym formacie i lokalizacji — nadpisuje. Dla nowych dokumentów otwiera okno dialogowe jak Save As.
File > Save AsCtrl+Shift+SZapisuje kopię pod nową nazwą, w nowej lokalizacji lub innym formacie. Photoshop przełącza się na nowy plik jako aktywny dokument.
File > Save a CopyCtrl+Alt+SZapisuje kopię w wybranym formacie bez zmiany aktywnego dokumentu. Dodaje przyrostek copy do nazwy. Przydatne do eksportu JPEG/PNG bez opuszczania pracy na PSD.
File > RevertF12Przywraca plik do ostatnio zapisanej wersji — cofnięcie wszystkich zmian od ostatniego zapisu.
💡 W oknie Save As opcja As a Copy (zaznaczone automatycznie w Save a Copy) spłaszcza obraz przy formatach nieobsługujących warstw i dołącza przyrostek copy. Opcja Layers (checkbox) jest aktywna tylko przy formatach obsługujących warstwy (PSD, TIFF z opcją warstw).

Formaty plików

.PSD
Photoshop Document
Format roboczy — zachowuje warstwy, maski, kanały, ścieżki, tekst wektorowy, efekty warstwy. Do 2 GB. Jedyny format gwarantujący pełną edytowalność.
.TIFF
Tagged Image File Format
Standard wymiany z DTP i drukarniami. Obsługuje warstwy (opcja), kanały alfa, CMYK, 16-bit. Bezstratna kompresja LZW lub ZIP. Duże pliki.
.EPS
Encapsulated PostScript
Eksport do programów DTP (QuarkXPress, InDesign). Obsługuje Clipping Path. Spłaszcza warstwy. Opcje: kodowanie Binary/ASCII/JPEG, podgląd TIFF/PICT.
.JPEG
Joint Photographic Experts Group
Stratna kompresja — doskonały dla fotografii. Jakość 0–12 (lub 0–100%). Nie obsługuje przezroczystości. Wielokrotny zapis degraduje jakość.
.GIF
Graphics Interchange Format
Maksymalnie 256 kolorów — dobry dla grafik z płaskimi obszarami koloru i animacji. Obsługuje przezroczystość binarną (1-bit). Bezstratna kompresja LZW.
.PNG
Portable Network Graphics
Bezstratna kompresja. PNG-8 (256 kolorów jak GIF) lub PNG-24 (pełny kolor). Obsługuje przezroczystość alpha (256 poziomów). Zastępstwo dla GIF bez animacji.
.PDF
Portable Document Format
Photoshop PDF — zachowuje warstwy i dane Photoshopa (opcja). Można otworzyć z powrotem w Photoshopie. Opcje zabezpieczeń i kompresji.
.BMP
Windows Bitmap
Format Windows bez kompresji. Głębia 1/4/8/24/32 bit. Rzadko używany poza środowiskiem Windows i aplikacjami systemowymi.
.PCX
ZSoft Paintbrush
Starszy format z kompresją RLE. Obsługuje głębię 1/8/24 bit. Sporadycznie wymagany przez starsze aplikacje.
.RAW
Photoshop Raw
Surowe dane pikseli bez nagłówka — do wymiany między programami. Nie mylić z formatami RAW aparatów fotograficznych (nie obsługiwanych w Photoshopie 6.0).

Tryby podglądu w Save for Web

  • Original — oryginalny obraz bez optymalizacji
  • Optimized — podgląd po optymalizacji z bieżącymi ustawieniami
  • 2-Up — oryginał obok zoptymalizowanego (porównanie)
  • 4-Up — cztery panele z różnymi ustawieniami jednocześnie — wybierz optymalny kompromis

Opcje Save for Web — JPEG

  • Quality (0–100) — suwak jakości kompresji
  • Progressive — JPEG ładujący się stopniowo (od rozmazanego do ostrości)
  • Optimized — lekko zmniejsza rozmiar pliku przez optymalizację tablic Huffmana
  • ICC Profile — dołącza profil kolorów (zwiększa rozmiar)
  • Matte — kolor tła zastępujący przezroczystość (JPEG nie obsługuje alpha)
  • Blur — lekkie rozmycie przed kompresją — zmniejsza rozmiar kosztem ostrości

Opcje Save for Web — GIF

  • Colors (2–256) — liczba kolorów w palecie; mniej = mniejszy plik
  • Algorithm — algorytm budowania palety: Perceptual / Selective / Adaptive / Web
  • Dither — symulacja brakujących kolorów przez przeplatanie pikseli: Diffusion / Pattern / Noise / No Dither
  • Transparency — zachowuje przezroczystość (jeden kolor przezroczysty)
  • Interlaced — GIF ładujący się stopniowo
  • Web Snap — przesuwa kolory do bezpiecznej palety 216 kolorów Web Safe
  • Lossy — opcjonalne stratne kompresowanie GIF (do 40% mniejszy plik)

Opcje Save for Web — PNG

  • PNG-8 — jak GIF: 256 kolorów, przezroczystość 1-bit, dithering
  • PNG-24 — pełne 24-bitowe kolory z 8-bitowym kanałem alpha (przezroczystość wielopoziomowa). Bezstratna kompresja — pliki większe niż JPEG.

ImageReady 3.0

Photoshop 6.0 jest instalowany razem z programem ImageReady 3.0 — dedykowanym narzędziem do grafiki webowej. Przycisk w dolnej części Toolbox (Jump to ImageReady, skrót Ctrl+Shift+M) otwiera bieżący dokument bezpośrednio w ImageReady.

Funkcja ImageReady 3.0Opis
Animacje GIFPaleta Animation — tworzenie ramek animacji z warstw lub ręcznie; tweening (automatyczne przejścia)
RolloverPaleta Rollover — stany interaktywne przycisków (Normal, Over, Down, Click, Out, Up, Selected, Custom)
Wycinki (Slices)Zaawansowane zarządzanie plasterkami — przypisanie URL, Alt text, typ zawartości (Image / No Image / Table)
Image MapsMapy obrazkowe z obszarami klikalinymi (circle, rectangle, polygon)
Save Optimized AsEksport jako HTML + obrazki — gotowy szablon strony z wycinkami i tabelą HTML
Preview in BrowserSzybki podgląd wyeksportowanej grafiki w domyślnej przeglądarce
✅ Przepływ pracy między Photoshopem a ImageReady jest dwukierunkowy — zmiany w jednym programie natychmiast aktualizują się w drugim po powrocie (Jump). Pliki PSD zapisują dane obu programów w jednym dokumencie.

Zalecany przepływ pracy przy zapisie

  1. Pracuj w formacie PSD — zapisuj często (Ctrl+S).
  2. Eksport do druku: File > Save a Copy → TIFF (LZW) lub EPS z Clipping Path.
  3. Eksport na web: File > Save for Web → JPEG (fotografie) lub PNG-24 (grafiki z alpha).
  4. Grafika webowa z animacją lub rollovery: Jump to ImageReady → Save Optimized As.
  5. Archiwum: zachowaj PSD z warstwami jako plik macierzysty.
