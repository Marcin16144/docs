Tekst i typografia

Narzędzie Type, tekst wektorowy, palety Character i Paragraph, Warp Text

Aktualizacja: 2026-06

Photoshop 6.0 wprowadził prawdziwy tekst wektorowy — edytowalny w dowolnym momencie, renderowany z pełnym antyaliasingiem, osadzony na dedykowanej warstwie tekstowej. To przełom w stosunku do starszych wersji, gdzie tekst był natychmiast rasteryzowany. Palety Character i Paragraph oraz narzędzie Warp Text dają pełną kontrolę typograficzną.

Narzędzie Type

Narzędzie Type (T) dostępne jest w czterech wariantach w Toolbox:

WariantSkrótOpis
Horizontal Type ToolTTekst poziomy — najczęściej używany. Kliknięcie tworzy punkt zakotwiczenia tekstu (point text); kliknięcie i przeciągnięcie tworzy ramkę tekstu akapitowego (paragraph text).
Vertical Type ToolShift+TTekst pionowy — litery ułożone od góry do dołu, kolumny od prawej do lewej. Stosowany w typografii azjatyckiej i efektach dekoracyjnych.
Horizontal Type Mask ToolShift+TTworzy zaznaczenie w kształcie tekstu poziomego — bez tworzenia nowej warstwy. Po zatwierdzeniu zaznaczenie można wypełnić zdjęciem lub teksturą.
Vertical Type Mask ToolShift+TZaznaczenie w kształcie tekstu pionowego.

Tworzenie i edycja tekstu

  1. Wybierz Horizontal Type Tool (T).
  2. Ustaw czcionkę, rozmiar i kolor w Options Bar lub palecie Character.
  3. Kliknij na kanwie — pojawia się migający kursor. Wpisz tekst.
  4. Zatwierdź: Ctrl+Enter lub kliknij ikonę zatwierdź (✔) w Options Bar. Anuluj: Esc.
  5. Aby edytować istniejący tekst: aktywuj narzędzie Type i kliknij na warstwę tekstową.

Point text a Paragraph text

TypJak stworzyćZachowanie
Point textKliknij (bez przeciągania)Tekst rośnie w nieskończoność wzdłuż jednej linii — nie łamie automatycznie. Dobry dla nagłówków i krótkich etykiet.
Paragraph textKliknij i przeciągnij ramkęTekst łamie się w ramce. Ramkę można skalować, obracać i deformować. Dobry dla dłuższych bloków tekstu.

Konwersja między trybami: Layer > Type > Convert to Point Text / Convert to Paragraph Text.

Options Bar dla narzędzia Type

Podczas aktywności narzędzia Type Options Bar wyświetla skrócone ustawienia typograficzne:

  • Orientacja tekstu — przełącznik poziomy/pionowy
  • Font Family — lista zainstalowanych czcionek z podglądem
  • Font Style — Regular, Italic, Bold, Bold Italic (zależnie od dostępnych plików czcionki)
  • Font Size — rozmiar w pt, px lub mm (wg ustawień Units & Rulers)
  • Anti-aliasing — None / Sharp / Crisp / Strong / Smooth
  • Alignment — Left / Center / Right (lub Top / Center / Bottom dla tekstu pionowego)
  • Color — kolor tekstu; kliknij próbkę, by otworzyć Color Picker
  • Warp Text — przycisk otwierający okno Warp Text
  • Toggle Character/Paragraph palettes — pokazuje/ukrywa palety

Warp Text

Warp Text (przycisk w Options Bar przy aktywnym narzędziu Type lub Layer > Type > Warp Text) pozwala wygiąć warstwę tekstową wzdłuż predefiniowanej krzywej — tekst pozostaje w pełni edytowalny.

Każdy styl ma trzy suwaki: Bend (stopień zniekształcenia, −100 do +100%), Horizontal Distortion i Vertical Distortion (perspektywiczne odkształcenie poziome i pionowe, −100 do +100%).

💡 Warp Text można połączyć z Layer Styles — dodaj Drop Shadow lub Bevel and Emboss do wygiętego tekstu. Tekst pozostaje w pełni edytowalny i warpowalny nawet po dodaniu efektów warstwy.

Rasteryzacja warstwy tekstowej

Warstwa tekstowa (Type layer) jest warstwą wektorową — nie można na niej stosować filtrów, narzędzi malarskich ani większości efektów pikselowych. Aby to umożliwić, warstwę tekstową należy zrasteryzować — skonwertować do pikseli.

  • Kliknij prawym przyciskiem na warstwę tekstową w palecie Layers → Rasterize Layer.
  • Lub: Layer > Rasterize > Type.
  • Photoshop automatycznie pyta o rasteryzację przy próbie zastosowania filtra na warstwie tekstowej.
⚠ Rasteryzacja jest nieodwracalna — po skonwertowaniu tekstu do pikseli nie można edytować treści, czcionki ani zastosować Warp Text. Zawsze zapisuj plik PSD z nienarasteryzowaną warstwą przed rasteryzacją.

Co można robić z warstwą tekstową bez rasteryzacji

  • Edytować treść, czcionkę, rozmiar, kolor i formatowanie (narzędziem Type)
  • Stosować Layer Styles (Drop Shadow, Bevel and Emboss, Glow itd.)
  • Stosować Warp Text
  • Stosować transformacje: Edit > Transform (skalowanie, obrót, pochylenie)
  • Używać jako maski obcinającej (Clipping Group)
  • Wczytywać zaznaczenie w kształcie tekstu: Ctrl+klik na miniaturze warstwy
✅ Chcesz zastosować filtr na tekście zachowując edytowalność? Zduplikuj warstwę tekstową (Ctrl+J), zrasteryzuj duplikat i stosuj filtry na nim. Oryginalna warstwa tekstowa pozostaje nienaruszona na wypadek korekty.
