Podstawy i interfejs

Czym jest DaVinci Resolve, wersja darmowa vs Studio, wymagania, projekt i 7 stron programu

Aktualizacja: 2026-06

DaVinci Resolve (Blackmagic Design) to kompletny, profesjonalny program do postprodukcji wideo łączący w jednej aplikacji: montaż, efekty wizualne (Fusion), korekcję i gradację koloru, pełne studio dźwięku (Fairlight) oraz eksport. Słynie z tego, że jego darmowa wersja jest w pełni funkcjonalna — bez znaku wodnego i bez limitu czasu. Działa na Windows, macOS i Linux.

🎬 Resolve wyrósł z narzędzia do color gradingu używanego w kinie i wciąż ma najlepszy na rynku moduł koloru. Od kilku lat to także pełnoprawny program do montażu — realna alternatywa dla Premiere Pro czy Final Cut.

Pobieranie i instalacja

  1. Wejdź na blackmagicdesign.com → Products → DaVinci Resolve → Download.
  2. Wybierz DaVinci Resolve (darmowy) dla swojego systemu. Pobranie wymaga krótkiej, bezpłatnej rejestracji (imię + e-mail). Instalator to ~3–4 GB.
  3. Zainstaluj i uruchom. Przy pierwszym starcie pojawi się Project Manager (menedżer projektów).
  4. (Opcjonalnie) Studio aktywujesz kluczem licencyjnym lub kluczem sprzętowym (USB) dołączanym m.in. do kamer Blackmagic.

Projekt i ustawienia

Resolve przechowuje projekty w bazie danych (domyślnie lokalnej „Disk database"), a nie jako pojedyncze pliki — projekty otwierasz z poziomu Project Managera.

  1. Nowy projekt: w Project Managerze kliknij New Project, nadaj nazwę.
  2. Ustawienia projektu: Shift+9 lub ikona koła zębatego (prawy dolny róg) → zakładka Master Settings: rozdzielczość (np. 1920×1080), Timeline frame rate i Playback frame rate.
  3. Zapisywanie: Ctrl+S. Włącz Live Save i Project Backups w Preferences → User → Project Save and Load.
⚠️ Frame rate ustaw na początku! Klatkaż osi czasu (Timeline frame rate) jest „zamykany" po dodaniu pierwszego materiału do projektu i później bardzo trudno go zmienić. Dobierz go do nagrań (np. 25, 30 lub 24 kl/s) zanim zaczniesz montaż.

Import materiałów (Media Pool)

Media Pool to biblioteka wszystkich klipów projektu, wspólna dla wszystkich stron.

  • Import: przeciągnij pliki z Eksploratora do Media Pool, albo na stronie Media użyj Media Storage (lewy górny róg) i przeciągnij do puli.
  • Koszyki (bins): twórz foldery w Media Pool (PPM → New Bin), by porządkować ujęcia, audio, grafikę.
  • Optimized media / proxy: PPM na klipie → Generate Optimized Media — Resolve tworzy lżejsze kopie do płynnego montażu ciężkich plików (4K, H.265).
📁 Resolve domyślnie nie kopiuje plików do projektu — odwołuje się do nich tam, gdzie leżą na dysku. Nie przenoś ani nie usuwaj źródeł po imporcie, bo klipy staną się „offline".

Pierwszy montaż w 5 krokach

  1. Media: zaimportuj nagrania do Media Pool.
  2. Edit: przeciągnij pierwszy klip na pustą oś czasu — Resolve sam utworzy Timeline z parametrami klipu (możesz też: PPM w Media Pool → Create New Timeline).
  3. Układaj kolejne klipy na osi, przycinaj krawędzie, usuwaj luki.
  4. (Opcjonalnie) dodaj tytuł, przejście, popraw kolor i głośność.
  5. Deliver: wybierz preset (np. YouTube 1080p), Add to Render Queue → Render All.

Szczegóły montażu znajdziesz na stronie Montaż i edycja →, a komplet skrótów na stronie Skróty klawiszowe →.

Zapis, kopie i przenoszenie projektu

  • Live Save zapisuje projekt na bieżąco; Project Backups trzyma wersje awaryjne.
  • Eksport projektu: w Project Managerze PPM na projekcie → Export Project (plik .drp) — przenosisz tak projekt na inny komputer (bez mediów).
  • Z mediami: File → Media Management kopiuje także pliki źródłowe; do archiwum użyj Export Project Archive (.dra).
